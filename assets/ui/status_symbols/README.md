# Полевые символы состояний

Пять SVG96 с простыми контурами: кровь, огонь, череп/яд, кислота и вода.
Созданы как кодовые векторные UI-символы по просьбе U убрать пиксельную ступенчатость.
Отдельный API `BattleConditionIcons.character_texture` применяется у фигур;
старый рамочный каталог24 PNG не изменён.

Размер показа/счётчики/hover — [контракт](../../../docs/BATTLE_PRESENTATION_REWORK.md).
Выбор и предел приёмки — [ART](../../../docs/ART_DIRECTION.md).
SVG импортированы только в isolated project; lossless, без mipmaps и alpha repair.
