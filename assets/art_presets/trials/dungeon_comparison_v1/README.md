Изображения не разрезаются на новые PNG: сцена выбирает внутренние UV-области
и отображает их на существующие поверхности ромба128×96. Шесть рисунков пола
берутся из первого ряда; кладка стен и боковин — из первого блока третьего ряда.
Остальные элементы листов сохранены как исходники, но не создают новых объектов
или препятствий в комнате. Точные UV принадлежат сцене/скрипту пресета.

Первая комната определяется текущим узлом похода `layer == 0`. Колонки0–3
доски8×8 используют A, колонки4–7 — B. Художественный выбор по клетке постоянен,
без игрового RNG. Это сравнительное подключение; финальная приёмка арта открыта.
