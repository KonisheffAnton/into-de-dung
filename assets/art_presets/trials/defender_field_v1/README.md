# Пробное поле и два Защитника

Тайлы A/B/C этой первой пробы отклонены как неестественные и сохранены для
сравнения. Сейчас сцена использует [grass_natural_v2](../grass_natural_v2/README.md).
Новый Защитник из этого набора остаётся подключённым.

Три варианта земли из пользовательского референса: A — два пучка, B — пучок
и пятно почвы, C — почти пустая поверхность. `defender_new.png` — прозрачная
производная нового Защитника. Противник использует прежний
[defender_reference_v1.png](../../approved/grass_defender_v1/defender_reference_v1.png).

[поверхность](../../../../scenes/demo/visuals/art_trial_tile.tscn) ·

Четыре вызова встроенного image_gen; PNG после генерации не редактировались.
Кадрирование/масштаб заданы в Godot. Верх128×96, UV внутри светлого канта;
варианты выбираются по постоянной таблице6×6 без RNG. Новый боец имеет равномерный
масштаб и видимую высоту72px; старый отражён относительно опоры.

Происхождение, точные запросы, размеры/SHA/UV и ограничения —
[пакет](../../../../docs/art/defender-field-20261009/README.md).
Это проба, не замена утверждённого набора. Пропорции, оттенки соседних тайлов,
посадка и итоговый вид оцениваются пользователем. У фигур один ракурс
и прежние Tween, не новые покадровые анимации.
