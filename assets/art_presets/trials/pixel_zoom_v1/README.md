# Пробная выборка спрайта в игровом размере

`native_sprite.gdshader` используется только двумя Sprite2D в
`scenes/demo/visuals/art_trial_unit.tscn`. Материалы и настройки принадлежат сцене;
у runtime нет мутаций общих материалов или загрузки исходников на каждый кадр.

| Рисунок | source_region | native_size |
|---|---|---|
| Новый союзный | 89,206,1034,966 | 77×72 |
| Прежний зеркальный | 0,0,312,292 | 78×73 |

UV превращаются в фиксированную сетку игрового рисунка, независимо от размера
большого PNG. Центры читаются nearest; alpha исходника пороговая0.5. Затем
box coverage экранного пикселя использует до девяти ячеек, с premultiplied alpha
и возвратом straight alpha перед CanvasItem modulation. Это сохраняет плавные
затухания/цветовые modulation родителя; прозрачный RGB не подсвечивает контур.
На целой сетке1:1 смешивание отсутствует; дробное положение/масштаб мягче.
Footprint ограничен двумя ячейками по каждой оси. Сильное уменьшение менее0.5
экранного пикселя на ячейку и GPU стоимость отдельно не проверены.

PNG, Atlas crop, flip_h, посадка, размеры и камера не изменены. Это rendering
проба, не новая генерация/исправленный пиксель-арт и не финальный стандарт.
