# Земля по референсам — проба v3

Поручение 2026-10-10 после отклонения предыдущих двух вариантов травы.
Четыре оригинальных PNG1448×1086, встроенный image_gen, без обработки файлов:

- `grass_a.png` — крупный пучок слева.
- `grass_b.png` — меньший пучок справа сверху.
- `grass_c.png` — спокойная земля, пятна почвы и мелкая трава.
- `grass_d.png` — пара пучков справа снизу.

[Сцена тайла](../../../../scenes/demo/visuals/art_trial_tile.tscn) задаёт четыре
одинаковых ромба128×96 и UV внутри непрозрачной части изображений. Рисунки
сохраняют исходные PNG; с2026-10-10 выбранная гаммаА применяется единым
color(0.79,0.80,0.75,1) ко всем четырём поверхностям, без отражений или поворотов. Постоянная
таблица8×8 выбирает вариант без игрового RNG. Повтор на больших полях возможен.
QuietSeam — тонкий полупрозрачный контур клетки, редактируемый в этой же сцене.
