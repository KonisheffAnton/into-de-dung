# Одежда разбойника — 2026-10-12

U поручил смену цветов по образцу Защитника. Общий временный список «Одежда»
в боевом HUD меняет ткань союзных Защитников и разбойников: исходная,
бордовая, синяя, лесная, охра, сливовая, серая. Выбор общий для этих классов
на текущей доске, не сохраняется в профиль/поход; новая доска — исходная гамма.

`cloth_masks.svg` — служебный атлас масок, не рисунок/анимация. Формат совместим
с native_sprite:10×10 ячеек128px. Слоты0 — still,1–12 — idle,13–18 — B1,
19–31 — D3. Все32 маски получены на native-сетке128 из центров полного PNG512,
как при отрисовке текущего разбойника. У Защитника отдельный атлас.

Маска выбирает оливковые капюшон, накидку и переднюю ткань. Лицо, кожаные
доспехи/ремни/сапоги, металл кинжалов и тёмный контур исключаются отбором
цветов. Правило рассчитано на текущие32 исходника; при смене рисунка нужны
повторные маски и просмотр. Оно не является общей сегментацией любого арта.
`mask_sources.json` фиксирует источник, SHA256, сетку и число выбранных пикселей.

Шейдер меняет только RGB выбранной ткани до фильтрации покрытия; свет/тень,
alpha и контуры сохраняются. Исходная гамма выключает ветку перекраски.
PNG и ресурсы тайминга не изменяются. D3 сохраняет0.65s падения,0.25s паузы
и0.80s fade; alpha рисунка задаёт тот же Tween. Generic-тело не перекрашивается.
У каждой фигуры собственные материалы; неизвестная текстура не получает маску.
Враги, прочие классы и legacy HUD прежние. Refresh/resize/reset сохраняют выбор
на той же доске; смена цвета не сбрасывает кадр/время и не обращается к session.

Воспроизводимость (Python с Pillow):
`python tools/art/build_rogue_cloth_masks.py --check`.
Перегенерация без `--check` требует повторного просмотра всех32 масок.
