# Defender death animation asset

U2026-10-12 одобрил для игровой интеграции версию с вручную восстановленной
бородой: `docs/art/defender-death-beard-fix-20261012/preview.gif`.

Каталог содержит исходные 33 кадра 128×128 RGBA, скопированные без изменений.
Пути и SHA-256 оригиналов и копий записаны в `source-manifest.json`.
`death_frames.tres` задаёт анимацию `death` без повтора: 33 кадра по 3 тика
со скоростью 50 fps, то есть 60 ms на кадр и 1.98 s на полный клип.

В превью последняя поза удерживается 900 ms вместо обычных 60 ms; эта пауза
добавлена только для удобства просмотра и в игровой ритм не включена.
Очередность и сами 33 позы остаются исходными.

Сохраняется опора canvas 128×128 и позиция Sprite2D(-69.42,-90.14) внутри
ArtRoot с масштабом 80%. Враг смотрит навстречу союзнику: позиция (69.42,-90.14),
scale.x=-1; HUD/якоря не отражаются. Второй набор PNG не нужен.
