# Одежда Защитника — 2026-10-12

U поручил выбор гаммы ткани и временный переключатель в игре.
«Одежда» в верхней строке боевого HUD меняет союзных Защитников текущего
экрана: исходная, бордовая, синяя, лесная, охра, сливовая, серая.
По следующему поручению U тот же выбор распространяется на союзных разбойников
через [отдельный атлас масок](../rogue_cloth_v1/README.md), по U2026-10-17 —
также на [Лучниц](../archer_cloth_v1/README.md).
Новая доска начинает с исходной гаммы; выбор не записывается в профиль/поход.

`cloth_masks.svg` — служебный атлас бинарных масок на сетке native_sprite,
не новый рисунок. 10×10 ячеек по128px: 0 — статичная поза77×72,
1–12 — vertical, 13–24 — sway, 25–57 — buff, 58–90 — death.
Маска выбирается по известной исходной текстуре; незнакомые ресурсы не красятся.
Шейдер меняет ткань до фильтрации покрытия пикселя. Щит с той же оливковой
палитрой исключён пространственной маской, кожа/металл/кожа ремней — отбором
исходных цветов. Пара цветов сохраняет свет/тень и тёмные складки.

Исходные90 PNG и статичный рисунок не меняются. `mask_sources.json` содержит
SHA256, сетку, число выбранных пикселей и исключённый контур щита каждого кадра.
Воспроизводимость: `python tools/art/build_defender_cloth_masks.py --check`
(нужен Pillow). Перегенерация без `--check` требует повторного просмотра всех
кадров: правила рассчитаны на текущий принятый набор, не произвольного бойца.

Настройкой владеет доска представления; материалы изолированы по экземпляру.
Сброс, resize и публикации на той же доске сохраняют выбор. Смена цвета не
запускает refresh, не меняет фазу анимации и не обращается к сессии/worker/RNG.
Враги, классы кроме warrior/rogue/archer, общее тело окружения и legacy HUD сохраняют прежний вид.
Внешний вид гамм и переходы остаются предметом ручной F5-приёмки.
