# Одежда Лучницы — 2026-10-17

По поручению U союзная Лучница использует существующий общий выбор «Одежда»
наравне с Защитником и разбойником: исходная, бордовая, синяя, лесная, охра,
сливовая и серая. Цвета принадлежат `DefenderClothPalette`, runtime-маршрут —
[visual contract](../../../../docs/BATTLE_VISUAL_SCENE_CONTRACT.md#выбор-цвета-одежды-персонажей).

`cloth_masks.svg` — двоичный атлас1280×1280,10 столбцов по128. Слоты0–11
соответствуют `../archer_idle_v1/idle/frame-01.png`…`frame-12.png`; still использует
slot0. Нет пересэмплирования: исходник уже128×128. `mask_sources.json` содержит
SHA256 всех12 исходников и размер маски каждого кадра (274–299 пикселей).
Оливковая туника и передняя свисающая ткань отделены от волос, кожи,
кожаного снаряжения, лука и тёмного контура. Правило цвета авторское для
этого набора, не универсальный детектор одежды будущих рисунков.

Shader меняет только RGB внутри маски до покрытия и текущей brighter-коррекции.
Исходная гамма выключает тканевую ветку, сохраняя более яркую общую палитру.
Материалы принадлежат экземплярам; враги и generic-тела сохраняют исходную одежду.
PNG/alpha, якоря/масштаб/изометрия и12-кадровый цикл2.6s не менялись.
Отдельных buff/death-клипов у Лучницы нет.

Воспроизведение (Python с Pillow):
`python tools/art/build_archer_cloth_masks.py`; сверка: та же команда с `--check`.
Godot: `python tools/demo/isolate.py --render-check --only archer_cloth_palette --screen 0`.
[Кадры, проверки и границы приёмки](../../../../docs/art/archer-cloth-20261017/README.md).
