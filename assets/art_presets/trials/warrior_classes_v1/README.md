# Выбранные модели классов

Выбор пользователя 2026-10-30: Щитоносец — №17, Воин — №11 из
[галереи](../../../../docs/art/warrior-variants-20261029/README.md).
ImageGen извлёк персонажей с прозрачным фоном по исходным концептам.
PNG сохранены без последующей обработки пикселей; provenance.json содержит
точный запрос, исходник и SHA-256. Вырезка области и игровой масштаб заданы
обратимыми параметрами сцены `art_trial_unit.tscn`.

Обе фигуры вновь имеют исходный равномерный масштаб: около58px высотой
на тайле128×96, shader76px с полями. У Щитоносца используется исходный
`shieldbearer-17.png`, область(96,89,1051,1102), scale0.0689655172,
position(-42.1,-73.8), ArtRoot0.8; enemy зеркален. Портрет читает тот же исходник.

По уточнению U модель17 сохраняется, меняется только цвет боевого материала.
[Актуальная палитра и сравнение](../../../../docs/art/shieldbearer-palette-20261030/README.md).
Обводка выключена; RGB-профиль включён только у Щитоносца, исходные PNG
не редактируются. Для11 и остальных моделей профиль по умолчанию выключен.
`shieldbearer-17-readable.png` и прежний пакет читаемости — отклонённая проба
формы, сохранённая для истории, но больше не подключённая к классу.

Это статичные модели; авторские покадровые анимации не создавались.
Правила и ограничения интеграции — [WARRIOR_V1](../../../../docs/WARRIOR_V1.md).
