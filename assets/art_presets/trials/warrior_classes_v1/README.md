# Выбранные модели классов

Выбор пользователя 2026-10-30: Щитоносец — №17, Воин — №11 из
[галереи](../../../../docs/art/warrior-variants-20261029/README.md).
ImageGen извлёк персонажей с прозрачным фоном по исходным концептам.
PNG сохранены без последующей обработки пикселей; provenance.json содержит
точный запрос, исходник и SHA-256. Вырезка области и игровой масштаб заданы
обратимыми параметрами сцены `art_trial_unit.tscn`.

Масштаб равномерный: видимая фигура примерно 58 px высотой на тайле 128×96.
Сетка shader — 76 px с полями; поза компактная, без изометрии персонажа.
По последнему запросу пользователя обводка отключена: используется обычный
`pixel_zoom_v1/native_sprite.gdshader` без чтения фона. Цвета исходника
не осветляются палитрой прежнего Защитника. Отдельные портреты читают тот же PNG.

Технический render — `test_reports/warrior-class-20261030/models-on-tiles.png`.
Это статичные модели; авторские покадровые анимации не создавались.
Правила и ограничения интеграции — [WARRIOR_V1](../../../../docs/WARRIOR_V1.md).
