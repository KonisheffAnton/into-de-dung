# Rogue animation trial v1

Пакет содержит выбранные анимации разбойника: idle (12 кадров), B1 buff (5 кадров), D3 death (13 кадров), а также `still.png` и `corpse.png`. Все игровые PNG имеют размер 512×512 и режим RGBA. `manifest.json` фиксирует SHA-256 исходников и результатов, операции сборки, тайминги и проверку RGBA для idle.

Idle скопирован побайтно из выбранного готового покадрового набора `rogue-idle-layered-20261012`, кадры 1, 5, 9, …, 45 согласно `rogue-idle-cadence-20261012/validation.json`. Их композиция на непрозрачном фоне `#3f4b43` совпадает с `preview.gif` в соответствующие моменты цикла. Это кадры выбранного U готового набора; сборщик не рисует позы и не интерполирует движение.

B1 взят из `rogue-buff-outline-20261012/final/manifest.json`. Локальная коррекция палитры явно разрешена U; кадры и длительности взяты из этого утверждённого результата. D3 взят из PixelLab `rogue-buff-death-variants-20261012/death-03-side/pixellab/frame-01.png` … `frame-13.png`. Новых генераций при сборке нет. B1, D3 и still масштабируются из 128×128 до 512×512 через nearest-neighbor ×4, сохраняя RGBA; `corpse.png` побайтно равен собранному D3 кадру 13. GIF-пауза 800 ms в D3 не включена.

Для посадки Sprite2D: scale `(0.25, 0.25)`, position `(-64, -94)` относительно `ArtRoot` с scale `0.8`. Пакет подключён к `scenes/demo/visuals/art_trial_unit.tscn` для обеих сторон в текущем походе и пробной сцене. B1 сопровождает существующую «Защиту», новой механики нет. После D3 публикуется штатное generic-тело окружения; `corpse.png` хранит последнюю позу как артефакт, к отрисовке тел не подключён. Lifecycle и исключения падений — `docs/BATTLE_VISUAL_SCENE_CONTRACT.md`.

## Длительности

- `idle`: loop, 12 кадров по 200 ms, 5 fps, цикл 2400 ms.
- `buff`: без loop, 200/350/60/120/240 ms (20/35/6/12/24 тиков при 100 fps), всего 970 ms.
- `death`: без loop, 13 кадров по 200 ms, 5 fps, всего 2600 ms.

## Сборка и проверка

Из корня репозитория запустить указанным в задаче bundled Python с Pillow:

```powershell
python tools/art/build_rogue_animation_assets.py
python tools/art/build_rogue_animation_assets.py --check
```

`--check` ничего не записывает: он заново вычисляет ожидаемые байты, сверяет исходные SHA из B1 manifest, проверяет размеры/режимы, кадры preview и каждый итоговый файл побайтно.
