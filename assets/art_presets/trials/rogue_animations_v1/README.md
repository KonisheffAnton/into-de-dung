# Rogue animation trial v1

Пакет содержит анимации разбойника: idle (12 кадров), B1 buff (6 кадров), D3 death (13 кадров), а также `still.png` и `corpse.png`. Все игровые PNG имеют размер 512×512 и режим RGBA. `manifest.json` фиксирует SHA-256 исходников и результатов, операции сборки, тайминги и проверку RGBA для idle.

Idle скопирован побайтно из выбранного готового покадрового набора `rogue-idle-layered-20261012`, кадры 1, 5, 9, …, 45 согласно `rogue-idle-cadence-20261012/validation.json`. Их композиция на непрозрачном фоне `#3f4b43` совпадает с `preview.gif` в соответствующие моменты цикла. Это кадры выбранного U готового набора; сборщик не рисует позы и не интерполирует движение.

B1 и D3 взяты из [правки темпа](../../../../docs/art/rogue-timing-cleanup-20261012/README.md), `buff-final/manifest.json` и `death-final/manifest.json`. B1: прежние стойка/крест, два новых этапа раскрытия PixelLab с меньшим шагом у максимума, прежний возврат/стойка. Локально исправлены только слишком тёмные RGB по прежнему разрешению U. D3 PNG сохранены побайтно, меняется только скорость ресурса. B1, D3 и still масштабируются из128×128 до512×512 через nearest-neighbor ×4, сохраняя RGBA; `corpse.png` побайтно равен собранному D3 кадру13. Сборщик не генерирует новые позы. Материал Rogue использует native_size128×128 при полном source_region512×512 для устойчивого уменьшения; исходные PNG не перерисовываются.

Для посадки Sprite2D: scale `(0.25, 0.25)`, position `(-64, -94)` относительно `ArtRoot` с scale `0.73`. Пакет подключён к `scenes/demo/visuals/art_trial_unit.tscn` для обеих сторон в текущем походе и пробной сцене. B1 сопровождает существующую «Защиту», новой механики нет. После D3 публикуется штатное generic-тело окружения; `corpse.png` хранит последнюю позу как артефакт, к отрисовке тел не подключён. Lifecycle и исключения падений — `docs/BATTLE_VISUAL_SCENE_CONTRACT.md`.

## Длительности

- `idle`: loop, 12 кадров по 200 ms, 5 fps, цикл 2400 ms.
- `buff`: без loop, 120/240/60/320/120/160 ms,100 fps,всего1020 ms. Быстрый первый развод, меньшая доводка и удержание на максимуме.
- `death`: без loop,13 кадров по50 ms,20 fps,клип650 ms. Представление добавляет250 ms удержания и800 ms затухания только RogueIdleSprite: всего1700 ms одним Tween, затем обычная публикация after/тела. PNG не содержат fade.

## Сборка и проверка

Из корня репозитория запустить указанным в задаче bundled Python с Pillow:

```powershell
python tools/art/build_rogue_animation_assets.py
python tools/art/build_rogue_animation_assets.py --check
```

`--check` ничего не записывает: он заново вычисляет ожидаемые байты, сверяет исходные SHA и длительности из B1/D3 manifest, проверяет размеры/режимы, кадры preview и каждый итоговый файл побайтно.
