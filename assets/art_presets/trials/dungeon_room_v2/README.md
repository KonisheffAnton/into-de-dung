# Каменное подземелье 01 — материалы и декорация

Четыре исходных PNG встроенного ImageGen сохранены побайтно. Референс —
панель01 приложенного пользователем шеститемного концепта. Это одна согласованная
палитра; прежняя A/B-проба остаётся в dungeon_comparison_v1 как история.

| Файл | Назначение | Размер |
|---|---|---|
| floor.png | Сплошная плоская поверхность из8×8 крупных плит | 1254×1254 |
| masonry.png | Отдельная фронтальная кладка для вертикальных граней | 1254×1254 |
| column.png | Изолированная разрушенная на рисунке колонна | 1086×1448 |
| fire.png | Компактный огонь на углях | 1448×1086 |

Ромб128×96 создаётся в сцене проекцией плоского пола. Одна клетка использует
156.75×156.75 исходных texel; соседние UV совпадают. Боковина использует313.5texel
на ребро и1254/256texel на nativepx высоты: рисунок повторяется, не тянется.
Текстура панели ловушки имеет ту же плотность. Нейтральные направленные tint
кладки задаются сценой, PNG не перекрашивается.

Колонна: Sprite2D region(216,374,624,780), uniform scale90/780, position(0,-33).
Область выбрана вокруг видимого alpha>=16 тела (221,379..832,1147); слабые
изолированные alpha-пиксели вне тела не должны определять его игровой размер.
Огонь: region(390,250,680,580), uniform scale0.095, position(0,-10).
Ни cropping, ни resize не записывались обратно в исходные файлы.

Runtime: dungeon_comparison_tile.tscn / dungeon_room_environment.tscn,
только первая комната похода. Колонна не имеет HP/разрушения и сохраняет
блокирование D1; ловушка расположена на уступе E4→F4.
