# Idle текущего союзного Защитника

U2026-10-11: внедрить второй вариант как основной, первый проигрывать очень редко.
Это текущий Защитник в шлеме; сохранённый образ «Ветеран» сюда не подключён.

- `vertical/` — №2, из `docs/art/defender-idle-vertical-20261010/pixellab/`.
- `sway/` — №1, из `docs/art/defender-idle-sway-20261010/pixellab/`.
- `idle_frames.tres` — по12 исходных кадров на петлю,5fps (200ms), цикл2.4s.
- `source-manifest.json` — пути и SHA-256 всех24 побайтно скопированных PNG.

Исходные пакеты сохранены. Перерисовки, обрезки, регистрации, интерполяции
и изменения ритма кадров нет. Изображения128×128 содержат прежнюю прозрачную
рамку16px вокруг96×96; позиция Sprite2D(-69.42,-90.14) равна отрицанию
исходной опоры(53.42,74.14) плюс этой рамки. Scale1 внутри прежнего ArtRoot80%.
Материал использует прежний native_sprite.gdshader с region128×128/native128×128.

Сцена: `scenes/demo/visuals/art_trial_unit.tscn` в обычном походе и F6-пробе.
Драйвер: `BattleDefenderIdleVisual`; часы: `DefenderIdleClock`.
Темп редкой петли задают `idle_normal_cycles_min/max` на корне сцены:
по умолчанию24–36 обычных циклов (57.6–86.4s накопленного idle), затем один
цикл покачивания и возврат. Число циклов и начальная фаза зависят от ID без RNG.
В паузах время idle не идёт; скорость боевого показа его не ускоряет.
