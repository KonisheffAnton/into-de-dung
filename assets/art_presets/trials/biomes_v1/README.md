# Биомы первой комнаты

Пять новых наборов дополняют прежний dungeon_room_v2: forest, ice, volcanic,
desert, swamp. Каждый содержит floor.png (плоский верх), side.png (вертикальный
материал), prop.png (прозрачное обычное препятствие). Все15 PNG — побайтные
результаты встроенного ImageGen. Регионы/равномерный scale принадлежат
BiomeArtCatalog; исходные RGBA не перерисованы, не обрезаны, не перекодированы.

Клетки используют непрерывный участок8×8 каждого floor, side повторяется
с постоянной физической плотностью. Ни floor, ни prop не растягиваются на торцы.
Прежние каменные PNG сохранены; чистка предыдущих проб не входит в этап.
