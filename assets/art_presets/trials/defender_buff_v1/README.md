# Жест усиливающих способностей Защитника

U2026-10-11 выбрал `docs/art/defender-shield-taunt-fluid-20261011/preview-compact.gif`
для анимации способности Защитника. Каталог содержит те же33 исходных PNG
128×128 без перекодирования или художественных правок. Хеши исходника и каждой
копии приведены в `source-manifest.json`.

U2026-10-11 попросил проигрывать жест чуть быстрее. `buff_frames.tres` задаёт
однократную анимацию `buff` со скоростью30 вместо25 кадров/с: на20% быстрее,
около1.89s вместо2.27s при скорости боя ×1. Все33 кадра и соотношения задержек
сохранены: кадры01–08/25–32 —1 такт,09–24 —2, последняя стойка33 —8.75.
Исходное компактное превью сохраняет прежние задержки40/80/350ms и2.27s;
`source-manifest.json` раздельно фиксирует исходный и игровой темп.

Сохраняется опора исходного вертикального idle: размер128×128, позиция Sprite2D
(-69.42,-90.14) внутри ArtRoot с масштабом80%. `art_trial_unit` подключает ресурс
к `BattleDefenderIdleVisual`; время задаёт общий Tween показа действия.
Точный охват команд, допуск и cleanup — [контракт](../../../../docs/BATTLE_VISUAL_SCENE_CONTRACT.md#жест-усиливающих-способностей-защитника).
