# Тихая земля и низкая трава — проба v2

Замена отклонённой травы первой пробы, по поручению 2026-10-09.
`ground_quiet.png` — общая основа всех клеток; `grass_low_a.png` и
`grass_low_b.png` — отдельные прозрачные низкие пучки. Три вызова встроенного
image_gen, PNG сохранены без последующей обработки.

[art_trial_tile.tscn](../../../../scenes/demo/visuals/art_trial_tile.tscn) задаёт
верх128×96, UV внутри исходной земли, альфу основы0.55, region/масштаб/позиции
пучков. Общий тон не зависит от выбранной композиции. Grass0 пустой;
Grass1–4 — четыре размещения двух рисунков. Большинство клеток без пучков;
постоянная таблица8×8 собирает украшенные клетки в группы без игрового RNG.

F6: [art_trial_battle.tscn](../../../../scenes/demo/art_trial_battle.tscn).
Бойцы, основные M3/№4 и F5 сохранены. Это ещё одна проба для ручной оценки,
не приёмка финальной травы или всей графики.
