# Значки A на деревянной панели

По запросу U2026-11-08: дерево с тонким железным ободком под каждым значком.
24 мотива в16/32px; размер/позиция/непрозрачные пиксели исходных A сохранены.
Цифры стаков/тиков не входят в PNG и не имеют собственной плашки.

Источник панели и происхождение: [пакет](../../../../docs/art/status-icon-frame-20261108/README.md).

`manifest.json` хранит SHA256 панели, исходных A и всех48 композиций.
Nearest, lossless, без mipmaps/fix_alpha_border/premult; панель непрозрачна.
Техническая проверка не заменяет отзыв пользователя о читаемости в бою.
