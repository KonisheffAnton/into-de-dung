# Значки A: игровые размеры

U2026-11-08 выбрал A для всех24 мотивов. `16/` — ряд состояний и компактный
осмотр фигуры; `32/` — карточка персонажа и одна строка осмотра клетки.
Отдельные RGBA PNG, прозрачное поле1/2px,
nearest, без mipmaps и коррекции прозрачной каймы. Пропорции сохраняются.

Происхождение и восстановленные края4 значков —
[пакет](../../../../docs/art/status-icons-a-20261108/README.md).
`manifest.json` связывает каждый PNG с исходным листом/областью A либо repair.
Пересборка: `python tools/art/build_status_icons_a.py`; проверка: `--check`.
Семантика показа — [HUD](../../../../docs/BATTLE_HUD_SCENES_V1.md#значки-состояний-a--2026-11-08).
Готовность размеров к чтению в бою требует отзыва U; выбор A уже принят.
