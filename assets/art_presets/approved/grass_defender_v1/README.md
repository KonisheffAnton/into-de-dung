затем смотреть [чистый эталон](../../../../docs/art/style-reference-20261009/selected-style.png).
В [исходном вложении](../../../../docs/art/style-reference-20261009/user-selection.png)

- [grass_reference_v1.png](grass_reference_v1.png) — M3, «Спокойный луг».
- [defender_reference_v1.png](defender_reference_v1.png) — одобренный светлый №4.

- [Редактируемая композиция Godot](../../../../scenes/demo/art_style_preview.tscn).
- [Игровой тайл](../../../../scenes/demo/visuals/placeholder_tile.tscn) и
  [игровая фигура](../../../../scenes/demo/visuals/placeholder_unit.tscn).

PNG — побайтные копии выданных для Paint экспортов. Новых генераций, перерисовки,
перекраски или повторной центровки нет. Это действующие игровые текстуры;
ранние варианты из docs/art не являются заменой этому набору.

Утверждены ориентир стиля, ракурс и статичный образец/посадка. Ручная приёмка
интеграции в бою, анимации, другие направления/классы и финальный арт остаются
открытыми. Сохранённые PNG не обещают готовый анимационный набор.
