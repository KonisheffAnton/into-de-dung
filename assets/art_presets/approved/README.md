# Утверждённые художественные пресеты

Точка входа для следующего чата. Текущий набор —
[grass_defender_v1](grass_defender_v1/README.md): спокойный луг M3 и Защитник №4,
согласованный ракурс4:3 и посадка по правой композиции пользователя.

Порядок: [ART_DIRECTION](../../../docs/ART_DIRECTION.md) → эталон из README набора
→ `preset.json` → игровые сцены. Учебные принципы —
[PIXEL_ART_GUIDE](../../../docs/PIXEL_ART_GUIDE.md).
Папка содержит выбранные рабочие PNG; варианты/непринятые пробы остаются в docs/art.

Отдельный выбранный образ на будущее — [Ветеран](../../../docs/art/veteran-20261011/README.md).
Он сохранён вне игровых пресетов; подключение и анимации не поручены.

Новый набор добавляется сюда после явного выбора пользователя. Сохранять источник,
дату, область приёмки, эталон, размеры/посадку и SHA; не объявлять одобрение одного
статичного изображения приёмкой анимаций, баланса или всего игрового интерфейса.
