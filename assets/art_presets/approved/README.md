# Утверждённые художественные пресеты

Точка входа для следующего чата. Текущий стиль персонажей закреплён в
[ART_DIRECTION, 2026-11-03](../../../docs/ART_DIRECTION.md#зафиксированная-стилистика-персонажей--2026-11-03).
По U2026-11-03 новый эталон тайла — уже внедрённый
[каменный тайл первой комнаты](../../../docs/art/current-tile-reference-20261103/README.md):
реальный рендер сцены, верх128×96 (4:3), кирпичные боковины64px и исходные атласы.
Прежние [warrior_format_v1](warrior_format_v1/README.md),
[defender_brighter_v1](defender_brighter_v1/README.md) и травяной M3
[grass_defender_v1](grass_defender_v1/README.md) сохраняют происхождение своих
наборов; их формат не переопределяет новые эталоны персонажей и тайла.

Порядок: [ART_DIRECTION](../../../docs/ART_DIRECTION.md) → эталон из README набора
→ `preset.json` → игровые сцены. Учебные принципы —
[PIXEL_ART_GUIDE](../../../docs/PIXEL_ART_GUIDE.md).
Папка содержит выбранные рабочие PNG; варианты/непринятые пробы остаются в docs/art.

U2026-11-08: [status_icons_a_v1](status_icons_a_v1/README.md) —24 выбранных
значка A, PNG16/32 для состояний фигур, реакций и клеток; читаемость в бою ждёт отзыва.

U2026-11-04: [acid05_selected_v1](acid05_selected_v1/README.md) — анимация01
кислоты05. В игре показывается только верхняя поверхность поверх любого
материала; каменное основание из исходных кадров исключено маской.

U2026-11-01: [character_skins_v1](character_skins_v1/README.md) содержит выбранные
02/17 для Щитоносца и11 для Воина, с точными PixelLab idle/death/ability клипами.
Переключение в хабе и playback — [контракт](../../../docs/CHARACTER_SKINS_V1.md).

Отдельный выбранный образ на будущее — [Ветеран](../../../docs/art/veteran-20261011/README.md).
Он сохранён вне игровых пресетов; подключение и анимации не поручены.

Новый набор добавляется сюда после явного выбора пользователя. Сохранять источник,
дату, область приёмки, эталон, размеры/посадку и SHA; не объявлять одобрение одного
статичного изображения приёмкой анимаций, баланса или всего игрового интерфейса.
