# Актуальный эталон Защитника — 2026-10-17

U поручил закрепить уже внедрённую яркую палитру актуальным эталоном в образе
Защитника. [defender-reference.png](defender-reference.png) — текущий статичный
ориентир образа и цвета для следующих персонажей, с прозрачным фоном.

Это рендер реального `art_trial_unit/ArtRoot/PlayerWarriorSprite` с его native
shader и brighter_palette_strength=1, без альтернативной гаммы одежды/HUD/теней.
Номинальный рисунок увеличен4× равномерно для просмотра; это не новый размер
бойца в игре и не новая текстура для подстановки в scene. Поза/материал взяты
из текущего production-пресета, исходные PNG сохранены.

[manifest.json](manifest.json) фиксирует источник, shader, SHA и область выбора.
[Сравнение и воспроизводимый рендер](../../../../docs/art/defender-current-reference-20261017/README.md).
Основной владелец правил — [ART_DIRECTION](../../../../docs/ART_DIRECTION.md).
Прежняя [композиция/геометрия](../grass_defender_v1/README.md) сохранена как основа;
цвет фигуры сверять с этим изображением. Это перенос характера палитры,
не точная LUT генеративной пробы. Анимации, F5 и весь финальный арт этим не приняты.
