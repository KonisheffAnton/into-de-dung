# Выбранные анимации поверхностей опасностей

Выбраны клипы `acidfilm-05` («Рассеянная рябь») и `caltrops03-01` («Редкие блики») из [исходного пакета](../../../../docs/art/hazard-animations-20261104/README.md). Файлы `acid_film05.png` и `caltrops03_glints01.png` — побайтные копии соответствующих `sheet.png`. Ресурсы SpriteFrames имеют анимации `acid` и `caltrops`, по 33 кадра 256×256 при 10 FPS, с циклом. Полный каменный тайл остаётся в PNG; отделение поверхности выполняет runtime-код интегратора. Эти ресурсы не ретушируют кадры и не подтверждают неподвижность камня или бесшовность движения.

[Манифест](manifest.json) хранит исходные пути, ID заданий и SHA-256 каждого кадра. Сборка проверяет лист и кадры попиксельно, включая семь неиспользованных прозрачных ячеек.

Сборка: `python tools/art/build_hazard_surface_animations.py`. Проверка без записи: `python tools/art/build_hazard_surface_animations.py --check`.
