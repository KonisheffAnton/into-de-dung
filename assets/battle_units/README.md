# Пробные воины

## Изометрические пресеты противника — 2026-10-08

Пользователь прислал три варианта для пробы стиля: бородатый воин,
воин в шлеме и рыжеволосая воительница. Исходники 1254×1254 RGB с серым фоном
сохранены без изменений в `sources/` (папка исключена из импорта Godot).
Встроенный image_gen подготовил отдельные RGBA-вырезки с прозрачным фоном;
это производные изображения, не побайтные копии исходных персонажей.
После удаления фона PNG не масштабировались и не перекрашивались.
