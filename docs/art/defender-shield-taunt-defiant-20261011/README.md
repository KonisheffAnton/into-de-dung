# Защитник: более агрессивный вызов

U2026-10-11 после первой пробы: «да и поагрессивнее», «С вызовом».
Поручен один новый кандидат PixelLab: два сильных удара мечом по собственному
щиту, заметный отвод между контактами и вызывающая подача корпуса/щита вперёд.
После второго удара — короткая гордая стойка с приподнятым подбородком,
затем возврат. Ноги остаются опорой. Вспышки, звёзды и новые мелкие детали запрещены.
Это постановка запроса; результат и художественная приёмка оцениваются отдельно.

## Результат и монтаж

Основной кандидат для отзыва — [GIF с двумя замахами](preview-edited.gif),
[в исходном размере](taunt-edited-native.gif), [раскадровка](filmstrip-edited.png).
Он собран из неизменённых PNG PixelLab: отбор, повтор и длительность кадров,
без дорисовки или интерполяции. [Точная последовательность](edited-timeline.json).
Два контакта стоят на4-м и9-м кадрах монтажа; между ними меч возвращается
в положение с заметным промежутком до щита.15 кадров, полный цикл1920ms.
Открытая стойка после второго удара задержана260ms. Вызов читается прежде всего
по силовой подаче и повтору жеста; отдельный подъём подбородка не получился.
Монтажный возврат использует предыдущие позы и может восприниматься резко;
окончательное восприятие и приёмка пользователя остаются открытыми.

Raw-ответ completed получен22:49 MSK: все17 PNG128×128 вместо запрошенных16,
списаны4 генерации. [Метаданные/хеши/usage](pixellab/result.json), [валидация](validation.json).
Неизменённая последовательность — [raw GIF](preview.gif), [native](taunt-native.gif),
[raw раскадровка](filmstrip.png). В ней первый контакт перекрыт большой белой
звездой05; в06 есть остатки эффекта,13 — вспышка у меча в стороне от щита.
В06–11 меч задерживается у щита без второго отчётливого отвода/контакта.
Голова склонена; гордая поза с поднятым подбородком не получилась.
Независимый просмотр сырого клипа: REQUEST_CHANGES для арт-приёмки.
Монтаж исключает05/06/13 и собирает повтор замаха из чистых кадров.
Это исправление последовательности ведущим, не исходная хореография генератора.
Игра не изменена; подключение к способности не выполнено.

Основа — текущий Защитник в шлеме из принятого vertical idle, не «Ветеран».

## Воспроизведение упаковки

`prepare-request.py` лишь собирает запрос, не отправляет его. Повторный POST
автоматически не выполнять: продолжение читает сохранённый background_job_id.
Raw-ответ хранится в игнорируемом `test_reports/defender-shield-taunt-defiant-20261011/job-latest.json`.
После completed извлечь кадры командой из корня проекта:

```powershell
python docs/art/defender-shield-taunt-defiant-20261011/extract-result.py test_reports/defender-shield-taunt-defiant-20261011/job-latest.json
python docs/art/defender-shield-taunt-defiant-20261011/prepare-preview.py
```

Упаковке нужен Pillow. Все полученные PNG сохраняются без изменения; actual count
берётся из ответа, потому что API может вернуть дополнительный исходный кадр.
GIF/раскадровка — увеличение nearest и фон для просмотра, без дорисовки поз.
Для более резкого ритма задано100ms на исходный кадр, в увеличенном GIF
последняя стойка держится550ms между повторами. Это монтажное решение превью.
Отдельные `*-edited` используют длительности из `edited-timeline.json`;
скрипт проверяет число кадров и фактически сохранённые GIF-задержки.
Извлечение сверяет job.id с сохранённым ответом принятия и отказывается подменять
уже сохранённые кадры. Повторное чтение того же результата допускается.
