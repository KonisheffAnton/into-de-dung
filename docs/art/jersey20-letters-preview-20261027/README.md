## Метод сравнения

[Кадр](source-battle.png) 1280×850 — побайтная копия из
[предыдущего сравнения](../pixeloid-numerals-preview-20261027/README.md).
Лист показывает crop x=400, y=0, w=880, h=700 при 50%, полные PNG — 100%.
Обрезанная сверху фигура уже есть в исходнике; фон не ретушировался.
Текст рисуется настоящими TTF через HTML/CSS, без генерации изображения.

Значения −12.5, −28.0, +8.0, −6.0 и КРИТ/ЩИТ/БЛОК/ПРОМАХ/КРОВОТЕЧЕНИЕ —
образцы оформления, не реальные события записанного боя. Везде один Jersey 20
Regular400, одинаковые цвета/позиции, наружный контур4px и тень3px native.
Видимая высота цифр40px, крита50px, слов32px и тегов24px native.
Под кадрами — цифры, слова, статус, «Щит броня HP» и смешанная строка
«КРИТ · −28.0 HP» с видимой высотой букв/цифр14px без контура.

Кегли нормализованы по видимой высоте заглавных; строчные сохраняют пропорции
выбранного шрифта. Дробный масштаб допустим для оптического сравнения.
Это рендер браузера, не Godot: размеры, пиксельная сетка, DPI и движение
не проверены. Вариант06 показывает текущую гарнитуру, не фактические игровые кегли.
Исходный Pixeloid em1836 и Jersey20 em1292 взяты из прежнего превью;
производные runtime-файлы для сравнения не менялись.
