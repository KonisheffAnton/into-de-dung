четыре исходные позы9/10/11/12 в атласе512². Белые маски покрывают только
оба глаза и угол4×4 в каждой ячейке; новые веки нарисованы PixelLab.
[Промпт](prompt.txt), [маски/координаты/соответствие кадрам](edit-manifest.json),
[raw PNG и происхождение](provider/provenance.json).

Секрет в пакет не входит; raw ответ сохранён вне Git в
`D:/Codex/home/generated_images/rvanoukh-selected-20261115/pixellab/edit-1/`.

Raw atlas сохранён побайтно в `provider/raw-atlas.png`. Генератор менял
также немаскированные части рисунка; они **не перенесены** в выбранный клип.
Финальные кадры — техническая сборка исходника с готовыми PixelLab-фрагментами
только внутри масок, а не33 отдельных сырых кадров провайдера.
Веки и другие художественные пиксели локально не рисовались.

- Кадр0 сохранён побайтно целиком. В кадрах1–8 глаза ещё открыты;
  исправляется только посторонний кластер в углу.
- Кадры9/10/11 получают собственные фрагменты закрытых глаз.
- Кадры12–32 используют фрагменты позы12: координаты глаз уже стабильны,
  повторное использование сохраняет закрытое состояние без мерцания.
- Во всех кадрах1–32 используется прозрачный corner patch из квадранта1
  (поза10). Там PixelLab успешно очистил маску; квадрант0 оставил6 пикселей,
  поэтому его corner patch не использован. Raw не ретушировался.

За пределами указанных масок каждый RGBA-пиксель итогового кадра точно
совпадает со своим прежним кадром смерти1. Падение не перегенерировалось.
