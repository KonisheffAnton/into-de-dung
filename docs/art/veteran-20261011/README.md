# Ветеран

Выбранный пользователем статичный образ для будущего использования, 2026-10-11.
U: «Предыдущий вариант мне больше понравился оствляем его на будущее, назовем ветеран».

[Ветеран — исходный PNG](veteran.png): первый упрощённый вариант Защитника,
затем дополненный короткими волосами с седыми висками и более помятыми доспехами.
Серая борода, суровое лицо, открытая голова, оливковые щит/одежда и холодная сталь.
Сохранять крупные спокойные формы; первый перегруженный деталями рисунок был отклонён.
Последующая версия с омоложением **не выбрана**. Название «Ветеран» относится
именно к сохранённому здесь рисунку до омоложения, не к исходному лысому варианту.

Это выбор образа на будущее, не поручение подключать его в игру. Текущий боевой
Защитник, его масштаб/посадка и ранее сохранённые idle-кандидаты остаются прежними.
Игровая посадка этого рисунка, другие ракурсы и анимации не подготовлены и не приняты.
Стиль — [ART_DIRECTION](../../ART_DIRECTION.md); техника — [PIXEL_ART_GUIDE](../../PIXEL_ART_GUIDE.md).
