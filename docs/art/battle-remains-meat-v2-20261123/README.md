# Свежие кучки PixelLab: немного больше мяса — 2026-11-23

U предпочёл кучки PixelLab и попросил добавить немного мяса только свежим.
Указание применено к трём свежим PL1–PL3; отдельный номер пользователь
не назвал. [Сравнение](before-after.png): сверху прежние, снизу новые,
нативные64×64 увеличены ровно×4 nearest-neighbour. Без сглаживания/перерисовки.
[Прежний набор и сухие кости](../battle-remains-variants-20261122/README.md).

Вход — предыдущие PL-F1/2/3, edit-image-pixen; запрос просит примерно на треть
больше имеющихся мясных участков при прежней композиции/палитре/камере.
Точная численная прибавка моделью не гарантирована: PL1 ближе к «чуть больше»,
PL2 осторожнее, PL3 заметно мяснее. Универсальность без головы/черепа/лица
сохранена. Это предложения, пользователь ещё не принял конкретную правку.

[Воспроизводимый запрос](run.py); точные payload/ответы/status/PNG находятся
в PL-F1, PL-F2, PL-F3. Всего3 POST, фактический расход3 generations.
Локально сделано только [оформление сравнения](build_preview.py).
Новые изображения сохранены отдельно; все12 прежних PNG, включая три сухих
PL-B1/2/3, совпадают с прежними SHA256. [Проверки](verification.json).
PNG64×64/RGBA/прозрачность проверены, независимое art review APPROVE для показа.

Игровые ассеты/механики не менялись; Godot/core/manual не запускались.
Следующий шаг — приёмка U и отдельный показ выбранной пары на игровом поле.
