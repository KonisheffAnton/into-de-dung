## Результат

Над складом добавлен выбор живого героя из всего состава, включая резерв.
Карточка вещи показывает владельца, вклад оружия в базу, пробивание/дополнительную
атаку либо остаток/максимум брони. Надевание и снятие бесплатны. При замене
прежняя вещь возвращается на склад; остаток брони не восстанавливается.
Оружие ограничено классом; надетую вещь сначала снимают с текущего владельца.

Используются прежние H1-мутации и copy/save/publish HeroHubScreen. При отказе
записи старый профиль остаётся опубликованным, повтор сохраняет тот же candidate;
выбранные ID героя/вещи сохраняются. Старый запрос снятия не снимает вещь с нового
владельца. Навигация, выбор и render не меняют профиль, RNG или файл сохранения.

Новые элементы сцены независимы на прежних metadata-условиях; подпись обновляется
и после удаления кнопки. Материалы, разборка, фон, портреты и общая тема не менялись.
Прежняя BasePage, черновик колоды и действия Наёмников сохранены.
Улучшение, разборка и изучение отключены, школы остаются нейтральной заготовкой.
Точный контракт — [HUB_SCENES_V1](../../HUB_SCENES_V1.md#экипировка-кузнеца--2026-10-24).
