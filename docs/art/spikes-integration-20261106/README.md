# Выбранные шипы в игре — завершение 2026-11-07

Поручение U: внедрить показанные шипы; выдвижные должны быть резкими.
В общих сценах текущего боя подключены плита01 и кальтропы03 из
[выбранного пакета](../hazard-motion-20261106/README.md). Правила урона,
отложенного взвода, очереди и сохранений не меняются.

Плита переключает три готовые позы: half появляется сразу, extended — через
40 мс. Далее прежний показ урона/смерти, атомарный after, удержание700мс и
втягивание100мс. Галерейный медленный подъём не переносится. Завершённый
хвост удаляет только свою запись позы: повторный resize не восстанавливает её.
Настенные пресеты сохраняют прежний вид и порядок показа.

Кальтропы имеют два блика по300мс за15,6с и точный неподвижный стык. Повторный
configure сохраняет фазу; скрытие/retire останавливает часы. Пять уникальных
кадров и три позы плиты собраны без изменения RGBA. Шейдер плиты скрывает
каменные боковины, но разрешает выбранные пиксели кончиков за краем ромба.

Владельцы поведения: [ловушки](../../ENVIRONMENT_HAZARDS_V1.md),
[визуальные сцены](../../BATTLE_VISUAL_SCENE_CONTRACT.md#выбранные-шипы-и-редкие-блики--2026-11-07).
Сборщик: `tools/art/build_selected_spike_animations.py --check`.
Ресурсы: `assets/art_presets/approved/spikes_selected_v2/`.
