По поручению U выбран [статичный вариант05](../hazard-variants-20261103/acid-05.png)
и создано 10 разных циклов PixelLab. Все задания completed: 330 исходных
PNG, по 33 кадра 256×256 на клип. Серия начата 2026-11-03, завершена
2026-11-04. База:
`c669f9c3e517f06506478c9a51f5d941bdd63022`, `main`.

Задана анимация только кислоты по всей верхней грани: пузырьки/пена/волны,
камера и каменный блок неподвижны. Это требования к генерации;
фактическую неподвижность и стыки нужно оценить по готовым клипам.
На этапе создания серии игровой интеграции не было. Позднее U выбрал01 для
[интеграции отдельной кислотной поверхности](../acid01-integration-20261104/README.md),
без привязки к каменному тайлу. Правила кислоты и ловушек не меняются.

[Открыть автономную галерею](gallery.html): пауза, кадр, скорость, три размера,
тёмный/шахматный фон. Она собрана локально и восстанавливается build_gallery.py
из сохранённых в Git файлов без API. GIF и листы лежат в pixellab/acid-01…10/.

Расход — **50 генераций**, по 5 на клип; отмен/неуспешных заданий нет.
[ID и расход](usage.json), [проверка кадров](validation.json),

## Вход и запросы

[Оригинал1254²](model/source-original.png) сохранён побайтно.
[Вход256²](model/input-256.png) — уменьшение полного кадра LANCZOS под лимит API,
без кадрирования, вырезания эффекта, перекраски или создания анимации локально.
Этот вход содержит весь каменный блок вместе с кислотой. Метаданные/SHA:
[transform.json](model/transform.json).

Актуальная [схема PixelLab](https://api.pixellab.ai/v2/openapi.json) сверена перед
POST. Использован `animate-pixminimax`: запрошено 32 кадра, возвращено 33 с
исходным кадром 0; first_frame=last_frame, no_background=true,
enhance_prompt=false, заданы все4 caption-поля. Полные тела без секрета и
ответы хранятся вне Git в `C:/Users/Aston/.codex/generated_images/acid05-animation-20261103/`.
[Промпты](clip-prompts.json) и [параметры/SHA запросов](requests.json) доступны в пакете.

## Наблюдения и границы приёмки

Осмотрены кадры 0/8/16/24/32 всех десяти клипов и браузерная галерея.
В №03 заметно сильное мерцание каменных боковин; в №06 и №10 меняется рисунок
кладки, в нескольких вариантах появляются потёки за верхнюю грань. №08 имеет
сильную пульсацию яркости кислоты. Это исходный результат генерации: кадры не
ретушировались. Названия обозначают задумку, а не гарантированное исполнение.
Неподвижность блока, художественный стык и пригодность для игры не приняты.

Первый кадр каждого клипа сохраняет alpha и все видимые пиксели входа.
PixelLab изменил RGB 116 полностью прозрачных пикселей: это честно отмечено
как несовпадение сырых RGBA/PNG, исходные байты API оставлены без исправлений.
Последний кадр ни одного клипа не совпадает с входом по RGBA; эта побайтовая
проверка сама по себе не доказывает видимый скачок. Стык нужно смотреть в цикле.

Экспортёр принимает только `completed` и проверяет соответствие ID принятому
заданию. Исходные PNG пишутся побайтно из API; локально собираются только
листы, GIF и галерея для просмотра. Длительность100мс/кадр (10FPS) — настройка
превью, не тайминг runtime. Метаданные каждого клипа сохраняют реальные
размеры/число кадров, SHA, расход и совпадение конечного кадра с входом.

```powershell
python docs/art/acid05-animation-20261103/export_pixellab.py
python docs/art/acid05-animation-20261103/validate_package.py --verify-raw
python docs/art/acid05-animation-20261103/build_gallery.py
node docs/art/acid05-animation-20261103/check_gallery.cjs
```

Повторная отправка по уже записанному submit-started запрещена; принятые
задания возобновляются через GET по сохранённым ID. Неопределённый POST
не повторять вслепую. prepare_requests.py не перезаписывает начатые запросы.
Секрет не хранится в Git, отчётах и промптах.

Godot/root import/full/core и ручные F5/zoom/DPI этим арт-пакетом не проверяются.
Этот пакет хранит исходные варианты и проверки их генерации. Последующее
внедрение01 имеет отдельный отчёт; новые генерации автоматически не начинаются.
