## Как показано

Три исходных PNG128² взяты из [выбранной B](../archer-idle-variants-20261014/README.md).
Для B1 полная высота alpha≥128 составляет51.840026784 условных px — ровно90%
высоты текущего статичного Защитника57.60002976. Масштаб одинаков по обеим осям.
Тот же масштаб и позиция применяются к B2/B3: высота B2 больше из-за исходного
движения, покадрового выравнивания/стабилизации нет.

Защитник: текущий `defender_new.png`, crop(89,206,1034,966), нативный показ77×72,
Sprite scale0.0745342 и ArtRoot0.8 из `art_trial_unit.tscn`. Его позиция сохранена.
Для первой примерки ось тела лучницы x64 и нижний край B1 y117 поставлены в
(-5,5.48802976) относительно центра тайла. Это **предварительная посадка**,
сверенная визуально, а не универсальный/утверждённый игровой anchor.

Поверхность — текущий trial grass A из `grass_reference_v3`: ромб128×96,
UV и tint(0.79,0.8,0.75) из `art_trial_tile.tscn`. Canvas рисует два UV-треугольника;
это отдельный просмотр верхней плоскости, без боковин, сцены, камеры и HUD Godot.
Nearest-показ, исходные PNG встроены в HTML побайтно. Позы/alpha/гамма персонажей
не редактировались; новых генераций, теней, света или интеграции нет.

Визуальное наблюдение ведущего: лучница читается более фронтально, особенно по
развороту корпуса и небольшой разнице высоты стоп. Это оценка для обсуждения,
не измерение угла камеры и не решение пользователя об исправлении.

## Проверка и продолжение

`node build.cjs` пересобирает HTML/manifest (sharp), `node capture.cjs` снимает
PNG (Playwright+Chrome). Пакеты доступны в bundled Node через NODE_PATH;
альтернатива — SHARP_MODULE/PLAYWRIGHT_MODULE с абсолютными путями модулей.
HTML автономна, открывается без сборки. Проверены загрузка, три кадра, оси,
SHA256 пяти источников; оба масштаба просмотрены. Игровые файлы не менялись.
Независимое ревью технического пакета — APPROVE; замечаний нет.
Godot/full/core/F5/editor/DPI/GPU не запускались, арт-приёмка открыта.
Отчёт закрытия: `test_reports/archer-on-tile-20261014/REPORT.md`.
