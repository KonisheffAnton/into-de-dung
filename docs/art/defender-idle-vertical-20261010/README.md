# Idle: только вертикальное движение деталей

2026-10-10, base `fe506d93cb7e6b69d9c826bb7c187697b42faa74`, main, без push.
U: в [покачивании](../defender-idle-sway-20261010/README.md) сложные движения
дают артефакты. Следующая проба должна двигать конечности и детали только
вверх-вниз, с допустимым небольшим запаздыванием. [ART_DIRECTION](../../ART_DIRECTION.md)
владеет направлением/приёмкой; [GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md)
фиксирует PixelLab как инструмент анимации.

## Задание

Один запрос `/v2/animate-with-skeleton-v3`,12 поз, seed20261012. Вход128×128
и18 исходных суставов переиспользованы из предыдущей пробы дыхания.
`prepare-request.cjs` задаёт только Y; X и порядок глубины каждого сустава
строго постоянны. Голова/шея поднимаются до3px на вдохе. Обе руки (плечо,
локоть, кисть) перемещаются целыми группами на ту же величину с задержкой
в одну позу —200ms. Внутренняя геометрия каждой руки сохраняется во входе;
таз, колени и ступни фиксированы. Новой оценки скелета нет.

В prompt прямо исключены боковое движение, покачивание, сгибание, скручивание
и поворот. [Проверка входных поз](pixellab/pose-validation.json) описывает
запрос, но не гарантирует соблюдение сгенерированными картинками.
Запрос без ключа и изображения base64 — `pixellab/request.json`.

## Предпросмотр

`prepare-preview.cjs` сравнивает предыдущие12 поз покачивания и новые12 поз,
по200ms каждая; одинаковый цикл2.4s. С исходных128×128 удаляются только
16px прозрачного поля до96×96. Позы не дорисовываются, не выравниваются
и не интерполируются. Общий масштаб80%, увеличенный показ×4, внизу
приблизительные размеры камеры75/100/125%. Нужен модуль Sharp в `SHARP_MODULE`.

[Сравнение](comparison.gif): слева прежнее покачивание, справа вертикальная
проба. [Все12 поз](filmstrip.png), [петля96×96](idle-native.gif),
[хеши и свойства кадров](pixellab/frames-validation.json).
PixelLab вернул12 PNG128×128; фактический usage3generations, charged=true.
Оба GIF содержат12 кадров по200ms, цикл2.4s; alpha внешнего поля нулевой.
Стык12→01 меняет787RGBA/115alpha-пикселей, внутренние переходы —1–1065RGBA/
0–178alpha. Часть соседних поз почти одинаковая; пиксельная дискретность
и цветовое мерцание требуют визуальной оценки, числа не доказывают плавность.

Независимое ревью **APPROVE как изолированной пробы**. В выходных PNG клинок
и основная форма щита движутся вертикально, без заметного поворота/бокового
дрейфа; контуры обеих стоп неизменны. Заметной деформации щита/меча на ленте
не обнаружено. Небольшие изменения края предплечья и RGB-мерцание сохраняются.
P3:01→02 почти неподвижен,02→03 значительно крупнее; подобные пары могут
давать ступенчатый ритм. Художественная приёмка и игровой экран не проверены.

Игровой PNG/масштаб80%/гаммаА/посадка сохранены. Это отдельная проба,
runtime не меняется; Godot/tests/F5/Editor/DPI/GPU и замеры не запускались.
Финальная приёмка U, интеграция/lifecycle/reset/restore и остальные действия
бойца открыты. Тени/динамический свет не добавляются.
Отчёт: `test_reports/defender-idle-vertical-20261010/`.
