## Источники и границы

Созданы встроенным image_gen:12 вызовов,10 результатов. Для04 два запроса
с иглами не вернули изображение (HTTP400, отклонение системой безопасности
провайдера). Вместо этой задумки создан вариант с рифлёными конусами по паре01.
Остальные используют [каменный эталон](../current-tile-reference-20261103/tile.png).
[Точные итоговые промпты](prompts.json), [отклонённые запросы](rejected-attempts.json),
[исходные пути, SHA, размер и alpha](sources.json) сохранены.

Все десять PNG скопированы побайтно, без ручной ретуши, обрезки, перекраски
и дополнительной пикселизации. Некоторые изображения сохраняют мягкий внешний
ореол провайдера; размер холста и прозрачность различаются. Камень между
состояниями визуально близок, но AI-рисунок не доказывает пиксельного совпадения.
Число гнёзд в промпте не гарантирует фактическое число; состояние и расположение
сверяются по изображению. Полный тайл и шипы помещаются в кадр.

Это парные концепты; для игры потребуются отдельные проверенные состояния,
посадка и анимация. [Правила ловушек](../../ENVIRONMENT_HAZARDS_V1.md) не менялись.
