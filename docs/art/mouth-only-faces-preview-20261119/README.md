# Только рот: примеры для людей — 2026-11-19

Пользователь попросил убрать полноценные лица, оставив рты, и сначала показать
примеры. Последнее уточнение: **лица монстров не трогать**. Здесь пять статичных
примеров человеческих классов: Воин, Щитоносец, Лучница, Разбойник и Маг.
Это направление для оценки; игровые ассеты и анимации не заменены.

[Лица: сейчас / только рот](faces-comparison.png) ·
[Полные персонажи](characters-preview.png).
В текущих примерах убраны глаза, брови и рисунок носа. Рот остаётся читаемым;
волосы, уши, бороды, капюшоны и наружный силуэт сохраняют узнаваемость.
У Мага сохранён один исходный рот в бороде, без дополнительной черты над ней.
Художественная приёмка этой стилистики остаётся за пользователем.

## Источники и границы

Исходники — фактические `still.png` текущих игровых пресетов, а не предыдущий
эксперимент со сборным телом. [references.json](references.json) связывает
каждый пример с исходным PNG и `skin.tres`. Выбор класса/скина задаётся
`scripts/demo/character_skin_catalog.gd`; ресурс используется
`scripts/demo/battle_character_skin_visual.gd`, включая портретный still.
Выбран один облик каждого из пяти классов; альтернативный `grey_bastion`
и остальные кадры клипов не перерабатывались.

Итоги в `edits/` — полные RGBA PNG256×256. Все пиксели вне финальной маски
лица совпадают с исходником, включая скрытые RGB. Исходный канал alpha сохранён
целиком, поэтому край вырезанного спрайта и его форма не меняются.
Игровые `assets/`, ресурсы, сцены и код не редактировались. Монстров в итоговом
листе и в `edits/` нет; их игровые PNG остались прежними.

## Получение изображений

Все новые черты лица нарисованы PixelLab. Первые обычные правки `edit-image-pixen`
меняли также детали вне лица; они не выбраны. Финальные участки получены через
`inpaint-image-pro-flash` с бинарными масками: первый на256×256, остальные
на нативных вырезках64×64 без увеличения входа.

`request-masks/` — маски, переданные провайдеру. `masks/` ограничивают выбранные
пиксели внутренней областью исходного силуэта: минимум alpha в окрестности3×3
не меньше240. Порог учитывает фактическую alpha253–254 внутри исходных PNG.
Это исключает светлые артефакты генератора на полупрозрачном контуре.
Сборка копирует выбранные RGB провайдера без изменения их цвета и оставляет
исходную alpha в каждом пикселе. Локальной дорисовки глаз, кожи или ртов нет.
Искомое изображение и исходник используются в монтаже с правильной alpha;
крупные лица увеличены nearest4×, полные спрайты — nearest2×.

[selection.json](selection.json) хранит координаты, маски и SHA256;
[provider.json](provider.json) — все запросы без base64/секретов, usage,
выбранные и отклонённые попытки. Сырые ответы и невыбранные изображения:
`D:/Codex/home/generated_images/mouth-only-faces-preview-20261119/`.
Один предварительный вариант монстра был получен до уточнения пользователя;
после уточнения он исключён, дальнейших запросов для монстров не было.

## Проверка и воспроизведение

```powershell
python docs/art/mouth-only-faces-preview-20261119/build_preview.py
```

Нужны Python/Pillow и Arial из Windows. Сборка использует файлы пакета,
не обращается к провайдеру и не расходует генерации. Все входы проверяются
до записи: пять человеческих классов, SHA, размеры, границы, бинарные маски,
неизменность вне маски провайдера и исходная прозрачность.

[Проверка пикселей и монтажей](art-validation.json) ·
[Отчёт этапа](verification.json) · [Независимое ревью](review.md).
Числовые проверки не заменяют художественную приёмку. Godot, full/core,
F5/Editor/DPI и игровые performance-проверки не запускались: это статичная проба.
Массовый перенос на клипы/облики и внедрение не начинать самостоятельно.
Предпочтение прежнего удара со сборным телом этим этапом не меняется.
