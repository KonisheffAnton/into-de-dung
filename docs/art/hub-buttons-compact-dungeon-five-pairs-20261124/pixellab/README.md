# Пять компактных данжевых концептов — PixelLab

Задача `hub-buttons-compact-dungeon-five-pairs-20261124`, base commit `f7c2f79aefc43df77aabb220591718ac293ce660`. Это визуальные варианты; runtime-интеграции нет.

Отправлено ровно пять PixelLab Pro jobs через `/v2/generate-image-v2`, с точными prompts из `briefs.json`, размером 688×384, `no_background=false` и двумя reference images в заданном порядке: G-D01 для врат/ключей, затем G-D03 для инструмента искателя. Официальная схема разрешает до четырёх reference images. Все пять jobs завершены; списано 25 generations за job, 125 всего. Job IDs, exact prompts, sanitized requests, usage и SHA-256 находятся в [manifest](receipts/manifest.json) и пяти [receipts](receipts/).

Сырые запросы с двумя Base64 references и полные ответы API лежат вне Git в `test_reports/hub-buttons-compact-dungeon-five-pairs-20261124/pixel-raw/`. Санитизированные receipts не содержат Base64 или секретов. Автоматических повторов не было.

## Визуальная проверка

Декоративные элементы и рамки в целом заметно компактнее, чем в D01/D03: кнопки сохраняют сухое матовое дерево, а ключи и инструменты встроены в углы или небольшие маркеры. Во всех пяти изображениях видны четыре вкладки, три карточки отряда и три героя во дворе. Мелкие подписи при размере 688×384 остаются ограничением; не все контролы и метки выполнены точно в каждом варианте.

| Вариант | Наблюдение |
| --- | --- |
| C01 — тонкая дверная рама | Петли и ключевой маркер читаются, рамы легче D01; подпись «Дополнительно» отсутствует. |
| C02 — врезанный ключ | Ключевая деталь встроена в активную вкладку, но по бокам всё ещё висят два заметных фонаря. |
| C03 — записки искателя | Карта и небольшие угловые детали сохранены; рамки выглядят тоньше, чем у D03. |
| C04 — шнур и фонарь | Компактная рамка, но большая пустая светлая плоскость занимает часть двора; кирка и фонарь крупнее заданного мини-акцента. |
| C05 — ключ и маршрут | Самый сдержанный вариант; ресурсная полоса расположена над вкладками, центр двора упрощён. |

Все изображения сохранены как получены, без постобработки.
