# Очистка деталей двух диорам — 2026-10-18

[Сравнение до/после по участкам](gallery.html).
Результаты: [яркий](diorama-bright-clean.png) / [приглушённый](diorama-muted-clean.png),
1672×941. Новые версии сохранены отдельно, в игру не внедрены.

U попросил пройти обе диорамы по частям и убрать признаки генеративных артефактов.
Ведущий и reviewer разобрали семь областей; [карта замечаний](audit.md).
Пять последовательных правок сделаны на приглушённой версии, затем очищенные
формы перенесены в яркую палитру по цветовому фрагменту прежнего яркого изображения.
Так обе версии получили одинаковые основные исправления.

| Проход | Результат | Изменение |
|---|---|---|
| 01 | [Гора](muted-01-mountain.png) | Плоскости башни, каменные стыки, скала и водопад |
| 02 | [Запад](muted-02-west.png) | Две крыши/фасады, связные обломки лодки |
| 03 | [Остальные дома](muted-03-houses.png) | Три крыши/опоры/проёмы, труба переднего дома, лишний предмет на коньке |
| 04 | [Предметы](muted-04-workshop.png) | Мост, наковальня со слитком, ящики, лавка и посуда |
| 05 | [Приглушённый итог](diorama-muted-clean.png) | Пена/волны, растительность и случайные контрастные точки |
| 06 | [Яркий итог](diorama-bright-clean.png) | Яркая палитра на очищенной композиции |

Сохранены широкий кадр, расположение ориентиров, полуразрушенные дома и башня,
отсутствие входа в башню и наружных лестниц на горе. Нижняя пещера и маг у костра
остались. Группа8, кузнец, продавец и покупатель не возвращены. Их прежние места
по-прежнему хранятся в [пакете удаления фигур](../hub-diorama-people-cutout-20261018/README.md);
эти координаты описывают прежние оригиналы, а не точные маски новых изображений.

[source-bright.png](source-bright.png) и [source-muted.png](source-muted.png) —
побайтные копии предыдущих фонов. Шесть вызовов встроенного ImageGen; все выходы,
промпты и входные цепочки сохранены в [provenance](provenance.json).
Увеличенные фрагменты — диагностические crop/nearest references, не ручная
перерисовка. Выходные PNG после генерации не обрабатывались. Usage/cost неизвестны.

ImageGen может менять мелкие детали и за пределами названной области; точная
попиксельная идентичность, ручная ретушь каждого пикселя и готовность к слоям/
анимации не заявляются. Это наблюдаемое уменьшение перечисленных артефактов,
не гарантия отсутствия всех признаков генерации. [Ревью](review.md),
[проверка файлов/источников](validation.json). Художественная приёмка за U.
Runtime/механика/HUD не менялись; Godot/full/core/F5/editor/DPI/GPU не запускались.
