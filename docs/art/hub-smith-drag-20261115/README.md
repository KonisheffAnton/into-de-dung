# Кузнец: перетаскивание экипировки

2026-11-15. Интерактивная демонстрация принятого UI; игровой код не менялся.
[Исходник для visualize](hub-smith-drag.html). Правила — [план §4](../../HUB_DESIGN_PLAN.md#4-проектирование-экранов).
Предыдущий [макет и выбор U](../hub-smith-preview-20261115/README.md).

В начале броня Брана снята: перенести кольчугу на значок брони, затем кожаный
доспех туда же (кольчуга возвращается в инвентарь), затем значок надетого доспеха
обратно в область инвентаря. [Надевание](drag-equip.png), [результат замены](drag-replaced.png),
[снятие](drag-unequip.png). Все вещи остаются видимыми в общем инвентаре;
маркер владельца отличает надетое от лежащего на складе.

Перенос начинается после8px движения. Копия значка следует за указателем,
подходящие цели подсвечены, текст сообщает действие/причину отказа.
Исходная вещь остаётся на месте до принятого отпускания. Снятие у другого героя
остаётся отдельным действием. Escape, отпускание вне цели, pointercancel,
потеря захвата/фокуса, смена героя/фильтра/внешнего UI-state отменяют перенос;
клик после drag подавлен, обычный следующий клик и клавиатурные кнопки работают.
Пустой слот не переносится, свой слот даёт no-op. Ошибочный класс/слот/владелец
не меняют экипировку. Состояние меняется локально, сохраняется через widgetState v2.

Условные имена/баланс/предметы и прежняя фигура Воина не стали новым игровым
контентом. Ремонта нет. Дисковая запись, её сбой/retry и Godot-интеграция не
моделируются и не проверялись. Этот макет не заменяет будущие игровые проверки.

Проверки: JS parse; standalone headless Edge21/0 прежних сценариев и27/0
новых сценариев с реальным mouse pointer: надевание/замена/снятие, отказы,
отмена, no-op, восстановление/смена контекста, отсутствие двойного клика,
клавиатурный паритет, сохранность9 предметов, очистка временных подсветок.
Геометрия1024/736/320 проверена прежним набором; три desktop-кадра просмотрены.
Отчёт и независимое ревью: `test_reports/hub-smith-drag-20261115/`.
Ручная приёмка, физический touch, экранный диктор, OS-DPI и performance не проверены.
Godot/import/full/core/F5 не запускались; старые игровые gates не повторены.
