# Компактный низ HUD и карточка по ПКМ — 2026-11-08

Реализация по U, main, base `ad8cf7c349705231d74fa488ac856b0348da6adc`.
`Status` вынесен из вертикальной раскладки поверх нижнего края поля. Удалён
пустой слот44px над картами; фиксированные Hint/Inspection сохраняют геометрию
при появлении/исчезновении статусов. Справа сообщение ограничено карточкой.
Карточку открывает только короткий ПКМ по фигуре. ЛКМ выбирает союзника либо
выполняет обычную атаку по врагу; перетаскивание ПКМ двигает камеру.

Точное поведение принадлежит [HUD](../../BATTLE_HUD_SCENES_V1.md) и
[тактическому вводу](../../TACTICAL_BATTLE.md). Механики, гамма и ресурсы арта
этим изменением не затронуты.
