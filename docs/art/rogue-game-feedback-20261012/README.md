Base `d16bd004a5ab91a44e33965fc8515f16106f388b`, main. Пользователь поручил ускорить
смерть и уложить финальную позу в изометрию, сделать развод кинжалов шире/агрессивнее,

  прежний стабильный возврат, стойка. Тайминг200/350/60/120/240ms=0.97s.

  13×100ms=1.3s вместо2.6s. Тело направлено от ног сверху-слева к голове
  снизу-справа; видны верхние плоскости. Вражеское отражение штатное.
- ArtRoot0.73 вместо0.8, Sprite2D0.25 и опора(-64,-94) прежние. При тайле128×96
  Rogue bbox80×73..74.25 native даёт58.4×53.29..54.20; Defender77×72 в обычной
  фазе при0.8 даёт61.6×57.6. Обычный силуэт меньше примерно на5.2% по ширине,
  5.9–7.5% по высоте. Сравнение противоположных крайних фаз дыхания не определяет
  этот диапазон: Defender достигает75 native по высоте. Picking следует ArtRoot.

`capture-game.gd` рисует копии настроенного штатной сценой ArtRoot с её материалами
на игровом тайле без HP/StatusHud; итоговые экранные пиксели увеличены×2.
Это диагностический рендер, не ручной F5 и не новая сцена игры.

Аудит — buff-palette-correction.json. В D3 локальных цветовых изменений нет.
`quantized-frame-*` — пробы упаковки экстрактора, в manifest не используются.

## Воспроизведение и границы

`provider.ps1` отправляет ключ DPAPI только api.pixellab.ai; ключ не хранится в
пакете/логах. Повторный submit с существующим submission-attempt запрещён.
request/result/extraction сохраняют исходные запросы и результаты; повторять
генерации для проверки пакета не требуется. `build-buff.py`, затем
`build-previews.py` пересобирают B1/просмотры из сохранённых PNG. Manifest фиксирует
SHA каждого выбранного источника; validation.json проверяет GIF по кадрам5/5 и13/13.

Игровую сборку проверяет `python tools/art/build_rogue_animation_assets.py --check`
(bundled Python с Pillow). Полные результаты и игровые PNG —
`test_reports/rogue-game-feedback-20261012/REPORT.md`. Idle/still, механики,
guarded-trigger, after/generic-тело, падения, прочие классы и lifecycle прежние.
Новый corpse.png — копия финального PNG как артефакт, отдельного отрисовщика тела нет.
Одежду/новые способности/другие анимации этот этап не начинает.
