# Резкость чисел полос — 2026-11-07

Исправление замечания U о размытых цифрах после проработки полос.
Base: main `ef72c0a04d45da97f5f3690ac059ee791b805460`.

Прежний рисунок масштабировал сглаженный Jersey20 вместе с полем и использовал
полуцелую baseline. Сейчас только цифры HP/брони растеризуются в целом экранном
кегле и рисуются в целых координатах без сглаживания. Общий ресурс шрифта
урона/HUD не изменён; размер/цвет/рамка полос и формат количества прежние.
Контракт — [показ ресурсов](../../BATTLE_PRESENTATION_REWORK.md).

Новая проверка измеряет промежуточные смешанные пиксели внутри чёрного текста
на полном/пустом треке обеих фракций, включая дробный масштаб/сдвиг. Прежняя
проверка наличия чёрного штриха оставлена, но одна она размытость не обнаруживала.
Машинный отчёт и отрицательный контроль прежнего кода:
`test_reports/vitals-crisp-numbers-20261107/validation.json`.

Проверены только записанные в отчёте сценарии; ручные F5/DPI/performance и
художественная приёмка U остаются открытыми. Full/core не запускались.
Настройки шрифта и преобразования сверены с первичными API:
[FontFile](https://docs.godotengine.org/en/stable/classes/class_fontfile.html),
[CanvasItem](https://docs.godotengine.org/en/stable/classes/class_canvasitem.html).
