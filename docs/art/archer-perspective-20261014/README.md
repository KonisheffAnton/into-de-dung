## Idle на новой основе

По следующему поручению U отправлен один запрос PixelLab `animate-pixminimax`.
Вход [reference-128.png](pixellab/reference-128.png) — равномерное nearest-
уменьшение всего нового RGBA до128², без порогования alpha/ретуши/смены позы.
[Запрос](pixellab/request.json), [промпт движения](pixellab/prompt.txt),
[параметры подготовки](pixellab/request-manifest.json).

First=last,12requested, seed2026101407, view=high top-down,
direction=south-east, enhance_prompt=false, drift_threshold=0.
Текст требует одного едва заметного вдоха/выдоха, максимум1px в груди,
без переноса/выпрямления тела; стопы/голова/руки/лук должны оставаться на месте.
`drift_threshold` регулирует цветовой дрейф, не пространственную фиксацию.
Поля сверены с текущей [OpenAPI](https://api.pixellab.ai/v2/openapi.json);
копия хранится в ignored-отчёте этапа. API-ключ только из DPAPI, без Git/логов.

Получены13PNG128² при12запрошенных; сохранены все13 без перекодирования.
Job `24608556-7368-4b02-a508-2920c7d8353c`, billing_usage=2 генерации подписки,
usd=0. Повторных запросов не было.

- [Новая проба рядом с прежней B](idle.html): пауза/перезапуск/перемотка,

Показ использует **целые кадры02–13**,12 поз за2.6s. Кадр01 совпадает с
видимым RGBA входа и содержит3069полупрозрачных пикселей, остальные12 имеют
бинарную alpha. Пропуск01 устраняет скачок прозрачности, не ретушируя PNG;
в архиве он сохранён. Шов13→02:374видимых RGBA/6alpha≥128 различий вместо
3088/20 при13→01. Это улучшение технического стыка, не гарантия незаметного шва.
HTML показывает равные интервалы; GIF220ms×8+210ms×4=2600ms из-за шага10ms.
GIF ограничивает палитру/alpha; для точных цветов и прозрачности использовать HTML.

**Требование тихого дыхания с неподвижными стопами и луком пока не выполнено.**
Высокий ракурс узнаваемо сохраняется, но верх силуэта поднимается сy25 доy21
при том же нижнем крае106. Положение/scale показа фиксированы, стабилизации нет.
В приблизительных ROI максимум изменений alpha≥128 относительно входа:
лук+рука247px, дальняя стопа33px, ближняя2px. Эти счётчики не являются
величиной смещения или точной сегментацией частей. Голова/лук/корпус ещё движутся.
Это отдельная неутверждённая idle-проба, а не готовое исправление до критерия.

## Воспроизводимость и границы

Bundled Node+sharp+Playwright: `node build.cjs`, `node capture.cjs` — статика;
`node prepare-idle.cjs` готовит API-вход без отправки. `extract-idle.cjs`
извлекает PNG из сохранённого окончательного job-ответа без перекодирования;
`idle-preview.cjs` собирает HTML/GIF; `measure.py` измеряет с Pillow.
NODE_PATH задаёт bundled node_modules либо SHARP_MODULE/PLAYWRIGHT_MODULE.
Готовые HTML автономны и не требуют API или скриптов отправки.
Статика/HTML/контролы/13PNG против ответа/GIF2600ms — технический PASS.
Просмотрены кадры и оба масштаба; полная художественная приёмка не заявлена.
Независимое ревью технического пакета — APPROVE только как неутверждённой
пробы; критерий движения не выполнен. Ручное проигрывание/F5 не проверялось.

Все прежние пробы и исходная B сохранены. Позы/alpha вручную не исправлялись.
Godot/full/core/F5/editor/DPI/GPU не запускались; игры/сцен/ресурсов не меняли.
