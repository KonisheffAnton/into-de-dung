# Предпросмотр двух полных плиток

[Локальная галерея](gallery.html) показывает оригинальные плитки 24 и 29 рядом с диагностической сборкой. Число движущихся групп читается из текущих данных и выводится в галерее. Пока выбраны не все группы, прочие остаются исходной статикой; при полном покрытии галерея назовёт результат кандидатом для выбора, а не принятым или внедрённым артом.

`build.py` читает выбранные raw PNG PixelLab и проверяет их SHA, нативный crop, исходный core, отсутствие alpha на границе crop и выход контура не более чем на 4 нативных пикселя. Каждый raw RGBA накладывается на исходную плитку 1254² в целочисленной ROI без деформации, перекраски или промежуточных поз. Движение фазируется по номеру группы: 96 слотов по 80 мс, целое число проходов каждой сохранённой последовательности (2–8). Карта выбора и фазы записаны в [manifest.json](manifest.json).

Для каждого стиля сохранены 96 просмотровых кадров 256², нативные снимки слотов 0/24/48/72/96 и [общий контакт](contact-both-256.png). 256² файлы — только уменьшенные просмотровые изображения. Галерея рисует оригинал и raw кадры на canvas 1254² в исходных координатах; переключатель задаёт CSS размер 256 или 512 px.

Режим **«Поверхность крупно»** показывает одинаковую нативную область `[x=288..966, y=233..746)` размером 678×513 на обеих плитках. Она охватывает весь верхний ромб с вершинами `(627,245), (954,493), (627,734), (300,493)` и запасом 12 px. Источник вида — соответствующий canvas полной плитки после той же RGBA-сборки; `drawImage` копирует область 1:1 без новых поз, деформации и перекраски. Это только способ просмотра, не экспорт рабочего ассета.

Проверены все 96 игровых слотов и отдельная нативная сборка точки 7680 мс: она совпадает с точкой 0 точно. Вне объединения входных масок с запасом 4 px исходные пиксели не меняются, crop clipping не найден. Видимый переход 95→0 измеряется отдельно для каждого стиля; он может отличаться, даже когда точка 7680 мс точно равна точке 0. Текущие числа и SHA фиксированного `selection.json` записаны в manifest и отчёте.

`manifest.json` и отчёт содержат метрики каждого из 96 переходов в нативном размере и при 256 px, изменение alpha масок raw наложений, яркость области эффекта и выделенного core в каждом слоте, минимумы/максимумы и наибольший соседний скачок. Контакты `fire24|29/worst-alpha-contact.png` и `worst-visible-contact.png` показывают до/после худшего перехода целиком и в нативном crop. Это только измерение существующих кадров, без постобработки анимации.
