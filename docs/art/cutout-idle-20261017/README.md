## Показ и движение

Слева неизменный утверждённый статичный Защитник; тайл и посадка взяты из
assets/art_presets/approved/grass_defender_v1/preset.json. Поверхность128×96,
Защитник в(-45,-56), масштаб0.25. Новые фигуры подогнаны примерно под72px
общей высоты, ось корпуса x=-2, низ ближней стопы y=17. Это новая примерка,
не утверждённые игровые anchors и не перенос универсальной точки по bbox.

Три жёсткие части: ноги/таз, корпус вместе с руками и оружием, голова.
Цикл3.2с: корпус поднимается максимум1px, голова0.6/0.65px с небольшим
запаздыванием; ноги неподвижны. Каждая часть один раз равномерно масштабируется
для показа; затем перемещается без перерисовки. Исходные RGB/alpha не правятся.
На ×4 движение квантуется до четверти логического пикселя, на ×1 — до пикселя.
Оружие движется с корпусом; отдельной артикуляции рук и ткани в этой пробе нет.
Страница имеет паузу, фазу, скорость и показ разнесённых частей.
Размеры ×1/×4 относятся к Canvas до масштабирования страницы браузером.

## Происхождение и воспроизведение

8 вызовов встроенного ImageGen: два первых атласа, правка лица B, затем
две правки на изометрию, усиление поворота A по ревью и две финальные правки
высоты камеры по уточнению U. Предыдущий диагноз о развороте не был причиной
последнего пользовательского замечания; не продолжать менять yaw вместо высоты камеры.
Ранние атласы сохранены, но фронтальные варианты не являются финальными.
Точные запросы: requests.json, correction-b.json, executed-isometric-requests.json,
correction-a-stronger-isometry.json, camera-elevation-requests.json.
provenance.json связывает результаты с provider PNG и точными входами правок.
Все8 PNG сохранены побайтно. Расход ImageGen инструмент не сообщает.
PixelLab не использовался; движения создаёт отдельный Canvas-просмотрщик.
Это ограниченная проба перекладки по текущему поручению, не общая замена
прежнего процесса производства анимаций через PixelLab.

Node с доступными sharp/playwright:

```powershell
node configure.cjs
node build.cjs
node capture.cjs
node validate-sources.cjs
```

configure.cjs задаёт крепления; rig.json — полученная конфигурация.
build.cjs встраивает все изображения в переносимый preview.html.
capture.cjs сохраняет GIF/снимки и validation.json. GIF может объединять
одинаковые соседние кадры, сохраняя длительность3.2с.
Проверка provider bytes требует native-файлов из provenance; просмотр — нет.

Проверки и независимое ревью: [review.md](review.md), validation.json,
source-validation.json. HTML/Canvas не является Godot-рендером. Godot/full/core/F5,
игровое внедрение, ручная DPI/GPU-матрица и художественная приёмка не выполнены.
Следующий шаг — отзыв U по A/B и движению. Другие анимации/интеграцию не начинать.
