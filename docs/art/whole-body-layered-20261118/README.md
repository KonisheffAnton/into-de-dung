# Цельное тело, оружие и шлем

Переработка по исправлению U2026-11-18. Предыдущая проба с вращением отдельных
частей тела отклонена пользователем как кукольная. Броню нельзя делить на
нагрудник, руки и ноги: **каждая поза тела — один цельный рисунок в броне**.
База этапа `4acb4f9177e31ee872fe4c58a745cbe6f31b1b66`, `main`.
В игру ничего не внедрено.

[Просмотр](gallery.html) · [движение с экипировкой](overview.gif) ·
[только цельное тело](body-only.gif) · [смена предметов на паузе](swap.gif).

## Три слоя

1. **Тело в броне** — полный PNG256×256 вместе с головой, руками, ногами,
   одеждой и обувью. Одна операция рисования на кадр, никаких отдельных
   спрайтов конечностей или деформации суставов.
2. **Оружие** — меч, топор или пусто, по общей точке хвата.
3. **Шлем** — стальной или пусто, по общей точке головы.

Перчатки и сапоги не являются отдельными визуальными слотами. Они могут быть
нарисованы внутри цельного облика тела, но отдельные предметы инвентаря
не меняют этот рисунок. Прототип вообще не обращается к игровому инвентарю.

В текущем показе одно заново нарисованное тело в кожаном комплекте. Для него
доступны все сочетания меча/топора и шлема. Полный второй комплект не выдаётся
за готовый: подготовлены только [статический ориентир](inputs/body-heavy-reference.png)
и проба переноса трёх кадров. При фактической цене25 генераций за3 кадра
пользователю предложен выбор объёма. U2026-11-18 ответил: **«Сначала одно
цельное тело»**. Это текущий объём пробы; второй анимированный комплект
не входит в этап. Выбор объёма не является художественной приёмкой движения.

## Общая анимация

Новые цельные позы созданы PixelLab. Это покадровая анимация, а **не прежний
скелет из вращающихся частей**. Общая последовательность кадров и трек точек
хвата/головы переиспользуются всеми предметами. Варианты тела должны иметь
те же позиции в последовательности; они заменяют сразу весь PNG.

Локально задаются длительности, выбор готовых кадров, общая поправка положения
всей фигуры и привязки предметов. Пиксели выбранных кадров тела не меняются:
[происхождение](origins.json) фиксирует побайтное совпадение с PNG провайдера.
Небольшая поправка положения опирается на нижнюю область стоп; это единый
перенос всей фигуры, не анимация отдельных частей. Шлем привязан к найденной
области лица, кисть размечена в координатах целого кадра.

Кадр тела рисуется целиком один раз. Отверстие у точки хвата вырезается только
из изображения оружия, чтобы ручка не закрывала ладонь; тело не маскируется.
Переключение предметов не сбрасывает время или позу. Просмотр позволяет
скрывать каждый из трёх слоёв, останавливать движение и выбирать время.

## Происхождение и ограничения

Перерисовка тела — PixelLab `edit-image-pixen`; дыхание и удар —
`animate-pixminimax`. Первоначальный удар с лишними дугами сохранён как
[отклонённая проба](rejected/attack-effects.json). Проба смены полного костюма
использовала `transfer-outfit-v2`; [описание API](https://api.pixellab.ai/v2/llms.txt).
Полные запросы/ответы без ключей хранятся в
`D:/Codex/home/generated_images/whole-body-layered-20261118/`.
Публичный [журнал запросов](provider.json) хранит ID, параметры и расход.
Подтверждённый расход завершённых заданий —37 генераций, включая пробу
второго комплекта и невыбранные попытки. В ударе использована одна чистая
цельная поза из первого клипа; кадр с эффектом из второго исключён.
Две неудачные правки промежуточной позы не вошли в результат.

Статические предметы перенесены из предыдущей пробы с nearest-масштабированием
при экспорте. Они не рисуются вместе с телом в PixelLab. Художественная
приёмка движения, посадки шлема и хвата остаётся за пользователем.
Привязки к готовым кадрам требуют проверки при добавлении нового полного
костюма; техническое совпадение времени не доказывает совпадение анатомии.

## Воспроизведение

Из корня репозитория, после получения сохранённых результатов провайдера:

```powershell
python docs/art/whole-body-layered-20261118/export_body.py
python docs/art/whole-body-layered-20261118/build_preview.py
python docs/art/whole-body-layered-20261118/check_preview.py
```

Python/Pillow, установленный Edge для headless-проверки. Сам просмотр автономен
и не требует сети. Для проверки синтаксиса JS используется `node --check`.
[Браузерная проверка](browser-validation.json), [итог](verification.json),
[независимое ревью](review.md). Godot/full/core/F5/Editor/DPI и игровая
производительность не проверялись. Следующий шаг — отзыв; внедрение и новые
серии не начинать автоматически.

52 браузерных проверки PASS;29 позиций кадров ×6 сочетаний, прозрачные края,
целый PNG тела, независимость предметов, пауза/время/переключение слоёв.
Python compile и Node syntax PASS; независимое ревью APPROVE.
Общий цикл2920 мс. GIF-кодировщик объединил соседние одинаковые изображения:
в обзоре26 кадров, в показе тела25; длительности сохранены полностью.
