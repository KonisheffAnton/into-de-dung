# Объём тайлов и градиент — 2026-10-17

U: добавить существующим плоским тайлам объём снизу, стенкам — градиент
в духе Into the Breach. В реальной сцене floor/platform имеют нижний торец18px
при native128; верхние кромки прежние, две стороны темнеют к основанию и
различаются освещённостью. WALL сохраняет геометрию и получает градиент;
VOID без боковин. Новый свет/текстуры/логическая высота не вводятся.

- [Итоговое поле](battle.png),1600×1200: включает исправленную посадку Лучницы.
- [Сравнение](comparison.png): слева прежние грани, справа новые;
  строки — плоский пол, высокий уступ, отрицательная высота, стена, пропасть.
  У отрицательного уступа прежняя перевёрнутая боковина больше не перекрывает верх.
- [Аудит рендера](render_audit.gd), [проверки и независимое ревью](validation.md).

Верхние PNG/UV/цвет, проекция4:3, опора бойцов и круглые тени сохранены.
Старый surface_polygons продолжает задавать picking; добавленный нижний край
декоративный. Отдельный технический контракт —
[visual lifecycle](../../BATTLE_VISUAL_SCENE_CONTRACT.md#толщина-и-градиент-боковин-тайла).
Ручная художественная приёмка толщины/градиента открыта.

Аудит наследует capture-helper из соседнего Archer-пакета, поэтому запускается
после импорта текущего проекта. Команда: Godot `--path <project> --screen 0
--script <absolute>/render_audit.gd -- --output=<folder>`.
