# Сборный персонаж: движение и три видимых слота

Самостоятельная проба по запросу U2026-11-18, без внедрения в игру.
База `634a957077a25ce2dd5c403b84ca2bbd093ccc4c`, ветка `main`.

[Открыть интерактивный просмотр](gallery.html) · [четыре сочетания](overview.gif) ·
[сравнение с PixelLab](comparison.gif) · [смена на одной позе](swap.gif).

## Что выбирает пользователь

- **Броня**: нет / лёгкий / тяжёлый полный комплект. Один выбор одновременно
  меняет корпус, пояс, плечи, предплечья, бёдра и голени.
- **Шлем**: нет / стальной. Отдельно от брони.
- **Оружие**: меч / топор. Отдельно от брони и шлема.

Отдельные предметы «перчатки» и «сапоги» не отображаются и не имеют
переключателей. Кисти и обувь остаются фиксированной частью базового облика.
Внутреннее разделение изображений на части нужно для сгиба локтей и коленей;
оно не создаёт дополнительных слотов экипировки. Проба не меняет игровые
слоты, параметры вещей или формат сохранений.

## Движение

Одна функция `NaturalRig.pose(timeMs, mode)` определяет позу независимо
от экипировки. Общая анимация включает дыхание, приседание при замахе,
перенос таза, разворот корпуса, быстрый удар, продолжение движения и возврат.
Двухзвенные руки и ноги сгибаются в локтях/коленях; стопы имеют постоянные
точки опоры. Перспективная деформация груди и смещение плеч показывают
небольшой разворот. Это приближение объёма статическими деталями, не 3D-модель.

`NaturalRig.render` выбирает изображения полного комплекта поверх той же
позы. Смена оружия, брони и шлема на паузе сохраняет время и суставы.
Цикл «дыхание + удар» — 4 с, отдельный удар — 2 с. Просмотр позволяет
поставить паузу, двигать время, замедлять и показывать суставы.

PixelLab рядом — [готовый цельный клип лёгкого мечника](../modular-equipment-animation-20261118/preview/clips/light-sword/attack/clip.json).
Он служит ориентиром живости, а не источником отдельных сменных слоёв.
Совпадение силуэта и естественности с PixelLab **не утверждено**.
Общая дуга для меча и топора намеренна для проверки переиспользования каркаса;
это не финальные отдельные боевые анимации разных типов оружия.

## Источники и воспроизведение

28 статических PNG перечислены в [манифесте](assets/manifest.json).
Базовые части взяты из [предыдущей пробы](../layered-character-rig-20261118/README.md).
Два новых прозрачных атласа созданы встроенным `image_gen`:
[суставы/шлем](joints-helmet-atlas.png), [два полных комплекта](full-suit-atlas.png).
[Точные промпты](generation-prompts.json). Новые покадровые клипы не генерировались.
Общий выбор PixelLab для прочих анимаций остаётся в силе; эта локальная
проба общего каркаса отдельно поручена U.

Из корня проекта:

```powershell
python docs/art/natural-layered-character-20261118/prepare_assets.py
node --check docs/art/natural-layered-character-20261118/motion.js
python docs/art/natural-layered-character-20261118/build_preview.py
python docs/art/natural-layered-character-20261118/check_preview.py
```

Требуются Python/Pillow, Node для проверки синтаксиса и установленный Edge
по пути, указанному в `check_preview.py`. HTML самодостаточен, сеть не нужна.
Проверки и GIF используют тот же браузерный рендерер. Проверка запускает
Edge headless; игровые сцены, Godot и фокус ОС не затрагиваются.

## Проверки и остаток

[Браузерные проверки](browser-validation.json), [сводка этапа](verification.json),
[независимое ревью](review.md). Точный состав и ограничения — в этих отчётах.
27 браузерных проверок PASS; четыре сочетания проверены в125 точках цикла
(500 отрисовок). Дополнительно проверены1000 поз с шагом4 мс: ограничение
досягаемости кистей/стоп не включилось. Python compile и Node syntax PASS.
Сбой Edge после успешного DOM проверен отдельно: старые визуальные экспорты
удаляются, остаётся отчёт об ошибке. GIF обзор/сравнение содержат49 кадров
по сумме4 с: кодировщик объединил один повтор из50 исходных кадров.
Художественная приёмка остаётся за пользователем: естественность движения,
посадка полного комплекта, швы суставов, разворот, шлем и ощущение удара.
Пиксельные детали при вращении могут ступенчато менять контур; плоские части
не дают произвольного поворота персонажа. Godot/full/core/F5/Editor/DPI и
игровая производительность не проверялись. Следующий шаг — отзыв; внедрение
и новые серии автоматически не начинать.
