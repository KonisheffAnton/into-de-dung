## Подключение

В той же F6-сцене [art_trial_battle.tscn](../../../scenes/demo/art_trial_battle.tscn)
четыре цельных варианта верхней поверхности: крупный пучок, меньший пучок,
тихая земля с пятнами почвы и пара пучков. Они сохраняют объёмные формы и
приглушённую оливковую гамму. Это новая проба, не доказанное улучшение.
[Игровые PNG](../../../assets/art_presets/trials/grass_reference_v3/README.md).

[Сцена тайла](../../../scenes/demo/visuals/art_trial_tile.tscn) задаёт точную
верхушку128×96 и внутренние UV без прозрачной кромки. Нет дополнительной
подкраски/поворотов/зеркалирования. Код переключает видимость четырёх
вариантов по авторской таблице8×8:32 тихих,12 крупных,12 меньших,8 парных.
Небольшие отличия исходного цвета PNG остаются; бесшовность не гарантируется
одним совпадением геометрии и требует оценки рендера.
QuietSeam — тонкий полупрозрачный Line2D по ромбу клетки, как ориентир тихих
стыков на пользовательском поле. Это отдельная авторская геометрия без светлой
текстурной каймы; скрывается вместе с GroundSurface над void.

На этапе v3 новый союзный и прежний отражённый Защитники были сохранены;
preview/live/worker/queue/RNG/save, основной M3/№4 и F5 не менялись.
Следующее поручение подключило те же PNG к актуальному F5-бою и изменило
выборку спрайтов/экранную толщину QuietSeam: [масштабирование](../pixel-zoom-20261010/README.md).
Параметры manifest.json здесь описывают исходный этап v3.
Enter — начать, R — сброс; колесо/кнопки — масштаб, ПКМ — камера.

## Происхождение

Восемь вызовов встроенного image_gen: A по двум вложениям; B/C/D как изменения A
с полем для сверки гаммы. Первый проход сохранён в `first-pass/`. В его рендере
светлые пятна слишком часто повторялись; ещё четыре адресные правки убрали их,
сохранив пучки и пятна почвы. Итоговые PNG скопированы без иной обработки;
только Godot задаёт UV и геометрию.
[Точные запросы](requests.json), [размеры/SHA и параметры](manifest.json).
Книги повторно не сканировались: применены советы из [PIXEL_ART_GUIDE](../../PIXEL_ART_GUIDE.md)
о крупных формах, тоне, паузах и проверке игрового масштаба. Они не игровые контракты.
