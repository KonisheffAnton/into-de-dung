## Наведение и взаимодействие

Наведение/фокус выделяет группу мягким золотистым контуром; курсор показывает
возможность клика. Клик открывает просмотр выбранной анимации. Это действие
галереи; игровые команды найма/торговли/ковки здесь не подключены.
Можно переключить постоянное проигрывание на анимацию только при наведении.
Торговец и покупатель используют общий кадр и взаимодействие, сохраняя связь
исходной парной анимации. Пауза останавливает проигрывание.

## Устройство слоёв

| Слой | Источник | Размещение |
|---|---|---|
| Фон | точная копия соответствующего PNG1672×941 | без преобразований |
| Толпа | crowd-02, полный кадр256² | центральная дорожка |
| Кузнец | последний smith-03, полный кадр256² | пластина над существующей наковальней |
| Торговец | левая часть market-05, source rect0,0,144,256 | за прилавком |
| Передний план лавки | пиксели того же фона под маской | навес/стойки/прилавок перед торговцем |
| Покупатель | правая часть market-05, source rect144,0,112,256 | перед прилавком |

Разделение пары проходит в полностью прозрачном промежутке135..150 всех9кадров.
Обе части зеркально отображаются, чтобы лица были обращены друг к другу при
расположении покупателя слева от торговца. Исходные PNG при этом не изменены.
Масштабирование nearest; координаты и порядок слоёв — [placement.json](placement.json).
Это точная техническая вставка и трансформации готовых кадров, не генеративная
перекомпоновка. Существующее пламя кузницы/наковальни остаётся частью фона;
искры выбранного кузнеца сохраняют свой проверенный порядок после контакта.

`backgrounds/` — четыре независимых фона; `layers/` —27PNG; `foregrounds/` —
четыре RGBA-слоя перекрытий из точных пикселей фона; `previews/` —12статичных
контрольных кадров. Статичные PNG не заменяют интерактивную анимацию.

`scene-data.js` содержит настройки и битовые alpha-маски для попадания курсора
по видимым пикселям. Прозрачное поле вокруг персонажа не является кнопкой.
Маски подготовлены заранее, поэтому браузеру не нужно читать пиксели локального
canvas через getImageData. Галерея работает с локальными файлами без сети/fetch.

## Проверки и границы

[prepare.py](prepare.py) воспроизводит слои/контрольные PNG из исходных файлов,
не обращается к провайдерам. [assembly-validation.json](assembly-validation.json)
проверяет побайтную сохранность фонов/кадров, прозрачный промежуток пары и
нулевое изменение пикселей вне персонажей на12контрольных композициях.
[Отчёт](../../../test_reports/hub-diorama-layered-20261018/README.md) содержит
дополнительные проверки интерактивности, файлов и независимое ревью.

`validate.py` сверяет31исходный файл, все1 769 472бита alpha-масок, RGB переднего
плана, локальные ссылки и создаёт153проверочных попадания по реальным PNG.
`node validate-interaction.cjs` проверяет их, а также обработчики загрузки,
hover/focus, клика, паузы/шага и отказа fullscreen на модели DOM. Это проверка
логики, не запуск браузера: фактическое воспроизведение/рендеринг ещё не проверены.

Это локальный прототип взаимодействия и слоёв; игровые сцены и логика не менялись.
Приёмка размещения/подсветки за U. Новых Godot/full/core/F5/editor/DPI/GPU нет.
