## Идея и результат

Источник: контраст областей покоя/сложности (PDF19, печ.22), поиск крупных
форм до отделки (PDF26/114, печ.31/132). Применение ведущего: проверить
несколько связанных групп низкой травы и широкие паузы вместо одинаково
наполненных клеток. Это интерпретация для игры, не правило устройства тайлов.

**[proposal-01.png](proposal-01.png)** — один вызов встроенного image_gen;
точный [запрос](request-01.json), источник/размеры/SHA — [manifest](manifest.json).
Референс — [исходное чистое поле](../style-reference-20261009/scene-preview.png).
Книжные изображения генератору не передавались; PixelLab/Retro Diffusion не вызывались.

PNG просмотрен: появились крупные группы по краям и спокойный центр.
Ограничения: фактура напоминает пятна мха/камуфляж, светлый кант снова заметен;
ни качество травы, ни преимущество перед M3 не доказаны. Это промежуточная
композиционная проба, не готовый тайл и не новый рендер Godot. Точное совпадение
геометрии/фигур/посадки с референсом генератором не гарантируется.

**Не утверждён и не подключён.** Действует
[grass_defender_v1](../../../assets/art_presets/approved/grass_defender_v1/README.md).
При дальнейшем выборе художественные пятна не должны обозначать препятствия,
другую проходимость или новый тип поверхности; игровые границы должны читаться.
Новая реализация/генерация — по поручению. Игровые PNG и сцены сохранены.
