## Формат тела и предметов

Ровно три слоя: **цельное тело в броне, оружие, шлем**. Голова, руки, ноги,
перчатки, обувь и вся броня нарисованы внутри одного полного PNG каждой позы.
Отдельные предметы «перчатки»/«сапоги» не меняют внешний вид. Тело не разрезано
на детали, суставы локально не вращаются. В каждой позе рендерер выводит один
PNG тела, после чего прикрепляет меч/топор и шлем по общему треку привязок.

При смене предметов кадр тела и время остаются теми же. Перенос всей композиции
постоянен для клипа: автоматического центрирования стоп в каждом кадре нет,
чтобы сохранить движение корпуса и перемещение веса, нарисованные PixelLab.

## Доспех и движение

Основной визуальный ориентир — утверждённый
[Красный бастион](../../../assets/art_presets/approved/character_skins_v1/red_bastion/still.png):
компактные пропорции, читаемая голова, светлые стальные наплечники и наручи,
коричневая кожа, кремовые тканевые панели, красный шарф. Его PNG использован
как вход PixelLab для нового цельного тела без оружия. Дополнительные
просмотренные ориентиры и SHA256 перечислены в [style-references.json](style-references.json).
Статус утверждённого исходного облика не означает приёмку этой переработки.

Задание движения PixelLab: загрузить заднюю ногу, согнуть колени, развернуть
таз и плечи в замахе, затем перенести вес на переднюю ногу и провести руку
вперёд-вниз; погасить движение коленями и вернуться в исходную стойку.
Это описание задания, а не утверждение, что провайдер точно выполнил каждый пункт.
Естественность, хват и посадку шлема оценивает пользователь по результату.

Выбраны13 кадров дыхания и33 кадра удара. В одном исходном кадре удара
провайдер нарисовал белую дугу; этот полный кадр заменён цельным результатом
отдельной правки PixelLab. Остальные PNG сохранены побайтно. Затянутые
удержания поз сокращены длительностями. Дыхание1560мс, удар1550мс,
общий цикл3110мс. Всего использовано9 генераций PixelLab.
