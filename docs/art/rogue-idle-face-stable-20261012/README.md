# Разбойник — коррекция лица в idle, 2026-10-12

Только PixelLab создаёт кадры; исходная проба сохранена без правки PNG.

## Причина

В первом наборе голова сдвигается на1px на4→5/11→12. После выравнивания
остаётся изменение черт: ROI лица11×11 (native x53,y29) меняет31/36/38 пикселей
на5→6/8→9/9→10. Меняются глаз, светлая плоскость лица и подбородок.
Первое техническое ревью не обнаружило эту художественную ошибку.

## Коррекция

`edit-animation-v2` отказал HTTP400: при128×128 допускает максимум4 кадра;
12 за раз не принимаются, хотя OpenAPI допускает frames2–16 без этого условия.
Сделаны два HTTP-вызова одного отвергнутого запроса (первый обработчик не сохранил
тело ошибки); job ID нет, баланс перед повтором4892.8, расход не обнаружен.
Запрос/ошибка/схема сохранены в `rejected-edit/`, генерации результата там нет.

Вместо независимых групп кадров отправлен один цельный `animate-with-skeleton-v3`:
job `63d3908c-0ccb-4c44-b390-4d48e86360ed`,12 поз. Использованы прежний входной PNG
и18суставов разбойника. Все суставы головы/шеи, ноги и таз закреплены;
только плечи/руки двигаются по Y с амплитудой1px. В запросе явно запрещены
моргание, движение головы и изменение черт. Это входные ограничения, не гарантия
фактического лица. Новая оценка скелета/imagegen не вызывались.

`prepare-request.cjs` создаёт запрос; `extract-result.cjs` сохраняет только
completed PNG. Экспорт GIF — обрезка проверенной прозрачной рамки и nearest,
без дорисовки, выравнивания кадров или интерполяции.
Job completed:12 PNG128×128, charged3 generations. Все кадры проходят проверку
alpha0/255 и пустой рамки16px; оба GIF12×200ms, цикл2.4s. Node parse/export PASS.
