# Шесть биомов — оценочная комната24×16

U2026-10-28: расширить первую комнату ровно вшестеро и назначить каждому участку
один исходный биом. Ориентир — [исходные шесть панелей](../dungeon-room-refinement-20261027/reference-01.png).
Прежнее каменное подземелье дополнено заросшими руинами, льдом, вулканом,
пустынным храмом и болотом. По горизонтали координат сетки:01/02/03; ниже04/05/06.

[Промпты встроенного ImageGen](prompts.json) и [пути/SHA/размеры/регионы](sources.json)
содержат15 новых PNG. Источники скопированы побайтно в
[biomes_v1](../../../assets/art_presets/trials/biomes_v1/README.md).
Прежние четыре каменных PNG не изменены. Для вертикальных граней каждого биома
есть отдельная текстура; пропорции препятствий сохраняет равномерный scale.
Механический статус всех шести препятствий — обычная непроходимая WALL, без HP.

[Контракт](../../BATTLE_VISUAL_SCENE_CONTRACT.md#шесть-биомов-в-увеличенной-первой-комнате)
владеет геометрией, камерой и ограничением первой комнаты; [TESTING](../../TESTING.md)
владеет командами. Результаты: test_reports/biomes-showcase-20261028/validation.md.
Ручная художественная F5/движение/zoom/DPI-приёмка остаётся отдельной.
