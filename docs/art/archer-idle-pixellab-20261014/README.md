## Что отправлено

По новому поручению U выполнен **один** `animate-pixminimax`: clean PNG128 как
first/last,12 запрошенных кадров, seed20261014, no_background=true,
drift_threshold=0, enhance_prompt=false. Получено13 кадров128×128, включая вход.
Job `5c629c12-e56f-4ba6-abf6-340ac7637ef5` завершён; фактический расход —
**2 генерации подписки**, `billing_usage.usd=0`. Повторов не было.

API не принимает MP4/массив движения в этом endpoint. Ролик изучен локально,
движение передано текстом по пользовательскому пресету. Для13 motion-guides
`transfer-outfit-v2` ограничивает результат64px; это снижало бы детализацию.
[Сверка API и причина выбора](api-notes.md). Побуквальное/покадровое повторение
старого результата не заявляется.

`prepare.cjs` уменьшает весь чистый1254² PNG до128² через nearest-neighbor;
без обрезки, удаления фона, перецентрирования или изменения отдельных пикселей.
Модель сама создаёт новые позы/alpha. `extract.cjs` сохраняет PNG точными байтами
окончательного ответа. `preview.cjs` упорядочивает все13 кадров по200ms/2.6s;
ничего не выброшено и не ретушировано. GIF ограничен палитрой/бинарной alpha;
исходные PNG и HTML — основа проверки, увеличение×4 только для просмотра.

## Наблюдения и ограничения

- На кадрах03–10 корпус заметно выпрямляется и уходит влево. У кадра07 bbox
  alpha≥128: `(15,7,109,121)`, у кадра02: `(25,15,119,121)`.
  Изменение границ достигает10px поX и8px вверх вместо требуемого1px.
  Это измерение общего силуэта, а не доказательство сдвига каждой его части.
- Нижняя граница силуэта остаётся121; точная неподвижность стоп не подтверждена.
  Нижние28строк имеют до113 изменений binary-alpha относительно кадра02,
  включая ноги и детали, а не только точки контакта.
- Кадр01 по RGBA равен входу. Он сохраняет промежуточную alpha/множество цветов
  статичного исходника; кадры02–13 имеют binary-alpha и более узкую палитру.
  Поэтому смена01→02 и13→01 требует отдельной визуальной оценки текстуры/контура.
- Последний кадр не равен первому. Их5385 отличающихсяRGBA-пикселей включают
  смену alpha/палитры и **не означают** такой же геометрический скачок.
  Кадр13 от ближайшего очищенного кадра02 отличается382RGBA-пикселями.
- По просмотру ведущего лицо и один лук остаются узнаваемыми, но лук/руки
  двигаются вместе с корпусом вопреки требованию покоя. Это не улучшенная
  утверждённая замена референса; сохранена как проба с недостатками.
