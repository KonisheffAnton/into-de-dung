# Ещё десять магов и десять лучников — 2026-11-01

По U созданы **20 новых концептов**, по10 на каждый класс, встроенным ImageGen.
Предыдущие одиночные [пробы](../mage-archer-concepts-20261101/README.md)
в эту двадцатку не входят. База main: `4b6394de580f0fafb887349e6880a3abe0965632`.
Это предложения для выбора, `integration=false`.

[Маги01–10](mage-contact.png) · [Лучники01–10](archer-contact.png) ·
[Автономная галерея с увеличением](gallery.html).

Сохранены компактные пропорции, простые пиксельные пятна, поворот вправо
и изометрический каменный тайл. Маги варьируют возраст, головной убор, причёску,
бороду, плащ и навершие посоха в синей палитре. Лучники — капюшон, причёску,
плащ, лицо и стойку с луком в оливково-кожаной гамме. Есть мужские и женские
предложения; существующие игровые классы и модели не менялись.
Точный масштаб/ракурс слегка различается между генерациями: это концепты,
не готовые спрайты с согласованной опорой.

У первого нового лучника ImageGen исправил неполную нижнюю половину лука.
Обе версии и запрос правки прослеживаются в [prompts.json](prompts.json);
в итоговую десятку входит только исправленная. Для последующих лучников
вариант02 стал ориентиром полного лука. Отдельные кисти, хват, пиксельная сетка
и посадка требуют художественного выбора и подготовки перед анимацией.

Все20 итоговых PNG сохранены побайтно из выдач, без локальной ретуши:
[источники, SHA и размеры](sources.json). Общие листы — снимки HTML,
а не повторная генерация персонажей. В галерее также показаны выбранные
Воин11, Защитник02 и Разбойник02 как ориентиры семейства.

## Просмотр и проверки

HTML встраивает23 изображения и работает без соседних файлов. Это генерируемый
дубликат PNG, поэтому он исключён из Git. После checkout собрать из корня:

```powershell
node docs/art/mage-archer-variants-20261101/build_gallery.cjs
node docs/art/mage-archer-variants-20261101/check_gallery.cjs
node docs/art/mage-archer-variants-20261101/check_portable.cjs
```

Обычная сборка использует только PNG проекта и сохранённые SHA из sources.json.
Исходные выдачи генератора не нужны. Дополнительный флаг `--verify-originals`
сверяет байты с выдачами по локальным путям, если они доступны на этой машине.
Для браузерной проверки можно задать `PLAYWRIGHT_MODULE` и нужен Edge.
Готовый HTML при переносе этих зависимостей не требует.
