# Костяной панцирь №2 — пять звериных вариантов

U 2026-11-15 выбрал №2 [предыдущей серии](../kostyash05-imagegen-five-20261115/README.md):
развить костяной панцирь, сделать морду зверинее, убрать мелкие детали,
сохранить рост в 1,5 раза меньше героев; «рисуй сам».

Выполнены пять отдельных вызовов встроенного **image_gen** с выбранным
персонажем как основой и Воином 11 как стилевым референсом. PixelLab не вызывался.

| 1 | Кабаний | Тупое выступающее рыло, крупные ноздри, короткие клыки |

| 5 | Широкопаст | Плоская широкая голова, горизонтальная пасть, почти нет ушей |

Сохранены короткие поджатые ноги, длинные передние лапы, голова ниже горба,
бледная кожа и грубая дубинка. Панцирь состоит из двух-трёх крупных пластин.
Рёбра сведены к теневому пятну, ткань и оружие упрощены, волдырей меньше.
Животные признаки задают форму морды; это варианты того же Костяша.

## Размер и проверки

Сырые изображения: RGBA 1402×1122. Высота тела при alpha≥8 по порядку:
786/781/790/788/776 px; минимальные поля 143/147/141/147/146 px.
Головы, панцири, ступни, когти и дубинки помещаются целиком.
Слабый внешний alpha-шум не включается в измерение тела; alpha исходников сохранена.

На листах Костяши имеют видимую высоту **304 px**, герои — **456 px**.
Отношение 456/304=1,5, в каждом ряду общая линия земли. Это соответствует
примерно 101⅓ px при эталонном герое 152 px. Масштаб презентационный:
нативный игровой спрайт и размер в F5 ещё не подготовлены/не проверены.
Для размещения готовых рисунков применяется nearest-neighbor; персонажи нарисованы image_gen.

Сборщик `build_comparison.py` адаптирован из предыдущего пакета, работает
только с упакованными файлами, проверяет SHA, промпты, alpha и высоту показа.
[Проверка сборки](validation.json), [независимое ревью](review.md).
