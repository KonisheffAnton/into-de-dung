## Проверки и границы

Оба PNG фактически1254×1254 RGBA, alpha0–255; проверены чтение, прозрачность,
SHA и совпадение копий с результатами ImageGen. Есть промежуточные значения
alpha и слабые полупрозрачные пиксели за основным силуэтом; это ещё не готовые
нативные128² игровые кадры. Требуемые128² были переданы в prompt, но провайдер
вернул крупные изображения. Локальная ретушь/ресайз не выполнялись.

Визуально проверены два кинжала, полная фигура, видимое лицо, отсутствие тайла,
подставки и нарисованной тени. Совпадение пиксельной сетки с эталоном не доказано.
После выбора предстоят подготовка128², опора и сравнение на тайле в игровом
размере; анимация и подключение требуют следующего поручения.
Godot/full/core/F5/editor/DPI/GPU не запускались: runtime-код и ассеты не менялись.
Независимый game_reviewer: APPROVE для сохранения внешней пробы, без блокеров.
Он сверил визуальные признаки, SHA исходников/копий и метаданные/alpha/bbox;
это не художественная приёмка и не проверка игры. Проверены14 локальных ссылок,
побайтный архив HANDOFF, SHA чужой сцены и32 файлов защищённого art-каталога.
HANDOFF2250 символов при ориентире2500; прочие входные документы прежние.

U также спросил об отдельных вариантах воина для разных масштабов камеры.
В текущем эталоне один PNG128². Найденная [работа с зумом](../pixel-zoom-20261010/README.md)
меняла выборку одного рисунка; прежний набор отдельных моделей не найден.
Предложение ведущего — сравнить базовый рисунок с упрощённым дальним вариантом,
сохранив пропорции/опору и непрерывность анимаций. Это обсуждение, не реализация.
