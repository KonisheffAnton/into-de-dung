# Рваноух — стандартный анимационный пакет PixelLab

По поручению U выбранный [Рваноух с рваной одеждой](../kostyash-rvanoukh-rags-20261115/README.md)
проведён через нативную подготовку и генерацию базовых клипов текущего
[skin pipeline](../../CHARACTER_SKINS_V1.md): ожидание, атака (`ability`) и смерть.
Получено **9 вариантов, 297 исходных PNG**. Это пакет для выбора движений;
ресурс врага, игровая механика и runtime-подключение пока не создавались.

## Варианты

| № | Ожидание | Атака | Смерть |
|---|---|---|---|
| 1 | Тяжёлое дыхание | Косой удар | Оседание вперёд — **карантин** |
| 2 | Принюхивается | Удар сверху с дугой | Падение на бок |
| 3 | Нервный хват | Низкий боковой взмах | Оседание под горбом |

Названия описывают замысел; точное движение видно в галерее.
Общий GIF показывает предложенный ведущим набор **idle2 / attack2 / death3**,
не выбор U. В атаке2 хорошо видны подъём дубинки, дуга и акцент удара.
В ожиданиях2/3 движения сдержаннее, чем в дыхании1.

**Смерть1 не выбирать для игры:** в generated-кадрах1–32 есть посторонний
непрозрачный кластер около(0,0), до8 пикселей. Тело и ступни не обрезаны,
но отступ холста нарушен. Исходный дефект не скрыт ретушью; все32 кадра
сохранены, карточка явно помечена. Смерти2 и3 проходят проверку краёв.
Итого восемь клипов без нарушения отступа и одна отклонённая проба.

## Нативный исходник

Исходный PNG1402×1122 сохранён побайтно в `model/source-full.png`.
Его видимая alpha≥8 высота697px приведена nearest-масштабированием к101px
на прозрачном холсте256²; Воин red_bastion имеет152px, отношение≈⅔.
Голова/ступни внутри кадра. Опора(128,200) — центр силуэта по X и нижняя
видимая точка по Y, не вычисленный центр между стопами.
Перерисовки модели и локально нарисованных поз нет.
[Точная геометрия, SHA и исходник](model/input-manifest.json).

Это нативный художественный размер. Применение texture_scale/ArtRoot,
пикинг, посадка на тайле и F5 пока не проверялись; герои не уменьшались.
Рост в движении меняется с позой; полная область атаки2 выше из-за дуги
оружия, а не увеличения тела. В галерее оба исходника показаны в одном масштабе.

## Генерация и экспорт

PixelLab `animate-pixminimax`:256²,32 запрошенных кадра + входной =33 на клип,
`enhance_prompt=false`, прозрачность, все четыре caption-поля заданы.
Для idle/атак задан исходник как `last_frame`, для смертей — свободная
конечная поза. [Промпты](clip-prompts.json), [параметры](requests.json),
[снимок актуальной схемы](endpoint-schema.json). Полные API-ответы находятся
в `D:/Codex/home/generated_images/rvanoukh-animation-20261115/`.
Секрет в пакет не входит. Все9 jobs completed, повторных POST не было.
Расход по billing каждого задания: **45 генераций**, по5 на клип;
баланс3179.71063541667→3134.71063541667 подтверждает ту же разницу.

`pixellab/<тип>-<номер>/` содержит33 raw PNG, лист2048×1280 с8 колонками,
GIF, filmstrip и `clip.json` с anchor/canvas/SHA/usage/таймингами.
Пиксели листов равны исходным кадрам. Raw PNG побайтно равны API-ответам.
Подготовка и атомарная защита от повторных платных POST прошли
[независимое ревью](preparation-review.md).

Тайминги просмотра: idle90мс/кадр (2.97с); attack60мс, конец350мс (2.27с);
death70мс, конец1500мс (3.74с). Это локальный тайминг просмотра, не тайминг
боевой команды. Галерея циклично играет только idle; атаки/смерти держат конец.
Отдельные GIF и общий GIF повторяются для просмотра.

## Проверки и остаток

`validate_package.py`: completeness, структура и byte integrity **PASS**;
297 PNG/ячеек,9 GIF,22 встроенных ассета автономного HTML, SHA источника,
anchor/canvas, тайминги и края проверены. Quality status **QUALITY_FAIL**
из-за карантина death1, а не общий PASS художественного качества.
`summarize_generation.py`:297 экспортированных PNG побайтно сверены с API.
Python compile и PowerShell parse прошли; runtime/Godot не затронуты.
[Независимое ревью — APPROVE как пакет для выбора](review.md).
[Проверка живой галереи](browser-check.json):9 клипов, пауза/кадры/скорость,
удержание конца и квадратный zoom проверены. IAB блокирует переход по
blob-ссылке полного исходника; обход не предпринимался. PNG/GIF доступны
непосредственно в папке пакета, их целостность проверена отдельно.

Первые кадры всех9 клипов совпадают с входом по alpha и видимому RGBA.
Концы idle/атак не побайтно равны входу: PixelLab возвращает бинарную alpha
и слегка меняет цвет/контур. Силуэт возврата визуально близок, но точный шов
не принят; кадры не подменялись и не переставлялись. Перед интеграцией нужны
выбор U, оценка стыка/удара/финальной позы и посадка в бою.
Ни подготовка галереи, ни технические проверки не означают приёмку U/F5.

## Воспроизведение подготовки

Из корня проекта: `python docs/art/rvanoukh-animation-20261115/prepare_input.py`.
`prepare_requests.py` готовит transport JSON вне Git и отказывается менять
уже запущенную серию. Сохранённый `invoke-pixellab.ps1` копируется в каталог
jobs; `run_pixellab.py --limit 9 --active 3` возобновляет только GET существующих
jobs, новые POST разрешены только для ещё не попытанных записей.
**Не повторять генерацию ради просмотра уже готового пакета.**

Для локального обновления экспорта: `export_pixellab.py`, затем
`build_gallery.py`, `build_preview.py`, `validate_package.py`,
`summarize_generation.py`. Они используют сохранённые ответы, без POST.
