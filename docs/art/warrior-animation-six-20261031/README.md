[Точные54 промпта и параметры](requests.json). Схема API сверена перед запуском:
[официальная документация](https://api.pixellab.ai/v2/llms.txt).
V3 отклонил16 кадров при256² (HTTP422, фактический максимум8); две отклонённые
попытки сохранены. Серия переключена на `animate-pixminimax`,32 кадра, прозрачность,
`enhance_prompt=false`. Idle/способность получают исходник также как last_frame.
Для смерти last_frame не задаётся. Фактическое число кадров и расход — в clip.json.
После десяти принятых задач сервис вернул429; явно отклонённая попытка сохранена,
последующая отправка выполнена после освобождения мест. Неопределённые POST не повторяются.

Исходные запросы с inline PNG, admissions, ответы, usage, баланс и код безопасного
сетевого wrapper находятся вне Git:
`C:/Users/Aston/.codex/generated_images/warrior-animation-six-20261031/`.
Ключ там не сохраняется: wrapper читает прежний DPAPI-файл, отправляет Bearer
только официальному API, не печатает и не записывает его.

Экспорт принимает только status=completed и проверяет job_id. PNG кадров
сохраняются побайтно; первые видимые пиксели и alpha сравниваются с входом отдельно
от RGB полностью прозрачных пикселей. Проверяются canvas, уникальность кадров,
касание границы и нарушение8px отступа, отдельно для любого/сильного alpha.
Флаги не исправляют рисунок автоматически и не означают художественную приёмку.
`last_frame` у API — направляющая поза, не гарантия точного RGBA. Проверка обнаружила
несовпадения последнего кадра, включая alpha; они отдельно перечислены в
`validation.json` как открытая приёмка замыкания/возврата. Сырые кадры не ретушируются.
Структурный PASS не означает бесшовность idle или художественное одобрение.

## Локальные пробы и просмотр

Локальная анимация отдельно разрешена U для этой серии. Это движение вырезанных
частей исходника, без дорисованных анатомических поз. Смерть — грубое падение/поворот
исходной фигуры с остановкой; не равно полноценной покадровой пластике PixelLab.
Маски, повороты и восстановление позы требуют пользовательской оценки.
У11 при подъёме меча открывается ранее закрытая нога: под клинком добавлен простой
подклад брюк/сапога цветами исходника. Это локальная условная дорисовка скрытой области.

На каждый клип: `spritesheet.png` (256²,8 колонок), `frames/`, `preview.gif`,
`clip.json`. PNG-листы и GIF сохраняются в Git; отдельные PNG кадров исключены
как дубликаты листов, но остаются в рабочем каталоге. Сырые PixelLab-ответы также
содержат исходные PNG. Локальные кадры воспроизводятся `build_local.py`.
Длительности заданы для сравнения, PixelLab не передаёт авторский тайминг.
GIF может склеивать одинаковые кадры; реальный тайминг прочитан обратно и записан.
GIF повторяется для сравнения. Галерея повторяет только idle; смерть и способность
удерживают последний кадр, кнопка «Сначала» запускает снова.
Доступны пауза, шаг/ползунок кадров, скорость, три фона, игровой и крупный масштабы.

## Воспроизводимость и границы
