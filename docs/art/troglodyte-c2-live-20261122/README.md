# С2 на игровом поле — 2026-11-22

[Анимация GIF](c2-on-field.gif) · [WebP без потери цветов](c2-on-field.webp).
960×640, без изменения размера и сглаживания. GIF использует общую палитру256
без дизеринга; WebP сохраняет исходные цвета GPU-кадров без потерь.
720мс до смерти, исходные33 кадра С2 по80мс,2000мс после. Всего5.36с, цикл.

Снята настоящая тестовая доска HeroHubBattleFactory, с текущими фигурами,
каменными плитками, проекцией2:1 и камерой×2. Троглодит не заменён тестовой
фигурой. В изолированной сессии подана DeathCommand, её receipt проигран
штатным BattlePresentationPlayer. Это управляемая запись игрового рендера,
а не ручной боевой плейтест и не монтаж отдельных исходных спрайтов.

Во время падения тень сохраняет опору клетки (540,350 в кадре).
В конце публикация состояния смерти убирает фигуру, полосы и GroundShadow;
на плитке появляется штатная отметка свежего трупа. Лежащая фигура С2
не остаётся постоянным спрайтом трупа. HP24 во время transient clip —
существующее поведение before-state; в финальном состоянии HP0 и тело мертво.
Игровое поведение, положение тела и тени этим пакетом не менялись.

Воспроизведение: скопировать [скрипт](../../../tools/demo/capture_troglodyte_death.gd)
в чистую импортированную runtime-копию и запустить Godot с параметрами
`--rendering-method gl_compatibility --rendering-driver opengl3
--script res://tools/demo/capture_troglodyte_death.gd -- --captures=<absolute-dir>`
(одной строкой, один runner, отдельный APPDATA). Вывод — PNG и capture.json.
