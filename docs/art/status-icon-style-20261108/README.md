# Значки в стиле текущих спрайтов — 2026-11-08

U попросил перенести предыдущие схематичные значки в художественный стиль игры.
Main, base `47605034978ec9140a63423bc5d7f6ed8a58cd67`.
Это P для выбора: новые растровые рисунки не подключены к runtime.

## Направление и источник

Стилевой референс — одобренный
[Grey Bastion](../../../assets/art_presets/approved/character_skins_v1/grey_bastion/still.png):
компактный силуэт, локальный тёмный контур, объём из нескольких световых
плоскостей, читаемые металл/кожа/ткань. Его фигура не является содержимым
значков; переносится техника рисунка. Цвета статусов заданы
[ART_DIRECTION](../../ART_DIRECTION.md#цвета-текста-статусов--2026-11-08).

Три листа получены через PixelLab `/generate-image-v2` с `style_image`,
прозрачным фоном и отдельно описанными мотивами A/B/C. Полные промпты и
параметры без секрета — [01](requests/sheet01.json), [02](requests/sheet02.json),
[03](requests/sheet03.json). Официальная схема сверена перед запросом:
[API](https://api.pixellab.ai/v2/llms.txt), [OpenAPI](https://api.pixellab.ai/v2/openapi.json).
Выбор провайдера и работа с ключом — [GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md).

## Листы

[Галерея](index.html) сохраняет расположение исходных PNG; подписи вынесены
за рисунки. `python build_gallery.py` пересоздаёт только HTML, без изменения PNG.

1. [Эффекты персонажа](preview01.png): кровотечение, горение, яд, кислота,
   оглушение, путы, заморозка, мокрота. [Raw01](raw/sheet01.png).
2. [Защита и реакции](preview02.png): магический/поднятый щит, оппортунист, контратака, прикрытие, ожидание,
   огонь на клетке, кислотная лужа.
   [Raw02](raw/sheet02.png).
3. [Состояния клеток](preview03.png): шипы, труп, обвал, напольная/настенная ловушка,
   глубокая кислота, провал, общая опасность. [Raw03](raw/sheet03.png).

Предыдущие [схемы и инвентарь](../status-icon-proposals-20261108/inventory.md)
сохраняются как описание смыслов. Ведущий и независимый reviewer визуально
сверили24 строки по3 мотива:72 рисунка. Это наблюдение состава листов,
не подтверждение узнаваемости каждого мотива без подписи в игровом размере.

## Техническая проверка

Все3 задания completed, по25 generations: фактический суммарный usage75.
Исходные PNG384×512 RGBA имеют прозрачность и побайтно равны base64-ответам API;
пиксели не исправлялись и не перекрашивались. Job ID, usage и SHA256 —
[01](requests/sheet01-result.json), [02](requests/sheet02-result.json),
[03](requests/sheet03-result.json). Preview — headless Chrome, увеличение2× nearest,
подписи вне исходного рисунка. Повторная сборка HTML побайтно воспроизводима.

**Это не готовый атлас для нарезки:** фактические ряды смещены относительно
запрошенной сетки128×64. Рисунок касается нижней границы всех трёх PNG, а у03
также верхней; у нижних мотивов возможна обрезка. Автоматически нарезать по
промпт-сетке нельзя. Исходники сохранены как есть для выбора стиля и мотива;
после выбора нужны отдельные спрайты с прозрачным запасом до всех краёв.

## Граница приёмки
