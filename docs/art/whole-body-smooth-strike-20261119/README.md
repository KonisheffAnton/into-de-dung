# Плавные переходы цельного тела — 2026-11-19

Автономная художественная проба по поручению пользователя: сгладить переход
от замаха к удару и возврат в стойку. Продолжает
[предыдущую версию](../whole-body-weighted-strike-20261118/README.md).
В игру не подключена; игровые сцены, код и механики не менялись.

## Устройство и результат

Сохраняются три слоя: **цельное тело в броне, оружие, шлем**. Руки, ноги,
голова и доспех находятся в одном полном PNG каждой позы. Перчатки и сапоги
не являются отдельными визуальными слотами. Общий покадровый трек и время
одинаковы для тела без предметов, меча и топора; шлем переключается отдельно.
Ориентир доспеха — «Красный бастион», как в предыдущей версии.

В удар добавлены восемь последовательных поз прохождения кисти перед грудью,
три позы начала замаха и двенадцать поз возврата. PixelLab получил контрольные
точки движения для восьми поз удара, но выдал **целые рисунки тела**.
В браузере нет вращения частей, деформации или смешивания двух рисунков тела:
один вызов рисует один исходный PNG. SHA256 подтверждают побайтную сохранность.
Локальны только выбор кадров, длительности и привязки оружия/шлема.

Всего13 кадров дыхания и40 кадров удара. Дыхание1560мс, удар1770мс,
полный цикл3330мс. Постоянный root[-8,0] сохраняет нарисованный перенос веса.
Первый и последний кадры удара, а также края дыхания совпадают по полному RGBA
и привязкам: на стыке клипов поза не перескакивает.

По [измерениям привязок](motion-report.json) максимальный соседний шаг кисти
во всём ударе уменьшился со122,772 до28,178px; в новой основной дуге —17,692px.
Максимальный поворот оружия между позами уменьшился с1,85 до0,6рад.
Это диагностика, а не доказательство художественной естественности.
На начальном замахе ещё есть более крупные шаги, чем внутри новой дуги;
приёмка движения, хвата и шлема остаётся за пользователем.

## Источники и воспроизведение

[selected_frames.json](selected_frames.json) хранит источники, тайминг и привязки;
[origins.json](origins.json) — происхождение каждого PNG;
[provider.json](provider.json) — запросы без изображений/секретов, ответы и расход.
Из семи заданий выбраны части трёх; четыре неудачные попытки не скрыты.
Общий расход этапа **42,2 генерации PixelLab**, включая25 на отклонённую
интерполяцию и0,2 на два определения контрольных точек.
Сырые запросы, ответы и отклонённые PNG сохранены вне репозитория:
`D:/Codex/home/generated_images/whole-body-smooth-strike-20261119/`.
Новые вызовы провайдера при воспроизведении не выполняются.

```powershell
python docs/art/whole-body-smooth-strike-20261119/prepare_assets.py
python docs/art/whole-body-smooth-strike-20261119/measure_motion.py
python docs/art/whole-body-smooth-strike-20261119/build_preview.py
python docs/art/whole-body-smooth-strike-20261119/check_preview.py
```

Первый шаг требует сырого кэша; остальные используют PNG репозитория,
Python/Pillow, Node24 и headless Edge с отдельным профилем. Экспорт получает
кадры из того же FrameRig, что галерея. `capture_browser.mjs` забирает готовый
QA JSON через локальный CDP и закрывает свой браузер. Это устраняет два
таймаута прежнего `--dump-dom`, сохраняя проверку68 поз предметов крупно.
Рендерер и четыре PNG предметов не изменены.
