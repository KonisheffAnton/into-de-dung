## Одинаковые условия

[Исходник](source-battle.png) 1280×850 побайтно совпадает с предыдущими пакетами.
Старые [первый лист](../combat-font-preview-20261027/README.md) и
[четыре пары](../combat-font-pairs-preview-20261027/README.md) не изменены.
В листе показан один crop x=400, y=0, w=880, h=700 при масштабе 50%; полные PNG — 100%.
Фон не ретушировался, генеративной перерисовки нет. Верхняя фигура частично
обрезана исходной камерой. Подписи и числа наложены нативным HTML/CSS.

Значения -12.5, -28.0, +8.0, -6.0 и подписи КРИТ, ЩИТ, БЛОК, ПРОМАХ,
КРОВОТЕЧЕНИЕ — демонстрационные, не реальные события записанного боя.
Во всех вариантах одинаковые позиции, цвета, контур и видимая высота:
цифры 40px native, крит 50px, новые слова 32px, теги 24px (в листе 20/25/16/12px).
Em-размер вычисляется по видимым границам цифр/букв отдельно. Краткие теги имеют
одинаковую высоту блока 36px. Контур 4px наружу и тень 3px native.
Строки под кадрами показаны без контура. Во всех шрифтах используется ASCII '-'
(у базового Pixelify нет U+2212); cmap проверяет все показанные знаки без fallback.
Нормализация высоты предполагает дробные масштабы: это оптическое сравнение,
а не проверка оптимальной пиксельной сетки или рендера Godot.

Цвета: урон #ffe6ce, крит #ffd06d, лечение #79edba, щит #85d9ff,
блок #b7dcec, промах #ebe5d7, кровотечение #ffa6a1.

## Источники

Файлы получены из первичных источников, без покупки и без регистрации:

- [Pixeloid](https://ggbot.itch.io/pixeloid-font), архив Pixeloid_Font_1_0.zip; OFL 1.1.
- [Kaph](https://ggbot.itch.io/kaph-font), архив Kaph_Font_1_20.zip; OFL 1.1.
- [Chetyre](https://hanshuyuri.itch.io/chetyre), архив Chetyre v1.0.zip; OFL 1.1.
- [Pixel Ultima](https://github.com/DeeJayLSP/pixel-ultima-font), закреплённый commit
  55de0f169cb3dd4f0c378b0408182a4d2b8b0eff; OFL 1.1.
- [Quest Square](https://spicygame.itch.io/fonts), SG Font Collection v6;
  [авторская декларация CC0](fonts/quest-license-source.txt).

TTF и лицензии сохранены в fonts/. [Происхождение](provenance.json) содержит SHA256,
публичные страницы, ID загрузок и точные имена файлов внутри архивов. Исходные
архивы и их метаданные — test_reports/combat-font-options-preview-20261027/.
Ключи временных загрузок в provenance не включены. Лицензии сохраняются побайтно
через локальный .gitattributes. Pixelify/Tiny5 скопированы из прежней пробы.
Автор Pixel Ultima предупреждает о возможных проблемах интервалов/обрезания;
проверка наших конкретных строк не означает проверку всего набора символов.

## Проверки и границы

[Рендер](render-preview.cjs): `node render-preview.cjs <node_modules с playwright>`;
установленный Edge, headless, DPR1. [Проверка](validation.json): 7 шрифтов загружены,
cmap всех показанных знаков, 42 подписи в кадрах без пересечений, 18 строк образцов,
правильные назначения шрифтов, ошибки браузера отсутствуют. PNG просмотрены.
Независимое ревью APPROVE. Побиксельная проверка: вне областей текста с запасом
12px native фон неизменен. Отчёты — test_reports/combat-font-options-preview-20261027/.

.gdignore исключает пакет из импорта Godot. Runtime/сцены/assets и защищённые
пользовательские файлы не менялись. Godot/full/core/F5 не запускались;
движение/DPI, художественный выбор и внедрение остаются открытыми.
Core/preview/queue/RNG/save/frozen прежние; новый этап автоматически не начинать.
