# Низкий огонь: варианты 21–40 — 2026-11-04

По отзыву пользователя о предыдущей серии сделаны ещё 20 статичных проб:
**цельный каменный тайл с низким огнём**, разные способы рисования, без высоких
языков. Огонь распределён по всей верхней грани; боковины остаются видимыми.
Выбор пользователя открыт; анимация и внедрение этой серии не выполнялись.

[Открыть автономную галерею](gallery.html) · [Общее сравнение](comparison.png).
Карточки 21–40 увеличиваются без обрезки; клик открывает отдельный просмотр,
кнопки листают варианты, Escape закрывает. HTML содержит все 20 PNG внутри.

Основа — [эталон текущего каменного тайла](../current-tile-reference-20261103/README.md),
изображение `tile.png`. Каждый вариант создан отдельным вызовом image_gen с этим
референсом. Все PNG1254×1254RGBA включают камень и огонь; прозрачность находится
вокруг блока. Это AI-пробы по референсу, а не побайтно сохранённая текстура камня
и не готовые runtime-оверлеи. Исходный эталон не менялся.

Почти плоские вспышки, гуашь, гравюра и тление сравниваются с короткими
приподнятыми язычками в30/32/34/35/38/40. Некоторые плоские пробы могут читаться
как раскалённая поверхность — это открытый вопрос художественного выбора.
Названия обозначают направления промптов, не гарантируют точное воспроизведение
каждой техники. Общая стилистика персонажей остаётся у [ART_DIRECTION](../../ART_DIRECTION.md).

## Происхождение и проверки

- [Точные промпты](prompts.json), [пути исходников/SHA256/alpha](sources.json),
  [учёт вызовов и повторов](generation.json). 21 вызов:20 результатов и один
  HTTP403 без изображения для37; повтор с тем же промптом успешен.
- PNG скопированы побайтно из результатов провайдера; без ретуши, обрезки,
  перекраски и дополнительной пикселизации. Слабые краевые alpha исходника сохранены.
- [Проверка файлов](asset-validation.json):20 различных SHA,RGBA1254²,
  alpha0–255, видимый силуэт(alpha>8) имеет отступ более40px от границ кадра.
- [Сборка](build_gallery.cjs) проверяет ID/номера/PNG CRC и встраивает20 изображений;
  [манифест](gallery-validation.json). [Проверка браузером](check_gallery.cjs):
  [PASS](browser-validation.json) для20 карточек, масштаба70/100/160%,
  modal/листания/Escape,390px и копии единственногоHTML без соседних ресурсов.
- Снимки и закрытие этапа: `test_reports/fire-low-styles-20261104/`.
  Сохранность предыдущей серии33 файлов, исходного арт-набора360 файлов
  и33 чужих файлов проверяется отдельно от художественной оценки.
