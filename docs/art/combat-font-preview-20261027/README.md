# Сравнение шрифтов боевых чисел — 2026-10-27

U: сравнить Pixelify Sans Bold, Russo One и Tiny5 на одном снимке нашего боя:
обычный урон, крит, лечение и щит. Только превью, без внедрения в игру.

[Сравнительный лист](comparison.png), [локальная галерея](comparison.html).
Полные кадры: [Pixelify](pixelify-battle.png), [Russo](russo-battle.png),
[Tiny5](tiny5-battle.png). Сначала открыть comparison.png, затем нужный полный кадр.

## Метод

Один [исходный снимок](source-battle.png), 1280×850, скопирован побайтно из
test_reports/demo-f452badf203a427999337faf2ba45996/attack-style-screenshots/facing-warrior-player-1.png.
В нём нет всплывающих чисел; верхний боец частично обрезан исходной камерой.
Исходник не ретушировался. Нативный текст HTML/CSS накладывается поверх изображения;
генеративной перерисовки персонажей, поля или букв нет.

Три одинаковых фрагмента кадра: x=400, y=0, width=880, height=480, масштаб 50%.
Полные PNG показывают весь исходный кадр в масштабе 100% с теми же подписями.
Числа — демонстрационные, не события этого боя:

| Событие | Текст | Цвет |
|---|---|---|
| Обычный урон | -12.5 | #ffe6ce |
| Крит | КРИТ / -28.0 | #ffd06d |
| Лечение | +8.0 | #79edba |
| Щит, поглощено | ЩИТ / -6.0 | #85d9ff |

В сравнительном листе видимая высота цифр 20px, у крита 25px; в полном кадре 40/50px.
Размер em вычисляется отдельно по видимой высоте набора 0123456789 в настоящем шрифте.
Позиции, тексты, цвета, наружный контур 2px и тень одинаковы. Для подписи КРИТ/ЩИТ
также выровнена видимая высота. Образцы под кадром — без контура для оценки букв.
Pixelify вес 700, Russo 400, Tiny5 переменный шрифт с весом 400 и остальными осями
по умолчанию. Это статический браузерный рендер, не проверка Godot, DPI или движения.

В загруженном Pixelify нет U+2212 (типографский минус), поэтому во всех вариантах
используется U+002D (обычный дефис-минус). Каждый показанный знак цифр/подписей
проверен по cmap файлов: скрытого подмешивания шрифта для этих символов нет.
Дробная часть .0 оставлена специально для сравнения; изменение игровых строк
и правила округления этим макетом не предлагаются к автоматическому внедрению.

## Источники и проверки

Настоящие TTF, лицензии OFL и метаданные сохранены в fonts/.
Исходные лицензии хранятся в Git побайтно через локальный .gitattributes,
включая исходные переводы строк и пробелы; их SHA проверяются как у TTF.
Версия репозитория Google Fonts, точные URL и SHA256 — [provenance.json](provenance.json).
Семейства: [Pixelify Sans](https://github.com/eifetx/Pixelify-Sans),
[Russo One](https://github.com/googlefonts/russoone), [Tiny5](https://github.com/Gissio/font_tiny5).
[Рендер и проверки](render-preview.cjs): Node.js + Playwright, установленный Edge headless.
Запуск: `node render-preview.cjs <каталог node_modules с playwright>`.
[Результат](validation.json): загрузка 3/3 шрифтов, cmap, границы 12/12 подписей,
размер исходника и отсутствие ошибок браузера. PNG дополнительно просмотрены.
Общая проверка пакета/защищённых файлов — test_reports/combat-font-preview-20261027/.

Каталог исключён из Godot через .gdignore. Runtime, игровые сцены, assets и
core/preview/queue/RNG/save/frozen не менялись. Godot/full/core/F5 не запускались.
Выбор шрифта, проверка в движении и внедрение остаются открытыми и требуют
отдельного поручения. Ручная F5-приёмка ранее выполненного разворота также открыта.
