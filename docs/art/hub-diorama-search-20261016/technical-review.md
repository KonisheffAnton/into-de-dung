# Независимое ревью инструментов

Роль game_reviewer, gpt-6-sol/high; только чтение. Игровой runtime не затронут.

Итог после исправлений: runner/reservation APPROVE; gallery APPROVE.
Исправлены атомарная запись JSON, защита от повторного POST для одного ID,
сохранение точного запроса, проверка SHA и локальное восстановление PNG,
резервирование ещё не начатых ID, цвета CSS, размеры/пропорции контактных листов,
ошибки поиска, недоступный localStorage и nullable usage.

Старый основной процесс начал 001-050 раньше исправлений. Для 051-100 до запуска
второго процесса созданы и проверены все 50 маркеров; основной процесс не мог
повторно отправить эти POST. Ведущий позднее передал ещё не начатые 086–100
новому владельцу резервов; завершение всех процессов проверено. Изменения плана
после тайм-аутов ограничены новыми вариантами 020 и 073, после завершения прежних
попыток. У 073 новый Pro job получен и завершён. Эти поздние операции проверил
ведущий; повторного независимого ревью они не получали.

Offline selfcheck без API: конкурентный ID отправляется один раз; повреждённый
PNG восстанавливается из сохранённого ответа; изменённый промпт не подменяет
provenance; резерв требует совпадающего владельца, отсутствие резерва запрещает
POST; async PNG восстанавливается локально при недоступном remote job.

Ограничение runner: force-kill оставляет runner.lock. После проверки отсутствия
живого владельца и сохранённых ответов можно вручную освободить только этот lock.
submission-started.json при неопределённом исходе POST не удалять для повтора.

Браузерные проверки — browser-checks.json. Полные provider JSON, schema snapshot,
скрипты и результаты selfcheck сохранены рядом с этим файлом вне репозитория.
