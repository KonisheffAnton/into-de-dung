База: камерное обжитое убежище у подземелья, наёмники живут и общаются;
войны на заднем плане нет. Игрок должен чувствовать отчуждение, «против всего мира».
Связи наёмников при обособленности мага — предложенная трактовка, не утверждённый сюжет.
Маг по заданию один, строго спиной, в глубокой тени; пол/возраст скрыты, никто
на него не реагирует. В части проб PixelLab нарушил эти требования: сохранён
весь поиск, а не только удачные результаты. Отбор в visual-review.md не приёмка.
Быстрые панели управления остаются требованием будущего хаба; HUD здесь не рисовали.

## Происхождение и расход

Итог: 19 Pro (`generate-image-v2`), 80 Pixen, 1 Pixflux.
99 PNG — 512×384, Pixflux №011 — 400×320. Все непрозрачные.
Карта стиля изучена из [текущего эталона](../style-reference-20261009/selected-style.png);
передана провайдеру как style-only только в пилоте 001. Остальные композиции
запрашивались заново, без исходной «Старой сторожки» и без механического перекрашивания.

Для каждого номера `items/NNN/`: original.png — исходный PNG провайдера;
request.json — точное тело POST без секрета; brief.json — замысел;
result.json — размеры/SHA/job_id/фактический usage.
[План всех запросов](plan.json), [проверка PNG](validation.json),
[побайтное сохранение](preservation.json).

В завершённых ответах учтено **556 генераций подписки**.
Баланс до/после: 4707.7 → 4150.7; разница **557**.
Разница с известным usage: 1; неопределённые ответы не выданы за нулевой расход.
Денежный баланс USD не пополнялся, покупок/новых подписок не было.

Пилот 011 сначала получил 422 из-за ширины 448; отклонённый запрос сохранён,

## Проверки и ограничения

- 100 PNG декодируются, имеют запрошенные размеры и разные SHA256;
  исходники скопированы побайтно, без ручного изменения поз, alpha или цвета.
- 100 уникальных промптов; точные сохранённые request совпадают с итоговым планом.
- Контактные листы и обзор — производные только для просмотра, пропорции сохранены.
- Независимое ревью вспомогательных инструментов APPROVE после исправлений;
  [сводка](technical-review.md), [offline selfcheck](runner-selfcheck.json).
- [Браузерная проверка](browser-checks.json): поиск/фильтры, увеличение,
  следующий оригинал, сохранение/снятие избранного. Галерея работает локально без CDN.
- Независимо просмотрены 001–019 и 021–030. Второй визуальный пакет не выполнен
  агентом из-за недоступности выбранной модели; остальные изображения проверил ведущий.
- Игровой код/сцены не менялись; Godot/full/core/F5 не запускались.
  Общая F5/editor/DPI/GPU-матрица и баланс V1 открыты.
- `.gdignore` исключает поисковые картинки из импорта Godot.
