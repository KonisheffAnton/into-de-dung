и поручил «развивай 5 вариант и сам рисуй», рост — в1,5 раза меньше героев.
Это означает **две трети роста**, а не уменьшение на50%.

Создан один новый рисунок через встроенный **image_gen**, по выбранному №5
и стилевому референсу текущего Воина11. PixelLab в этом этапе не вызывался.

морда, длинная передняя лапа, короткие подогнутые ноги и маленькая дубинка.

## Как проверен масштаб

У канонических still Воина и Мага видимая высота152px. На листе они показаны
при456px, Костяш — при304px: **456/304 = 1,5**. Нижняя точка всех трёх силуэтов
совпадает на y544. В масштабе эталона это152/1,5 =101⅓px.
Лист собран из готовых рисунков с nearest-neighbor; это только масштаб показа.

В сырой выдаче imagegen есть едва видимый alpha1–7 шум за пределами существа.
Поэтому рост видимого тела измеряется при alpha≥8: bbox(313,188,1121,971),783px.
При компоновке вокруг тела сохраняются ещё4px исходного поля; исходный PNG
не очищается и не заменяется. Финальный показ повторно измерен при том же
пороге:304px. Первоначальное измерение по любому alpha>0 захватывало шум и
было исправлено до сдачи; прежний уменьшенный показ не является результатом.

Runtime не менялся. Сравнение относится к каноническим still; в текущем боевом
коде у Разбойника/Лучницы есть отдельная поправка ArtRoot0,9 к Воину. Этот лист
не является проверкой размера на поле. Посадка/нативный спрайт/анимация и
внедрение требуют отдельного поручения после художественного выбора.

Воспроизведение без генерации: `python build_comparison.py` из папки пакета.
Исходные PNG, видимые высоты, baseline и соотношение проверяются сборщиком.
