## Генерация и ограничения

Imagegen: десять отдельных исходных вызовов, без входных картинок. У G46
попытка убрать ореол редактированием не удалась, поэтому выбран новый
результат отдельной генерации. Все три исходника G46 сохранены; итоговый —
`imagegen/G46-final.png`. Итого 12 вызовов встроенного инструмента, usage
он не сообщает. [Промпты](imagegen-prompts.json),
[G46](g46-regeneration.json), [происхождение](imagegen-sources.json).

PixelLab: один `generate-image-v2`, без style reference и без входов G;
seed 202611949, job `043eac14-9c38-4e35-9373-30375968473f`, завершён,
10 generations, 16 кандидатов. Выбраны исходники с индексами
0, 1, 2, 3, 5, 7, 9, 10, 12, 14 по порядку PL49–PL58.
[Request/receipt/status и PNG](pixellab/ribs-skull/),
[provenance](pixellab-provenance.json). Это один отбор, повторных POST нет.

На листах PL исходные 64×64 увеличены ×4 NEAREST. У G большие растровые
исходники: bbox alpha≥128 уменьшается NEAREST до 48×30, затем увеличивается
×4. Локально рисунки/alpha не ретушировались, источники скопированы побайтно.
Imagegen не гарантирует нативный пиксельный растр: отдельные края мягкие.
У PL фактическое пятно 53–58×31–38 вместо запрошенного 44×24; у обоих
провайдеров некоторые рёбра/кости длиннее задания. У PL49–PL53/PL58 светлый
задний фрагмент заметнее, у PL54–PL57 почти теряется; лицо/парные глазницы
не читаются. Эти различия оставлены для сравнения, окончательное соответствие
стилю и нужная степень заметности черепа требуют выбора пользователя.

## Примерка на поле

GPU BattleDemoBoard 8×8, каменный тайл 128×64, камера 100%, воин
fighter/red_bastion с art_scale 0.8. PL — исходные 64×64, scale 1 и NEAREST;
G уменьшены при отрисовке до 60×32 через NEAREST, исходный alpha сохранён.
Вырезка 1060×620 из полного 1440×1100 не меняет пиксели или масштаб.
Кучки — временные Sprite2D на двадцати пустых безопасных клетках.
Кадр проверяет вид на поле, а не механику останков или их будущую расстановку.

Использована ранее импортированная isolated-копия, сверенная с фиксированным
base `f7c2f79aefc43df77aabb220591718ac293ce660`. Чужие текущие изменения
боевого кода не переносились в копию; различия с live checkout перечислены
в `runtime-check.json`. Защищённая main_menu проверяется отдельно по live hash.
Из 1685 runtime-файлов 1557 совпали с base побайтно, 127 отличаются только
CRLF/LF, main_menu совпал с защищённым live-файлом; иных расхождений нет.
В кадре совпали 10 353 из 10 353 непрозрачных пикселей всех десяти PL.
Свежий import, core/full, ручные F5/Editor/DPI/performance не запускались.

Проверки и независимый просмотр: [verification.json](verification.json),
[runtime-check.json](runtime-check.json), [capture-all.json](capture-all.json),
[pixel-check-all.json](pixel-check-all.json), [art-review.md](art-review.md).
Проверяются RGBA/уникальность/прозрачные поля, точные копии источников,
защищённые файлы, 20 безопасных клеток, неизменность state/RNG/counters/revision
и совпадение всех непрозрачных пикселей PL в GPU-кадре с исходными RGB.
