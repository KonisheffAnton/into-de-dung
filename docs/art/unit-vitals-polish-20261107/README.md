# Полосы здоровья, брони и равновесия — 2026-11-07

Внедрённая проработка по поручению U; художественный отзыв в текущем бою ещё открыт.
Основа — main `351c91a6451c1ba91e0bdce8db88776e8b320807`.
Владелец размеров, цветов, дробей, прогноза и семантики —
[контракт показа](../../BATTLE_PRESENTATION_REWORK.md); направление —
[ART_DIRECTION](../../ART_DIRECTION.md). Механика урона и баланса не менялась.

Здоровье зелёное, броня имеет несколько спокойных металлических плоскостей,
запас равновесия — второстепенную янтарную полосу. Чёрные числа остаются внутри
HP/брони с чёрной рамкой; пустые треки светлее, чтобы ноль не терялся.
Масштаб 75% сохраняет рамку и две цветные строки запаса; положительная
доля не исчезает, но точное значение по-прежнему задаёт число/осмотр.

## Кадры Godot

Все PNG — прямые снимки рендера без ретуши и изменения масштаба.
Галерея проверяет одинаковые ресурсы обеих фракций на production-сценах
шести class ID (пять текущих классов и legacy fighter). Семь колонок:
полный запас, половина с прогнозом, почти ноль, ноль, три цифры,
невосприимчивость к пробою, дробный максимум брони.
Нулевое HP с alive=true — синтетическая граничная проверка рисунка;
настоящая смерть отдельно проверяет скрытие полос.

карты может быть меньше 75% и не является обещанием читаемости цифр.
