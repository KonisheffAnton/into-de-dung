## Размер

Сравнивается полная высота силуэта, включая волосы, по alpha≥128 — тем же
порогом, которым получена игровая область Защитника. Его текущие параметры:
crop1034×966, Sprite scale0.0745342, ArtRoot0.8; высота≈57.6 условных px.
Лучница: bbox(244,148)–(1164,1178),920×1030; высота≈51.84px, ровно0.9
от Защитника. Обе оси масштабируются одинаково. Ширина не обязана быть90%:
щит/силуэт у классов разные. Нижние границы выровнены только для сравнения;
это не измерение общей стопной опоры или роста тела без причёски.

Исходный RGBA не ресэмплирован и не ретуширован; HTML задаёт crop/масштаб
показа, Chromium снимает сравнение. У результата imagegen есть полупрозрачные
пограничные пиксели, как и у исходного Защитника. Alpha не порогована в ассете;
alpha≥128 используется только для измерения видимого bbox. Это не гарантия
готовой нативной сетки или альфы0/255 для будущей анимации.

## Проверка и границы

`build_comparison.py` (Pillow): размеры, RGBA, прозрачность, bbox, SHA и отношение0.9.
`capture_comparison.cjs` (Playwright+Chrome): снимок HTML с nearest-показом.
Пример: `python docs/art/archer-reference-20261012/build_comparison.py`;
`node docs/art/archer-reference-20261012/capture_comparison.cjs`.
Зависимости Pillow/Playwright доступны в bundled runtime; для Node можно задать
`PLAYWRIGHT_MODULE` полным путём к модулю. Снимок просмотрен в×1 и×5.
Отчёт: `test_reports/archer-reference-20261012/REPORT.md`.
Независимое ревью пакета — APPROVE: RGBA, bbox, uniform scaling и90%
подтверждены; художественную приёмку оно не заменяет.

В игре лучница ещё generic fallback; код, сцены и игровые ресурсы не менялись.
Анимации здесь не генерировались. Промпт — предложение для опыта U во внешней
модели, не реализация и не отмена PixelLab для генераций агентом в проекте.
Рисунок и размер ждут художественного отзыва U. Godot/full/core/F5/editor/DPI/GPU
не запускались; техническая проверка файлов не означает арт-приёмку.
Следующие генерации, интеграция, гаммы одежды — только по поручению.
