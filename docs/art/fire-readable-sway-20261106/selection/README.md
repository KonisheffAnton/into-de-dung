# Отбор более читаемого движения огня 24/29

`analyze.py` повторно проверяет 56 уже готовых групп по исходным raw PNG PixelLab. Исходный отбор, кадры и плитки из `fire-single-tongue-20261106` он только читает. Предложения и SHA записываются в `test_reports/fire-readable-sway-20261106/selection-analysis.json`; контакты в `contacts/`. Повторный запуск: `python docs/art/fire-readable-sway-20261106/selection/analyze.py`.

Проверка сохраняет закрытие исходного core, пустую границу crop, прежние пределы цвета и яркости, исключает raw00 и 17 кадров по независимому просмотру. Новый диагностический предел для контура — 6 нативных пикселей от входа вместо 4. Выбраны только существующие позы с соседним alpha-XOR не больше 180; обратный ход повторяет те же PNG. Старые число проходов, фаза и период 96×80 мс сохранены, каждая позиция предложенного порядка реально попадает хотя бы в один слот.

Пять локальных предложений дают больший размах контура, но **не достигают увеличения заметности всего поля в 1,5–2 раза**. Сумма размахов групп: огонь24 +2,9% по alpha и +2,0% по видимым RGB-пикселям; огонь29 +18,9% и +11,7%. Эти суммы сравнивают крайние позы каждой группы отдельно, а не одновременную анимацию всего тайла. Цветовая разница и художественная пригодность цикла требуют отдельного просмотра. В сцену ничего не подключено.

Контакты показывают исходный crop, прежнюю крайнюю позу и весь новый прямой ход. Это диагностическая композиция неизменённых raw RGBA поверх исходника, без новых промежуточных кадров, деформации или перекраски.
