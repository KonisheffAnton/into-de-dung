## Результат и проверка фаз

Пластину добавил PixelLab `edit-image-pixen`; затем `animate-with-text-v3`
создал пять последовательностей. В каждой запрошено восемь кадров, возвращено
девять PNG 256×256 с прозрачностью. Исходные последовательности преждевременно
включали свечение/искры, поэтому они не выданы за исправленные результаты.

Десять дополнительных PixelLab-правок создали чистые контактные кадры,
удалили ранние эффекты и уменьшили огненные вспышки в вариантах 02/04/05.
Финальные петли собраны выбором кадров, без рисования пикселей, интерполяции
или геометрического преобразования. Каждый опубликованный PNG — побайтная
копия сохранённого результата PixelLab. Полный порядок: [final-manifest.json](final-manifest.json).

пауза, шаг назад/вперёд, ползунок кадра и сравнение с необработанной последовательностью.
GIF — предпросмотр с общей палитрой255цветов и бинарной альфой; исходные RGBA PNG
остаются авторитетными. Первые и последние кадры пиксельно различаются;

сила вспышки01/03 отличается от02/04/05. Возврат02 собран обратным порядком

отскок до искр, не заявляем; проверяем порядок, который попросил U.

## Повторная сборка и границы

Использовать Python с Pillow; команды выполняются без сети и секретов:

```powershell
python package.py --provider-dir 'C:/Users/Aston/.codex/generated_images/hub-smith-plate-animation-20261018'
python assemble.py
python validate.py --provider-dir 'C:/Users/Aston/.codex/generated_images/hub-smith-plate-animation-20261018' --report '../../../test_reports/hub-smith-plate-animation-20261018/validation.json'
node --check gallery.js
```

`package.py` отказывается перезаписывать изменённые оригиналы провайдера.
`assemble.py` воспроизводит финальные копии по явной таблице источников.
`validate.py` проверяет запросы/хеши/альфу/ссылки/декодирование и порядок заявленных
меток; визуальный порядок отдельно проверяется по кадрам.
Итоги проверок и независимое ревью: [отчёт](../../../test_reports/hub-smith-plate-animation-20261018/README.md).
Новых browser playback/Godot/full/core/F5/editor/DPI/GPU и приёмки U нет.
