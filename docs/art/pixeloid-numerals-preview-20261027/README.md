## Метод

[Исходный кадр](source-battle.png) 1280×850 побайтно скопирован из
[предыдущего сравнения](../jersey-cyrillic-preview-20261027/README.md).
В листе crop x=400, y=0, w=880, h=700 при 50%; полные PNG — 100%.
Верхняя фигура обрезана исходной камерой. Фон не ретушировался.
Надписи рисуются настоящими TTF через HTML/CSS, без генерации изображения.

Значения −12.5, −28.0, +8.0, −6.0 и КРИТ/ЩИТ/БЛОК/ПРОМАХ/КРОВОТЕЧЕНИЕ —
примеры оформления, не реальные события записанного боя. Использован минус U+2212.
Цвета, позиции, наружный контур 4px и тень 3px native одинаковы.
Видимая высота цифр 40px, крита 50px, слов 32px, тегов 24px native.
Em-размер нормализован по видимым границам; дробный масштаб допустим для
оптического сравнения. Под каждым кадром — цифры, буквы, статус и смешанная
строка «КРИТ · −28.0 HP» с видимой высотой букв/цифр 14px без контура.

Это рендер браузера, не Godot и не проверка пиксельной сетки/DPI/движения.
Вариант 06 показывает нынешнюю гарнитуру, но не фактические игровые размеры.
Pixeloid взят из исходного TTF (em=1836), а не производного runtime em=2448;
видимая высота уравнена. Жирность Pixeloid записана в статическом TTF;
Jersey — Regular400, Oxanium — variable700; font-synthesis отключён.

## Источники

- [Jersey](https://github.com/scfried/soft-type-jersey) — Sarah Cadigan-Fried;
  Jersey 15/20/25 скачаны из Google Fonts, commit
  e7db6ca603fd4862010383ff17ffd6cc4ffac1c0. Jersey 10 побайтно взят из прежнего превью.
- [Oxanium](https://github.com/sevmeyer/oxanium) — исходный variable TTF,
  OFL и metadata из того же закреплённого commit Google Fonts.
- [Pixeloid](https://ggbot.itch.io/pixeloid-font) — оригинальный Bold и лицензия
  побайтно скопированы из прежнего превью.

Точные URL, размеры и SHA256: [provenance.json](provenance.json).
Лицензии/metadata сохранены в fonts/; .gitattributes сохраняет их байты.

## Проверки и границы

[Рендер](render-preview.cjs): `node render-preview.cjs <node_modules с playwright>`;
установленный Edge, headless, DPR1. [Проверка](validation.json): шесть шрифтов
загружены; русская азбука А–я/Ёё и HP присутствуют у Pixeloid, цифры/знаки —
у всех кандидатов. 42 подписи внутри кадров без пересечений; 24 строки образцов
без переполнения. CDP проверяет реальные локальные шрифты без системного fallback.
Ошибок браузера нет. Все шесть полных PNG сохраняют исходный фон вне границ
надписей с запасом 12px для контура/тени. Лист и полный Jersey 20 просмотрены.
Отчёты проверки пикселей, SHA и независимого ревью:
test_reports/pixeloid-numerals-preview-20261027/.

.gdignore исключает пакет из импорта Godot. Runtime, сцены, прежние превью и
защищённые пользовательские файлы сохранены. Godot/full/core/F5 не запускались.
Core/preview/queue/RNG/save/frozen прежние; новый этап автоматически не начинать.
