## Итог проверки

[Техническая проверка](validation.json) дала PASS для **18/18 клипов, 186/186 исходных PNG байт**, реконструкции входов, SHA запросов, admission ID, ячеек листов и GIF. Первый кадр каждого клипа совпадает с исходным по видимому изображению; различия RGB в полностью прозрачных пикселях учитываются отдельно. Ни один кадр не касается края 256²; у трёх spike клипов исходный кадр 0 содержит слабый alpha ближе восьми пикселей к краю. Это не обрезка. [Расход](usage.json): 87 generations, баланс 4699→4612 из 5000, USD credits 0.

[Playwright проверка](browser-validation.json) автономного HTML: 18 карточек/6 групп, загрузка PNG, покадровое управление, пауза, скорость, сброс одноразовых шипов, desktop и 390px без горизонтального переполнения и ошибок. Изображения проверки лежат в `test_reports/fire-spikes-animation-20261105/`.

**Художественная проверка: строгий PASS отсутствует.** [Наблюдения по всем 18 клипам](clip-observations.json) сделаны по полным листам кадров, а не только пятикадровой выборке. У огня `fire23-01` и `fire24-01` верхняя плоскость сравнительно спокойная, но боковой камень меняется на 3202 и 2962 пикселях маски (>8 RGBA) соответственно; другие варианты добавляют искры, языки, серые детали или меняют высоту/цвет поверхности. [Независимая проверка огня](independent-fire-review.json) подтверждает 0/12 строгих художественных PASS. `spike01-01` ближе других к однократному выдвижению, но меняет камень и не совпадает с заданным концом; `spike01-02` переключается туда-обратно; `spike01-03` сразу раскрывается.

Иглы `caltrops03-01/02` дают много заметных звёзд вместо двух редких кратких бликов; `03` рисует выступающие белые шипы. Камень меняется. **Шов не бесшовен**: последний→первый кадр отличается на 6487/8099/7038 видимых RGBA пикселях >8 при 631/640/638 изменённых alpha пикселях. Для сравнения предпоследний→последний отличается только на 796/273/204 пикселях. Это метрики сырых RGBA из [validation.json](validation.json); [проверка на чёрном/сером/белом фоне](root-loop-check.json) и [контакты шва](root-seam-contacts.png) дают отдельные композитные измерения, в том числе 6576/8239/7154 пикселей >8 на сером фоне. Частота просмотра 3 кадра/с не скрывает скачок. [Покадровый drift](drift.json) измеряет боковины и alpha bounds; прямое различие пикселей включает цвет и свет и само по себе не доказывает геометрическое движение.

Новые PNG не подставлены в runtime. Для художественного решения сравните полные циклы и оригиналы в галерее; технический PASS подтверждает происхождение файлов, а не выполнение описанного движения.

## Воспроизведение локальных проверок

Из корня проекта, с установленными Pillow/NumPy/Node Playwright:

```powershell
python docs/art/fire-spikes-animation-20261105/validate_package.py --verify-raw
python docs/art/fire-spikes-animation-20261105/summarize_usage.py
python docs/art/fire-spikes-animation-20261105/measure_drift.py
python docs/art/fire-spikes-animation-20261105/build_gallery.py
node docs/art/fire-spikes-animation-20261105/check_gallery.cjs
```

`--verify-raw` читает локальный внешний архив ответов PixelLab; без него валидатор проверяет сохранённые SHA/листы/GIF в Git. Скрипты подготовки и отправки сохранены для аудита, но **повторный POST этих 18 ключей запрещён барьером**.

[Проверки завершения](closeout-validation.json) подтверждают сохранность прежних пакетов, 33 чужих файлов, 1613 файлов runtime/tooling, закреплённого стиля персонажей и правил передачи; предыдущий HANDOFF проверен побайтно в рабочем дереве и Git. Godot/core/full и ручной F5 на этом этапе не запускались.
