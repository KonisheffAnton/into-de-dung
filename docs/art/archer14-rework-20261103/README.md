# Лучница14 — пять переработок, 2026-11-03

По U переработана выбранная для сравнения Лучница14 «Седая наставница».
Сохранены седые волосы, оливковый плащ, коричневая кожа, бронзовая застёжка
и лук. Корпус и ноги короче, голова относительно крупнее, светотень собрана
в более крупные пиксельные группы. Ориентиры — Воин11 и Защитник02.
Это пять близких версий одного образа, окончательный вариант ещё не выбран.

Все пять PNG1254² получены отдельными вызовами встроенного image_gen и
сохранены побайтно. Исходная14, Воин11 и Защитник02 не перерисованы.
У14-04 генератор сохранил длинную накидку вместо предложенного укороченного
жилета со свёрнутым капюшоном; фактическая версия ближе к14-01.
Единая точная пиксельная сетка, кисти/хват, игровая посадка и художественная
приёмка ещё требуют оценки. Это концепты на фоне и тайле, не готовые
прозрачные спрайты. Анимации и внедрение не поручены; runtime не менялся.

В сравнении все восемь исходных квадратных кадров показаны при одинаковой
ширине, без локальной растровой ретуши. Размеры тайлов внутри оригиналов
различаются. Галерея использует обычную браузерную фильтрацию;
comparison.png — снимок её разметки. HTML содержит все изображения,
переносится одним файлом и исключён из Git как воспроизводимый дубликат.

```powershell
node docs/art/archer14-rework-20261103/build_gallery.cjs
node docs/art/archer14-rework-20261103/check_gallery.cjs
```

Для сборки нужны пять PNG пакета и три референса по относительным путям
из sources.json. `--verify-originals` дополнительно сверяет новые PNG
с локальными выдачами генератора. Проверка браузера требует Edge и Playwright
(путь можно задать через `PLAYWRIGHT_MODULE`); готовый HTML от них не зависит.
