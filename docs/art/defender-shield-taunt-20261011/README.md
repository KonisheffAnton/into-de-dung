# Защитник: два вызывающих удара мечом по щиту

U2026-10-11 поручил анимацию применения способности через PixelLab:
Защитник дважды ударяет мечом по собственному щиту, вызывая противника.
Это отдельный кандидат для просмотра; подключение к способности ещё не выполнено.

Основа — текущий Защитник в шлеме, тот же `reference-128.png`, что у принятого
vertical idle. Сохранённый образ «Ветеран» к этой пробе не относится.
Ракурс, простые крупные формы, сталь/оливковая палитра и неподвижная опора —
[ART_DIRECTION](../../ART_DIRECTION.md). Инструмент и доступ — [GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md).

## Запрос и происхождение

Один запрос `POST /v2/animate-with-text-v3`,16 кадров, seed20261011,
прозрачный фон, усиление промпта выключено. В `first_frame` и `last_frame`
передан один и тот же эталон. Хореография: подготовка → контакт → отвод
меча с видимым промежутком → второй контакт → возврат в исходную стойку.
Ограничения запроса не являются доказательством точности полученной анимации.

- [Манифест запроса](request-manifest.json), [полный запрос без секрета](pixellab/request.json).
- [Эталон](pixellab/reference-128.png), [принятие задачи](pixellab/response.json).
- `prepare-request.py` воспроизводит запрос из сохранённого эталона; API не вызывает.
- `prepare-preview.py` собирает GIF/filmstrip из исходных PNG без изменения поз.
- Поля API сверены с [официальной схемой](https://api.pixellab.ai/v2/openapi.json).

## Статус и продолжение

PixelLab принял задачу `e6b7f1e4-4165-4cb4-8332-b8c3dd80db8e`.
Из-за очереди с оценкой1170s U выбрал **сохранить и вернуться позже**.
Постоянный опрос остановлен. На вопрос U о задержке выполнен один диагностический GET:
последний ответ [job-status.json](pixellab/job-status.json) — `processing`, queue8, estimate807s.
Tier2 распознан как active; официальный тариф включает priority queue, но API не
сообщает причину задержки. Текущий статус при продолжении нужно прочитать заново.
Изображений результата ещё нет, два удара/опора/качество не проверены;
фактическое списание генераций пока неизвестно.

Для продолжения вызвать `GET /v2/background-jobs/e6b7f1e4-4165-4cb4-8332-b8c3dd80db8e`
с доступом по GRAPHICS_WORKFLOW. Новый POST для получения этого результата не нужен.
Сохранить свежий ответ в `pixellab/job-status.json`; при `completed` выполнить
`extract-result.py`, затем `prepare-preview.py` через Python с Pillow.
Проверить16 PNG, прозрачность, оба контакта, возврат, неподвижность ног и отсутствие
новых деталей. Сохранить billing_usage в `pixellab/result.json`, сырой ответ с base64
перенести в игнорируемый `test_reports/defender-shield-taunt-20261011/`.
Если сервис вернёт `failed`, сохранить причину; повторную генерацию автоматически не запускать.
