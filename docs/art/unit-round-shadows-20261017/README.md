# Простые тени в игровой сцене — 2026-10-17

U: добавить под персонажей обычные круглые тени без детализации в существующую
сцену. Изометрия остаётся4:3. Это внедрение общего пятна под обеими сторонами,
включая классовые спрайты и запасные/процедурные фигуры. PNG не редактировались.

- [Поле с тенями](battle.png) — настоящий рендер `HeroHubBattleView`,1600×1200.
- [То же поле без пятен](battle-before.png) — переключён только флаг тени.
- [Все классы](all-classes.png) — строки: Защитник, Разбойник, Лучница,
  fallback (BodySprite/EnemyPresets); слева союзная пара, справа вражеская. В каждой паре
  сначала без тени, затем с ней. Галерея собрана на нейтральном фоне;
  пиксельные проверки выполняются до сборки на прозрачных кадрах.
- [Аудит](render_audit.gd), [проверки](validation.md), [независимое ревью](review.md).

Одно приглушённое овальное пятно лежит под выделением/телом и следует опоре
бойца; поза удара и наклон смерти его не деформируют. Поведение и параметры
принадлежат [контракту визуальной сцены](../../BATTLE_VISUAL_SCENE_CONTRACT.md#круглая-тень-под-фигурой).
Снимки получены при фиксированном idle; они не заменяют ручной F5/арт-приёмку.

Это не перенос [ImageGen-концепта направленных теней](../battlefield-shadows-preview-20261017/README.md)
и не внедрение [пробы прежней2:1 изометрии](../previous-isometry-preview-20261017/README.md).

Повтор: сначала свежий импорт и визуальный gate через `tools/demo/isolate.py`
с `--render-check --only current_art_zoom presentation_contact --screen 0`.
Затем в его изолированном project с отдельным APPDATA запустить Godot
`--path <project> --screen 0 --script <absolute-path>/render_audit.gd -- --output=<folder>`.
Аудит сверяет пиксели, движение, reuse и state/RNG/counters/revision; выход0 означает PASS.
