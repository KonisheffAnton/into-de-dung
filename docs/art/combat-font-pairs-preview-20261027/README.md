## Одинаковые условия

[Исходный кадр](source-battle.png) 1280×850 побайтно совпадает с source-battle.png
из [первого сравнения](../combat-font-preview-20261027/README.md), которое сохранено
без изменений. Исходный PNG не ретушировался и не перерисовывался.
В отличие от первого листа здесь показан весь кадр без обрезки в масштабе 50%.
Четыре полных PNG сохраняют размер 1280×850 и масштаб 100%.

Рендерятся настоящие локальные TTF поверх изображения через HTML/CSS.
КРИТ/ЩИТ/БЛОК/ПРОМАХ/КРОВОТЕЧЕНИЕ используют шрифт букв; значения -12.5,
-28.0, +8.0 и -6.0 — шрифт цифр. Это демонстрационные значения, не события боя.
Знак минуса везде U+002D: у Pixelify нет U+2212. Подмена другим шрифтом запрещена
проверкой cmap всех используемых знаков. Jersey здесь не получает кириллицу.

Во всех четырёх вариантах одинаковые цвета, позиции, размеры и контуры.
Видимая высота цифр нормализована по 0123456789: 40px native, крит 50px;
новые слова 32px, короткие подписи КРИТ/ЩИТ 24px. В листе это 20/25/16/12px.
Обычные слова измеряются отдельно от Щ с нижними элементами; em-размеры различны.
Для короткой подписи отведён одинаковый блок 36px, чтобы её метрики не смещали число.
Контур направлен наружу на 4px native (2px в листе), тень 3px native.
Строки под кадрами показывают знаки без контура. Tiny5 использует вес 400
и значения остальных осей по умолчанию; Pixelify 700, остальные 400.

Цвета: урон #ffe6ce, крит #ffd06d, лечение #79edba, щит #85d9ff,
блок #b7dcec, промах #ebe5d7, кровотечение #ffa6a1.
Верхний боец обрезан самой исходной камерой; это не изменение макета.

## Источники и проверка

TTF, лицензии и метаданные — fonts/. [Происхождение и SHA256](provenance.json).
Pixelify/Tiny5 скопированы из первого пакета побайтно; Jersey/Press Start скачаны
из того же закреплённого коммита Google Fonts. Monogram Extended взят из
[репозитория автора](https://gitlab.com/datagoblin/monogram/-/blob/19fde16e15d229f69e55520bec093d05aee5eca7/source/itch/html-tester/monogram-extended.ttf).
Его CC0 указана на [странице автора](https://datagoblin.itch.io/monogram);
[основание](fonts/monogram-license-source.txt) и официальный текст CC0 сохранены.
Лицензии хранятся в Git побайтно через локальный .gitattributes.

[Рендер](render-preview.cjs): `node render-preview.cjs <node_modules с playwright>`;
нужен установленный Edge для headless-запуска. [Проверки](validation.json):
5 шрифтов загружены, все используемые знаки присутствуют, 28 подписей находятся
в кадре и не пересекаются; проверены назначенные шрифты и 8 строк образцов.
Ошибок браузера нет. PNG просмотрены визуально; независимое ревью APPROVE.
Побиксельное сравнение подтвердило неизменность фона вне областей надписей
с запасом 12px native на контур/тень; отчёт pixel-check.json находится ниже.
Общие проверки и ревью — test_reports/combat-font-pairs-preview-20261027/.
