# Вариант №2 — один резкий удар

U2026-11-14 выбрал [вторую гиперболизированную пробу](../warrior-attack-exaggerated-20261114/README.md)
как основу: нужна одинарная атака и более резкий выпад с акцентом на удар.
Это выбор направления для доработки, не приёмка финальной анимации или интеграции.

Сохранены точные рисунки №2: широкий светлый след с тёплым краем, воин и меч.
Сделан **монтаж существующих кадров**, без нового запроса PixelLab, дорисовки,
трансформаций фигуры или изменения PNG-байтов. Новая геометрия выпада не создаётся:
резче становится ритм существующего рубящего движения и подачи корпуса.

## Монтаж

[edit.json](edit.json) владеет порядком и длительностями.
Исходные индексы от0: `0,2,3,4,11,19,20,21,28,29,30,31,32`.
Первый взмах12–18 исключён;19 служит позой замаха перед оставленным ударом20–21.
Обратный подъём меча22–27 также исключён: после контакта клинок остаётся низко,
след затухает и герой возвращается в стойку. Все индексы идут вперёд без повторов.

| Фаза | Длительность |
|---|---|
| Подготовка | 280мс |
| Выпуск в удар | 20мс |
| Акцент контакта — исходный21, новый7 | 100мс |
| Восстановление | 180мс |
| Пауза между повторами для сравнения | 700мс |

Активное движение580мс; полный показ1280мс. Пауза700мс относится к галерее/GIF,
не к игровому cooldown или длительности боевой команды. Новых механик нет.
Здесь выбран более резкий ритм, чем мягкая подготовительная рекомендация reviewer
(50мс выпуска и200мс восстановления). Окончательное ощущение веса выбирает U.

## Открытые замечания

На11→19 резко меняется угол меча/шарфа;21→28 быстро поднимает корпус после
контакта. Это намеренно короткие переходы, их плавность требует оценки в движении.
Исходная вспышка21 касается нижнего края; монтаж не восстанавливает обрезанные
пиксели. Конечный32 не совпадает с начальным0 по RGBA; шов повторения открыт.
Одобрение упаковки не означает художественной приёмки этих переходов.

База: `main`, `cf60fed3239695b8d1dde59a175d1fe24d96e71e`.
Runtime/core/preview/queue/RNG/save/frozen не меняются, `integration=false`.
Godot/import/full/core/F5/zoom/DPI/performance не запускаются для этой пробы.
Чужие main_menu.tscn и battlefield-reference-03 сохраняются; без push/расписаний.
