# Idle: дыхание с движением рук и щита

2026-10-10, base `e4e04e7ea9e991d5c428e292566c657167b3a20a`, main, без push.
U: направление [предыдущего дыхания](../defender-idle-breathing-20261010/README.md)
верно, но щит/рука слишком статичны, персонаж выглядит монолитным. Требуется
мягкое движение всего тела в такт дыханию с сохранением направления и опоры.
Образ/приёмка — [ART_DIRECTION](../../ART_DIRECTION.md), провайдер —
[GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md). Игровой PNG/масштаб80%/гаммаА/
посадка не меняются; это отдельный предпросмотр, не интеграция в игру.

## Запрос PixelLab

Один вызов `/v2/animate-with-skeleton-v3`,12 поз, seed20261012.
Вход `pixellab/reference-128.png` — тот же native96×96 экспорт игрового PNG
с16px прозрачного поля, без повторного рисования и масштабирования.
Исходные18 суставов переиспользованы из оценки предыдущего этапа; новой
оценки скелета нет. Схема сверена по [официальному OpenAPI](https://api.pixellab.ai/v2/openapi.json).

`prepare-request.cjs` воспроизводит запрос без изображения base64 и ключа:

- корпус поднимается до2.5px на вдохе и слегка смещается вбок;
- таз/колени получают меньшую долю переноса веса, ступни закреплены;
- локти и кисти движутся относительно плеч с небольшой задержкой;
- ориентиры лица перемещаются вместе, без изменения направления взгляда;
- порядок глубины суставов постоянен; кадров12, цикл2.4s,200ms на позу.

Параметры описывают задание, а не гарантии для сгенерированных картинок.
Оригиналы и фактический usage сохраняются в `pixellab/`; геометрию выхода
нужно оценивать по PNG/GIF. Никакой постобработки поз и регистрации кадров.

## Предпросмотр

`prepare-preview.cjs` сравнивает предыдущую петлю8×300ms и новую12×200ms
на общей шкале24×100ms; повторяются исходные кадры без интерполяции.
В каждой серии обрезаются только16px прозрачного поля до96×96.
Общий масштаб80%, сверху дополнительное увеличение×4, ниже приблизительные
размеры камеры75/100/125%. Это сравнение вне игры, не запись F5.
Нужен `SHARP_MODULE` с путём к модулю Sharp.

[Сравнение с прежним idle](comparison.gif): слева предыдущий подъём верха,
справа новая проба. [Двенадцать поз](filmstrip.png), [петля96×96](idle-native.gif),
[проверки исходников](pixellab/frames-validation.json).
GIF-энкодер объединил совпадающие кадры сравнения: фактически16 кадров
по100/200ms, суммарно2.4s. Native GIF сохраняет12×200ms. Это удержание кадров,
а не интерполяция или изменение скорости одной из сторон.

PixelLab вернул12 PNG128×128; usage3generations подписки, charged=true,
без новой оценки суставов. Стык12→01 меняет103 пикселя альфа-маски и897RGBA,
внутренние переходы —1–209alpha и11–1186RGBA. Стык не крупнейший переход;
само по себе это не доказывает художественную плавность. Пиксельная дискретность
движения и небольшое мерцание цветов остаются для оценки пользователя.

Независимое ревью **APPROVE как отдельной пробы**: рука с мечом и щит меняются
относительно корпуса, видимого разворота/шага/скольжения нет, маски обеих стоп
совпадают во всех12 кадрах. P3: почти одинаковые01→02 и08→09 соседствуют с
более крупными изменениями; при200ms на позу ритм может казаться ступенчатым.
Это не финальная художественная приёмка и не проверка в F5.

Runtime не менялся; игровой PNG/масштаб80%/гаммаА/посадка сохранены.
Godot/tests/F5/Editor/DPI/GPU и замеры производительности не запускались.
Направление прежней пробы принято как основа, финальный клип ждёт отзыва U.
Подключение, lifecycle/reset/restore и остальные действия бойца остаются
отдельной работой после выбора idle. Тени/динамический свет не добавлялись.
