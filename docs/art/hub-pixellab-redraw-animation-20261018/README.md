# PixelLab: две диорамы и анимации выбранных людей

U2026-10-18 поручил передать в PixelLab две приложенные диорамы, затем три
выбранных изображения людей: по пять простых анимаций толпы, кузнеца и пары
продавец–покупатель. Это новые отдельные пробы. В игру они не внедряются.

## Исходники

Пять вложений пользователя сохранены побайтно в `sources/`. Они являются
основанием этого этапа; отвергнутый cleanup не используется. Выбор этих трёх
изображений людьми не означает приёмку будущих анимаций или runtime-интеграции.
Совпадение RGBA с файлами прежней серии не найдено: номера прежних проб
не приписываются новым вложениям автоматически.

Для анимации PixelLab v3 принимает не более256×256. В `inputs/` — копии:
границы содержимого найдены по alpha≥32, обрезанный прямоугольник вписан
nearest в232×232, затем помещён по центру прозрачного256×256. Это не новые
нарисованные позы. Alpha внутри обрезки сохранена при nearest; слабый ореол
вне неё не входит в рабочую копию. Размер/обрезка/смещение/SHA записаны.
Все исходные PNG остаются неизменными.

## Две перерисовки

Использован `/image-to-pixelart-pro` с полными исходниками1672×941, по одному
запросу на палитру. Этот режим сам определяет пиксельную сетку и выходной размер;
отдельный `unzoom` не добавлялся. Запрошено сохранение композиции, заброшенных
домов, водопада, кузницы, лавки и мага; башня без входа и наружной лестницы.

| Источник | Результат PixelLab | Наблюдение |
|---|---|---|
| [Яркий](sources/bright.png) | [479×307](dioramas/bright.png) | Заметно грубее, насыщеннее; мелкие детали сливаются. |

обратно в16:9, повторных генераций для диорам не запускалось.

## Заданные движения

Каждая проба — отдельный запрос `/animate-with-text-v3`, запрошено8кадров, первый и
направляющий последний кадр одинаковы. Прозрачный фон, неподвижная камера и
стопы, сохранение количества/облика фигур заданы текстом; это не гарантия
геометрической фиксации. `enhance_prompt=false`, seed у каждого запроса свой.

| № | Толпа | Кузнец | Торговец с покупателем |
|---|---|---|---|
| 01 | Короткие реплики | Один удар | Открытая ладонь |
| 02 | Оглянуться | Два лёгких удара | Перечисляет доводы |
| 03 | Обсуждение карты | Размеренный удар | Показывает товар |
| 04 | Тихий разговор | Короткий рабочий ритм | Убеждает покупателя |
| 05 | Слушатели | Проверка и удар | Весёлая история |

Наковальня отсутствует в выбранном изображении кузнеца. Движение заказано
к рабочей точке рядом с клещами; наковальня остаётся отдельным предметом
диорамы. Точное совмещение с ней потребует отдельного выбранного размещения.

Во всех15анимационных запросах API вернул9кадров вместо запрошенных8. Все
полученные кадры сохраняются и проигрываются; первый не объявляется побайтной
копией входа (его RGBA отличается после обработки провайдера).

Кадры `animations/<категория>-<номер>/frame-*.png` — оригинальные PNG PixelLab.
Контактный лист и горизонтальный спрайтшит только собирают эти кадры.
`loop.gif` — удобный просмотр160мс/кадр: GIF имеет общую палитру255цветов
и бинарную прозрачность. Эталон цвета/alpha — исходные RGBA PNG, не GIF.
Галерея проигрывает сами PNG с изменяемой скоростью (по умолчанию6кадр/с).

## Происхождение и проверки

Официальная схема сверена2026-10-18:
[PixelLab API](https://api.pixellab.ai/v2/llms.txt),
[OpenAPI](https://api.pixellab.ai/v2/openapi.json); нужная часть в
[api-contract.json](api-contract.json). Секрет читается только из локального
DPAPI и передаётся официальному API; в этом пакете его нет.
Полные запросы/ответы и защищённый от повторной отправки runner:
`C:/Users/Aston/.codex/generated_images/hub-pixellab-redraw-animation-20261018/`.
Запросы здесь заменяют base64 на относительный файл и SHA; восстановленное
тело сравнивается с фактически отправленным запросом. Неопределённый POST
не повторяется автоматически, сохранённый job ID используется для опроса.

`package.py` читает только уже сохранённые ответы и проверяет PNG против их
хэшей. `validate.py` проверяет пять копий вложений,17 запросов, PNG/alpha,
кадры, представления и локальные ссылки. Проверки и независимый обзор:
[отчёт этапа](../../../test_reports/hub-pixellab-redraw-animation-20261018/README.md).
Статические проверки не заменяют playback в браузере, Godot/F5/editor/DPI/GPU
или художественную приёмку. Пользователь выбирает понравившиеся варианты;
следующая генерация/подключение автоматически не начинается.
