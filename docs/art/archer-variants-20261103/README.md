Все10 PNG1254² сохранены побайтно из встроенного image_gen, без локальной
ретуши. Ориентиры: выбранный Разбойник02 — компактность и композиция;
лучник02 предыдущей серии — палитра, лук и снаряжение. Это новые рисунки,
не пиксельно точный монтаж или готовые прозрачные игровые спрайты.
Размеры фигур, кисти, хват, единая пиксельная сетка и посадка требуют выбора
и подготовки перед анимацией. У17 лук расположен по диагонали вместо
предложенной горизонтали; узнаваемое снаряжение сохранено.

Галерея встраивает все10 изображений и переносится одним HTML. Её уменьшение
использует обычную браузерную фильтрацию без дополнительного nearest-прореживания.
Общий лист — снимок HTML, а не повторная генерация/перерисовка ассетов.
HTML исключён из Git как воспроизводимый дубликат PNG; сборка после checkout:

```powershell
node docs/art/archer-variants-20261103/build_gallery.cjs
node docs/art/archer-variants-20261103/check_gallery.cjs
```

Builder использует PNG и SHA пакета. `--verify-originals` дополнительно сверяет
байты с локальными выдачами, если они доступны. Browser check требует Edge и
Playwright (путь можно задать `PLAYWRIGHT_MODULE`); готовый HTML от них не зависит.
Проверки:10 уникальных PNG,10/10 исходных байтов; Edge headless —10 карточек,
номера11–20, встроенные изображения, увеличение1254², Escape/кнопка,
390px без overflow,0 ошибок — [gallery-validation.json](gallery-validation.json).
Переносимость и ревью — [validation.json](validation.json).
Независимое read-only ревью: APPROVE;10 SHA/побайтных исходников и комплектность
пакета подтверждены. Оно не заменяет художественный выбор пользователя.

Игровые сцены, ресурсы, анимации и shader не менялись. Godot/import/full/core/F5
не запускались. Выбор модели, генерация анимаций и внедрение этой серии не поручены.
