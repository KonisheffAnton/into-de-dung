# Огонь29: интенсивность и свободные кончики

U попросил чуть интенсивнее огонь и убрать обрезание языков соседними тайлами.
Main, base `6d4017bc0e16b10fb18a3e0f59724bdd2f40d75f`.
Поведение принадлежит [контракту сцены](../../BATTLE_VISUAL_SCENE_CONTRACT.md#выбранный-огонь29--2026-11-07).

Причина среза — ромбовая маска всей композиции. Каменное основание осталось
под этой маской; отдельный слой исходных языков теперь свободен от неё.
Покрытие получено из26 групп/145 прежних raw PixelLab, RGB скопирован точно
из выбранных96 кадров. Shader gain1.12 делает языки немного ярче. Скорость,
позы и цикл7.68с прежние; новых генераций нет. Слой следует тому же кадру,
положению и масштабу основания, собственных часов нет.

У выбранной серии все пиксели с alpha>8 вне ромба лежат над задними рёбрами:
обычный Y-sort уже располагает их после соседнего пола. Глобальная глубина,
сортировка Board, стены, фигуры и логика огня не менялись. Пакет добавляет
19,070,976 общих RGBA байт; итог обоих наборов38,141,952 байт, без mipmaps.
Это расчёт декодированных текстур, не замер VRAM или performance.

Ресурсы: [overlay и provenance](../../../assets/art_presets/approved/fire29_flame_overlay_v1/README.md),
[сборщик](../../../tools/art/build_fire29_flame_overlay.py).
Исходная выбранная анимация, старые атласы и шипы сохранены.
В старом builder исправлена только проверка состава: допускается уже
отслеживаемый `.gitattributes`; генерируемые байты остаются прежними.

Свежая проверка: `test_reports/demo-90949cdcc58842068f205469b116896c/`.
Import/startup PASS; fire29_overlap114/0, fire29_animation165/0,
visual_scene_contract106/0, dungeon_room_comparison1983/0.
GPU-контроль вернул204 видимых пикселя за ромбом без изменений внутри него
относительно той же сцены с ромбовой маской. Gain1.12 относительно gain1.0:
11102 пикселя ярче,0 темнее. Проверены глубина фигуры,96 синхронных слотов,
точный rendered возврат к0, pause/resize/reuse/retire, live state/RNG.
Оба builder `--check` PASS; независимое ревью APPROVE без блокирующих замечаний.
Ревью отдельно подтвердило23,743 пикселя alpha>8 за ромбом суммарно по96 кадрам,
