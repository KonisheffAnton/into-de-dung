# Сгорбленные хобгоблины — новая десятка PixelLab

Последнее U2026-11-14 уточняет [прежнюю серию](../hobgoblins-ten-20261114/README.md):
ниже Воина11, головы крупнее, ноги короче, меньше мелких деталей;
**сгорбленные/скорченные, тощие, но коренастые**. Это заменяет прежнюю тучность.
Сохраняются бледная/альбиносная кожа и гротескная асимметрия вымышленных существ.
Коренастость передаётся шириной плеч, плотными предплечьями и крупными кистями,
а худоба — узким торсом/талией, впалым животом, угловатыми плечами и локтями.

## Что передано PixelLab

10 независимых описаний/seed в [requests.json](requests.json).
Текущий [Воин11](references/warrior11.png) — точная копия runtime `red_bastion/still.png`;
[происхождение/SHA](references/source.json), стиль — ART_DIRECTION2026-11-03.
Контур, детализация и светотень взяты как style reference; палитра своя бледная.
Голова около40% высоты, низкая сжатая поза, согнутые очень короткие ноги,
крупные простые пиксельные группы и2–3 тона вместо мелкой фактуры/жилок/морщин.

Первый пробный запрос192×160 дал хорошее направление формы, но высоту148px
при152px у Воина — разница только4px. [Проба](pilot/too-tall-192x160.png)
и [её происхождение/расход](pilot/source.json) сохранены, в десятку не входят.
Итоговые запросы используют **192×128**: высота рисунка физически меньше
152px эталона без локального уменьшения. Это новая генерация, не resize пробы.
Схема endpoint проверена: [api-schema.json](api-schema.json).

Полные планы, принятые jobs, запросы и ответы вне Git:
`C:/Users/Aston/.codex/generated_images/hobgoblins-hunched-ten-20261114/`.
Финальные10 — в подкаталоге `final192x128/`. Принятые POST не повторять;
при обрыве сети продолжать по сохранённому ID. Ключ хранится только через DPAPI.

## Показ и воспроизведение

`variants/` содержит побайтные исходные PNG PixelLab192×128.
Для сравнения в общей ячейке256² исходник лишь вставляется на прозрачный холст:
x=32, y=200−нижняя граница alpha. **Масштаб и пиксели не меняются.**
Это выравнивание статических превью по нижней границе, не утверждённая игровая
опора: край оружия может лежать ниже стопы. Воин показан в исходном масштабе.

[Общий лист](contact-sheet.png), [малый лист](contact-sheet-small.png),
[сравнение с Воином11](style-compare.png), [галерея](gallery.html).
HTML исключён из Git как воспроизводимый дубликат; исходники/скрипты сохранены.

```powershell
python docs/art/hobgoblins-hunched-ten-20261114/build_gallery.py
python docs/art/hobgoblins-hunched-ten-20261114/validate_package.py
```

Экспорт требует внешних сохранённых ответов, сборка/валидация — только пакета
в репозитории. Новые позы локально не рисуются; контактные листы имеют
просмотровые подписи/фон и nearest-увеличение готовых пикселей.

## Результат и проверки

Получены все10 новых исходников192×128. Высоты силуэтов по номерам:
126,128,125,120,128,126,128,128,128,128px — каждый ниже Воина11 (152px).
Размер достигнут генерацией; локального уменьшения фигур нет.
Головы крупнее относительно тела, спины согнуты, талия/живот худые,
плечи и предплечья плотные; мелкая фактура в целом проще прежней серии.

[Происхождение/размеры/края](sources.json), [10 фактических payload](request-validation.json),
[целостность](validation.json), [браузер](browser-check.json), [ревью](review.md).
Расход110 генераций:10 на отклонённую пробу +100 на итоговую десятку;
[учёт](usage.json), повторных POST нет, API billing USD0.

PASS py_compile4,10 rawSHA/RGBA/alpha,10 точных вставок на прозрачный холст,
размеры меньше эталона,21 embedded PNG,3 контактных листа, LF-хеш manifest.
IAB smoke:10 загруженных квадратных карточек,3фона, эталон,
открытие/закрытие увеличения623,69². Независимое APPROVE целостности
и измеренного соотношения роста; это не пользовательская художественная приёмка.

**Замечания:** все10 raw касаются нижнего края; №2/5/7/8/9/10 также верхнего.
Ориентир105–116px и свободные поля из промпта не выполнены. Подложка256²
сохраняет исходные пиксели и не восстанавливает возможную обрезку.
Границы нужно довести перед анимацией/игровым использованием выбранных фигур.
№8 заметно грубее остальных по пиксельной фактуре. Это не скрыто нормализацией.
Направление всех десяти отдельно не утверждено; приёмка остаётся за U.
