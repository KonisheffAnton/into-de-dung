Задача `hub-buttons-wood-five-pairs-20261123`, base commit `373a220ea810ab00df06136ba93e1ca80d0dc625`. Это визуальные концепты; runtime-интеграции нет.

Отправлено ровно пять отдельных PixelLab Pro jobs на `/v2/generate-image-v2`, каждый с prompt из `briefs.json`, размером 688×384, `no_background=false` и одним reference `imagegen.png` размером 1672×941.
