# Чуть более яркая палитра всех текущих персонажей

U, 2026-10-17: «Примени эту палитру к текущим персонажам всем».
Ориентир — [цветовая проба эталонного стражника](../defender-brighter-palette-20261017/README.md).
Внедрён общий RGB shader: насыщенность ×1.10, мягкий подъём полутонов
`c + 0.18*c*(1-c)`, с защитой тёмных тонов через smoothstep0.08–0.30.
Это перенос характера выбранной палитры на разные материалы, не точная LUT
из ImageGen-картинки, которая отличается от исходника разрешением и деталями.

[Сравнение до/после](comparison.png) и [игровой кадр](battle.png).
В каждой паре слева прежняя палитра, справа новая; масштаб рисунка ×2.
Defender, Rogue, Archer получают коррекцию во всех своих подключённых кадрах,
для обеих сторон. Также подключены три запасных вражеских рисунка и BodySprite
помощников. Иконки карточек/эффекты/HUD/тайлы не являются рисунками персонажей.

Shader включён явно только в `scenes/demo/visuals/art_trial_unit.tscn`, которую
используют текущий HeroHubBattleView и отдельная пробная сцена поля.
Классовая коррекция идёт после маски одежды, до расчёта покрытия; Archer по-прежнему
не получает маску одежды. Fallback использует обычную выборку своей текстуры.
Прозрачность, faction modulation, fade смерти, исходные PNG, игровые позы,
anchors/native grids, отражение, ресурсы кадров/их длительности сохранены.
Другие материалы получают исходную палитру при default strength0.

`render_audit.gd` — воспроизводимое сравнение тех же исходников/материалов
при strength0/1 на прозрачном SubViewport: все still и подключённые кадры,
фракционные tint, полупрозрачная modulation, варианты одежды. Сравнивает alpha
попиксельно и проверяет изменение RGB/рост средней светлоты видимых пикселей.
Этот аудит дополняет обычные игровые runners; не подменяет плейтест.

Запуск в импортированной изолированной копии проекта:
```powershell
<Godot> --path <project> --screen 0 --script res://docs/art/character-brighter-palette-20261017/render_audit.gd -- --output=<absolute-output-directory>
```

Проверки и ограничения записаны в `validation.json`, `render-audit.json`,
`review.md` и `closeout.json`. Первый промежуточный current_art_zoom выявил
сдвиг texture между секциями сцены; исправление проверено отдельным чистым запуском.
Финальная художественная оценка/F5/editor/DPI-матрица остаются за пользователем.
Новых генераций, PixelLab, изменений механики и автоматического следующего этапа нет.
