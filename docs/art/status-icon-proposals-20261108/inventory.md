# Что уже есть и что предлагается обозначать

Сверка кода2026-11-08, UI commit `d0832d083556ca89bf2c157387ac74694059b550`.
Лист A/B/C — **P**, выбор смысла/силуэта. Это векторные схемы на основе
существующей SVG-системы UI, не принятый финальный пиксельный арт и не подключение
в runtime. Новые растровые пробы после выбора следуют [GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md).

## Фактические источники

[`BattleStatusPresentation.entries`](../../../scripts/demo/battle_status_presentation.gd)
публикует9 типов статусов. В
[`BattleDemoIsoVisual._status_icon`](../../../scripts/demo/battle_demo_iso_visual.gd)
подключены **три** готовых SVG: [кровотечение](../../../assets/placeholder_battle/bleeding_icon.svg),
[горение](../../../assets/placeholder_battle/burning_icon.svg),
[мокрота](../../../assets/placeholder_battle/wet_icon.svg).
Яд и кислота рисуются кругами с бликами. Остальные непредставленные типы имеют
ромб-заглушку; статусы с отдельным эффектом на фигуре исключаются из нижнего ряда.
Поэтому отсутствие маленькой текстуры не означает отсутствие визуала статуса.

| Тип / ID | Текущий показ | Образ для выбора |
|---|---|---|
| Кровотечение `bleeding` | SVG, стаки/срок | Рана и красная капля |
| Горение `burning` | SVG, отдельный огонь | Пламя без ромба клетки |
| Яд `poison` | Круг с бликом, стаки/срок | Тёмно-зелёный череп/яд |
| Кислота на бойце `acid` | Круг с бликами | Кислота разъедает предмет |
| Оглушение `stunned` | Звёзды возле головы | Белые звёзды над головой |
| Путы `entangled` | Корни/путы у фигуры | Коричневые связанные ноги |
| Заморозка `frozen` | Лёд вокруг фигуры | Лёд, препятствующий движению |
| Мокрота `wet` | SVG капли | Голубая вода без ледяных граней |
| Магический щит `shield` | Отдельный щит, HP/попадания | Светлая защитная оболочка |
| Поднятый щит `raised_shield` | Подпись «ЩИТ90%» | Физический щит перед ударом |
| Оппортунист `opportunist` | Буква режима/готовность реакции | Уходящая нога и догоняющий удар |
| Контратака `counterattack` | Буква режима/готовность реакции | Ответный разворот клинка |
| Прикрытие `cover` | Буква режима/щит/готовность | Щит между двумя фигурами |
| Ожидает хода `pending` | Подпись «ЖДЁТ ХОДА» | Фигура с часами |

Последние5 строк — отдельные поля проекции/режимы, не новые enum статусов.
Заряд и готовность реакции используют одно семейство с различием заполнения;
новое состояние боя для этого не требуется. Усиление оружия остаётся подробностью
осмотра; ресурсы HP/броня/равновесие/действия не дублируются значками эффектов.

## Клетки

Данные собирает
[`BattleDemoBoard._build_environment_index`](../../../scripts/demo/battle_demo_board.gd),
fallback рисует [BattleEnvironmentVisual](../../../scripts/demo/battle_environment_visual.gd).
Полноразмерные сцены огня/кислоты/шипов/ловушек — графика мира, а не готовые
маленькие иконки. Предложенные значки могут использоваться в осмотре клетки;
выбор места их показа и интеграция ещё не выполнены.

| Тип / ID листа | Фактическое состояние | Отличие символа |
|---|---|---|
| Огонь `fire_on_tile` | Горящая клетка, анимированная сцена | Пламя на ромбе пола |
| Лужа кислоты `acid_pool` | `hazards.acid`, кислота на полу | Неглубокая пузырящаяся лужа |
| Шипы `spikes` | Шипы/кальтропы | Уже выставленные острые шипы |
| Труп `corpse` | Один/несколько тел; есть счётчик | Лежащее тело/кости на земле |
| Будущий обвал `collapse_warning` | Отмеченная под разрушение клетка | Трещина и осыпающийся край |
| Напольная ловушка `floor_trap` | Механизм на полу | Нажимная плита/механизм |
| Настенная ловушка `wall_trap` | Механизм в стене с направлением | Стена и летящий из неё болт |
| Глубокая кислота `deep_acid` | `TerrainType.DEEP_ACID`, смертельная | Кислота и погружение, отличное от лужи |
| Провал `void` | `TerrainType.VOID`, включая клетку после обвала | Тёмная дыра/оборванный пол |
| Опасная поверхность `hazard` | Обобщённый `TerrainType.HAZARD` | Общий знак опасности без выдуманной стихии |

Настенная ловушка поворачивает один символ по направлению. Вооружённость —
акцент/заполнение того же символа. Постоянного состояния «потраченная ловушка»
в текущей проекции нет; после срабатывания она убирается. Вода/масло как отдельные
состояния клетки не объявлены; `wet` относится к персонажу. Высота — геометрия,
обычный пол/стена — основа поля. Удар, лечение, срабатывание ловушки и летящие
обломки — события/анимации, не дополнительные постоянные значки.

## Критерии отбора

1. Узнавать предмет/действие по силуэту: текущий базовый значок над фигурой16px,
   схемы имеют viewBox32; показ32/64 служит увеличением, а не игровой приёмкой.
2. Не различать яд/кислоту только цветом: у яда череп, у кислоты разрушенный край.
3. Для трупа использовать горизонтальную позу/землю, а не зелёный череп яда.
4. Путы коричневые, оглушение белое, кровотечение красное, яд тёмно-зелёный,
   кислота ярко-зелёная — как [цвета статусов](../../ART_DIRECTION.md#цвета-текста-статусов--2026-11-08).
5. Числа стаков/срока остаются снаружи символа. Проверить реальные16px и75%
   zoom перед внедрением: схема32px сама по себе такую приёмку не заменяет.
6. Реакции и глубокая кислота сложнее простых стихий; их распознаваемость без
   подписи требует отдельного отзыва U. Три рисунка не доказывают узнаваемость.
