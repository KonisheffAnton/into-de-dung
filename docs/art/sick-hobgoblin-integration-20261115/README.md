# Нездоровый хоб-гоблин в игре — 2026-11-15

По выбору U внедрён Рваноух под именем «Нездоровый хоб-гоблин»:
idle3 основной, idle2 редкий, рык1 из последней пятёрки и смерть1 с закрытыми
глазами. Рык — косметический жест; у противника обычный ближний удар без
добавленных способностей. Стартовые числа выбраны ведущим: HP24, движение3,
равновесие4, физический удар3+2, воздействие2, брони нет.

Поведение, частоты и совместимость принадлежат
[SICK_HOBGOBLIN_V1](../../SICK_HOBGOBLIN_V1.md).
Каталог4 добавляет одного монстра к пяти классам; каталоги1–3 не мигрируют.
Найм, лимит отряда, форма profile7 и сохранённый план похода прежние.
Воспроизвести: обычный запуск → меню → хаб → поход → первый бой.

без увеличения маленького врага. Сгорбленный силуэт и рваная ткань сохранены.
Противник в покое смотрит влево, в атаке временно разворачивается к цели.

при смене владельца/облика/retire. Действие или контроль прерывает жест.
