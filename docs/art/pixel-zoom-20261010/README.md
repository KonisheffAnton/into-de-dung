## Сравнение и пределы

Адресный `current_art_zoom` показывает настоящий экран похода на сессии фабрики,
PNG75/100/125% при viewport1280×850 и1440×1000. Парные кадры75% отключают материал
на тех же фигурах без замены PNG/позиции. `sampling-player/enemy.png` показывает
до/после с увеличением уже отрисованных пикселей×3; это проверка растра,
не другой художественный исходник. Проверены parent/self alpha и изоляция state.
Дополнительный canvas0.833×0.917 со смещением(.5,.25) проверяет дробный transform;
это моделирование canvas, не проверка DPI/масштабирования окна ОС.

Наблюдение ведущего: при отдалении меч/край щита меньше распадаются на одиночные
пиксели, но результат мягче. Простая nearest-квантизация без покрытия давала
более рваный край на75% и оставлена только в промежуточных снимках отчёта.
Не объявляется полное устранение сглаженности: дробный масштаб с уменьшением
не сохраняет все тонкие пиксельные детали. Форма исходника/кант, повторение земли,
цвет/трава/стыки/посадка, арт/анимации/баланс ещё требуют пользовательской оценки.
Для значительного уменьшения нужен отдельный подготовленный LOD; текущий
footprint ограничен2 ячейками. GPU/плавность/AI p95 не измерялись.
