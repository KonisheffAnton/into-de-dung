## Исходник и подготовка

[Полный прозрачный исходник](model/source-full.png) создан из выбранного концепта
встроенным ImageGen как производный cutout: это художественное извлечение,
не математически точная сегментация. Точный источник и запрос — в
[происхождении cutout](model/cutout-provenance.json). Исходник сохранён без правок.

[Вход 256×256](model/input-256.png) подготовлен из полного исходника: alpha≥128
задаёт прямоугольник фигуры с запасом 2 пикселя, nearest масштабирует полный
силуэт до высоты 152 px, опора сапог размещена около (128,200).
[Манифест преобразования](model/transform.json) содержит размеры, области,
масштаб, смещение и SHA-256. Это техническая посадка для PixelLab, не новая поза.

## Движения

| Тип | 1 | 2 | 3 |
|---|---|---|---|
| Ожидание | Тихое дыхание | Настороженный перенос веса и поправка ножа | Дыхание и лёгкое движение шарфа |
| Смерть | Падение набок | Через колени на спину | Вперёд через колени |
| Способность | Скрещивание ножей и сильный разводящий взмах | Короткий парный взмах | Низкая подготовка, скрещивание, возврат |

Промпты просят оставить движение около исходных стоп и сохранить облик,
ракурс, два ножа и прозрачность. Для ожидания и способности вход передан также
как `last_frame`; это направляющая конечной позы PixelLab, не гарантия точного
совпадения. Смерть не получает `last_frame` и должна удерживать падение.

## API и экспорт

Перед отправкой проверены официальная OpenAPI-схема PixelLab и баланс. Использован
`POST /v2/animate-pixminimax`: 256×256, `frame_count=32`, прозрачность,
`enhance_prompt=false`; результат содержит 33 кадра на клип. Каждый запрос
записан до POST, каждый принятый `background_job_id` сохранён, продолжение
выполняется только через GET. Неопределённые POST нельзя повторять вслепую.
Полные ответы API находятся вне Git в
`C:/Users/Aston/.codex/generated_images/rogue-animation-02-20261101/`.
Ключ остаётся только в уже существующем `C:/Users/Aston/.codex/secrets/pixellab.dpapi`;
его не копировали в пакет и не записывали в журналы.

Все 9 заданий завершились без ошибок; фактический расход — 45 генераций
(5 на клип), баланс снизился с 1777,3 до 1732,3. `pixellab/<тип>-<вариант>/frames/`
сохраняет PNG провайдера побайтно; соседние
`spritesheet.png`, `preview.gif`, `filmstrip.png`, `clip.json` предназначены

## Проверки и ограничения

`validate_package.py` прошёл: девять экспортов, 297 оригинальных PNG,
297 ячеек листов, размеры, alpha, SHA-256, первые кадры, GIF и уникальные кадры.
`validate_gallery.py` прошёл: все 20 встроенных изображений побайтно совпадают
с файлами; синтаксис JS дополнительно проверен `node --check`. GIF-кодировщик
объединяет соседние одинаковые кадры, сохраняя общую длительность.

В каждом первом кадре видимая область и alpha совпадают с входом, но 20 RGB
пикселей в полностью прозрачной области отличаются. Все три idle и три
способности заканчиваются в позе, которая не совпадает с входом по RGBA;
у конечных кадров PixelLab alpha стала двухуровневой, в отличие от мягкой alpha
исходника. Это возможный видимый шов idle и неточный возврат способности;
пользователю нужно просмотреть проигрывание. У девяти клипов нет пикселей на
краю или в отступе 8 px. Подробные расхождения — в `validation.json`, без
ручной замены кадров.
Браузерная проверка копии HTML без соседних ассетов:9 canvas/20 встроенных
изображений, скраббинг, idle-loop, одноразовое удержание конца, restart/step,
масштаб/скорость/фон,390px без overflow, ошибок0 — [browser-validation](browser-validation.json).
Художественная приёмка плавности, сохранения модели, падений и возврата в
стойку остаётся за пользователем. Runtime, Godot и игровая интеграция не
проверялись и не выполнялись.
