# Значки на дереве, числа без плашек — 2026-11-08

Main; base `e025abf93837acc575241677d8eb34daa3c3d402`.
U попросил убрать чёрные подложки у стаков/тиков и добавить тематический
деревянный фон с металлической рамкой под сами значки.
Выбор — [ART](../../ART_DIRECTION.md#предложения-значков-состояний--2026-11-08),
поведение — [HUD](../../BATTLE_HUD_SCENES_V1.md#значки-состояний-a--2026-11-08)

## Источник и сборка

PixelLab `create-image-pro-flash` подготовил32px железный край, но удалил дерево
из центра: `raw-frame.png` сохранён как отклонённый результат, в игру не входит.
`edit-image-pro-flash` заполнил центр непрозрачным деревом, сохранив край:
рабочий источник `wood-iron-panel.png`. Два запроса/ответа с seed, job ID,
usage и SHA сохранены рядом; расход5+5=10 generations. Палитра панели16 цветов.

[Сборщик](../../../tools/art/build_status_icon_frames.py) уменьшает только панель
до16px nearest и накладывает существующий A без сдвига/масштабирования/перекраски.
Все48 исходных A и каждый непрозрачный пиксель сохранены; композиции16/32,
две чистые панели и SHA-манифест — [ресурсы](../../../assets/art_presets/approved/status_icons_framed_v1/README.md).
Lossless, nearest, без mipmaps/fix_alpha_border/premult.

## В бою

По последнему уточнению U у персонажей на поле нет подложки/рамки:
их ряд использует исходные прозрачные A. Дерево/железо остаётся у значков
в компактном осмотре, карточке справа и осмотре клеток.
Геометрия HUD и игровые размеры прежние. Стаки сверху, срок снизу; вместо
прямоугольных плашек только тонкий тёмный контур шрифта. `+N` также без плашки.
Глифы привязаны к целым экранным пикселям; шрифты полос ресурсов не меняются.
