# Пять концептов с данжевой атрибутикой — PixelLab

Задача `hub-buttons-dungeon-five-pairs-20261123`, base commit `e28135645f3992bd8b2adc7fc1670bdec3f8dd44`. Только визуальные предложения; runtime-интеграции нет.

Отправлено ровно пять PixelLab Pro jobs на `/v2/generate-image-v2`, с точными prompts из `briefs.json`, размером 688×384, `no_background=false` и общим reference G-W03 размером 1672×941. Все пять завершены. Фактическое списание — 25 generations за job, 125 всего. Job IDs, prompts, sanitized requests, usage, raw evidence paths и SHA-256 находятся в [manifest](receipts/manifest.json) и пяти файлах [receipts](receipts/).

Полные запросы (включая Base64 reference) и ответы хранятся вне Git в `test_reports/hub-buttons-dungeon-five-pairs-20261123/pixel-raw/`. Санитизированные receipts не содержат Base64 или секретов. Повторных запросов не было.

## Визуальная проверка

Все варианты сохраняют четыре верхние вкладки, три карточки отряда и трёх героев во дворе. Во всех пяти формы и рамки передают атрибуты подземелья, а большая часть лиц кнопок остаётся матовой древесиной. Малые подписи при 688×384 довольно мелкие.

| Вариант | Наблюдение |
| --- | --- |
| D01 — врата и ключи | Дверные створки, скважины, цепи и каменный портал у CTA узнаются сразу; ключ у кнопки крупный. |
| D02 — своды и факелы | Каменные арки и боковые факелы явно задают силуэт; деревянные вкладки читаются внутри кладки. |
| D03 — снаряжение искателя | Верёвка, карта, крюк и фонарь заметны; слева вокруг интерфейса оставлено серое свободное поле. |
| D04 — ловушки и механизмы | Направляющие, шестерни и рычаг выделены; крупная механическая рамка CTA частично закрывает двор, но текст «В путь» остаётся читаемым. |
| D05 — древний склеп | Каменные надгробные рамки, черепа и костяные зажимы хорошо заметны; древесина остаётся на кнопках. |

У изображений нет постобработки; сохранены исходные предложения PixelLab.
