## Происхождение и ограничения

[reference.png](reference.png) сохранён побайтно из вложения пользователя.
[manifest.json](manifest.json) содержит точные финальные запросы, порядок входов
и пути исходных PNG встроенного image_gen. Стилистический образец — вложение;
эталон защитника и tile-geometry-guide.png — камера/посадка/геометрия.
prompts.json — исходный план, prompts-final.json — промежуточная редакция;
фактические запросы итогов принадлежат manifest.json.
Первая попытка G01 с разными направлениями сохранена в iterations/G01-first.png.
Всего 16 вызовов ImageGen, 15 итогов; расход инструмент не сообщает. PixelLab: 0.
Оригиналы не перерисованы, не растянуты и не очищены вручную; alpha не менялась.

Фигуры показаны сверху в передних ракурсах, преимущественно вправо; задних видов нет.
Существа размещены на клетках общего пола без отдельных подставок под ногами.
Край тела слизи иногда выглядит как основание; это часть нарисованного существа.
**Точная наша проекция 4:3 не достигнута:** ряд ромбов заметно более плоский.
Не выдавать передачу эталона в запросе за точное совпадение результата.
Посадка и одинаковый угол каждого корпуса не установлены измерениями.
Для точной игровой геометрии нужна отдельная доводка выбранного варианта.
Некоторые близкие версии сохраняют почти ту же композицию и детали референса.

[Проверки PNG/происхождения](validation.json) воспроизводятся `python validate.py`
при наличии исходников по native source paths и временного вложения.
Для просмотра галереи эти внешние файлы не нужны. [Оценки](ratings.json).
Игровые сцены/ассеты и действующий эталон не заменялись; Godot/full/core/F5
не запускались. Пользовательский выбор, анимации и интеграция не выполнены.
Следующий шаг — отзыв по G01–G15 или новый референс по поручению пользователя.
