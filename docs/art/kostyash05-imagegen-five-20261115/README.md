## Масштаб и проверки

Каждый сырой PNG — RGBA 1402×1122. Видимая высота при alpha≥8:
782/788/788/787/792 px, минимальные поля 152/147/149/149/146 px.
Головы, ступни, когти и оружие внутри кадра. Порог не считает ростом слабый
alpha 1–7 шум вне фигуры; исходная alpha не исправлялась локально.

В презентации все Костяши показаны при **304 px**, герои — при **456 px**:
456/304=1,5. В каждом ряду общая линия земли. У канонических героев исходная
высота 152 px, поэтому эквивалент Костяша — 101⅓ px. Это точный масштаб показа,
а не готовый нативный спрайт 101 px и не проверка размера на поле.
Для презентации используются готовые рисунки и nearest-neighbor; новые
пиксели персонажей рисовал только image_gen. Игровые ArtRoot не изменялись.

`build_comparison.py` повторно измеряет видимую высоту после подбора размера,
проверяет пять разных SHA, референсы, промпты, alpha, поля и неизменность PNG.
Запуск из папки пакета: `python build_comparison.py`, без генерации.

[ревью](review.md).
Сборка и py_compile прошли. Первичная ошибка имени поля отчёта исправлена;
