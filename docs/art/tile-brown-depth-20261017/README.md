# Коричневые боковины, увеличенная толщина — 2026-10-17

U: «толщину побольше и оттенки коричневого а не зеленого».
В существующей сцене нижний торец пола и платформ увеличен с18 до30px
при native128. Коричневые боковины темнеют к низу; левая сторона темнее правой.
Зелёный верх, трава/UV, проекция4:3, опоры и тени персонажей сохранены.
Отдельные стены сохраняют прежнюю геометрию и палитру; VOID без боковин.

  Строки: плоский пол, высокий уступ, отрицательная высота, стена, пропасть.
- [Аудит](render_audit.gd), [проверки и ревью](validation.md).
- [Предыдущий вариант](../tile-depth-gradient-20261017/README.md).

Геометрия верха и picking прежние; нижний край декоративный.
[Контракт](../../BATTLE_VISUAL_SCENE_CONTRACT.md#толщина-и-градиент-боковин-тайла).
Ручная художественная приёмка толщины и оттенков открыта.

Аудит наследует capture-helper из Archer-пакета. После импорта проекта:
Godot `--path <project> --screen 0 --script <absolute>/render_audit.gd
-- --output=<folder>`. Прежний вариант18px восстанавливается только во временном
экземпляре для сравнения; текущие игровые исходники не меняются.
