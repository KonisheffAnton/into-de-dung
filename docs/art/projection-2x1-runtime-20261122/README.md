# Игровая проба 2:1 с быстрым возвратом — 2026-11-22

U выбрал правую2:1 из [эскиза](../shallower-perspective-20261122/README.md)
и поручил попробовать её в игре на прежних тайлах, покрытиях и персонажах.
Отдельное требование — быстрый откат при неудаче.
База: main, `9f4c279eeb907a8fb2a3744b8a33fd561e0605f7`.

## Что изменилось

Основной authored Board начинает с ромба128×64 вместо128×96.
Те же изображения поверхности и покрытий проецируются на новую сетку;
исходные PNG, UV, материалы, SpriteFrames и тайминги остаются прежними.
Бойцы/колонны не сжаты; высотная ступень32 и вертикальная глубина кладки
сохранены. Направления, подсветки, тени и выбор клетки следуют текущей проекции.
Камера учитывает фактические размеры поля; карта24×16 и шесть биомов прежние.

Старый поиск стиля20261121 не используется. Runtime-ассеты не перерисованы,
новые генерации изображений для этого этапа не выполнялись.
Точное поведение — [контракт](../../BATTLE_VISUAL_SCENE_CONTRACT.md#переключаемый-ракурс-21--43--2026-11-22).

## Как попробовать и вернуть

1. Обычный F5 → «Начать тест» → «В путь» открывает2:1.
2. Рядом с кнопками масштаба нажать **«Ракурс2:1»**: сразу вернутся4:3.
   Подпись показывает текущий режим; повторный клик снова включает2:1.
   Во время исполнения действия переключатель заблокирован, затем доступен.
3. Переключение действует на текущий Board. Для прежнего режима во всех новых
   сценах поставить `shallow_projection = false` в
   `scenes/demo/battle/battle_board.tscn` (или выключить Shallow Projection
   у корня этой сцены в Inspector).

Никакого восстановления картинок, профиля или сохранений не требуется.
Этап оформляется отдельным Conventional Commit: полный кодовый откат возможен
через git revert именно этого коммита, без reset чужих изменений.

## Ограничение растровых покрытий

В цельных2Dкадрах огня/напольных шипов рельеф уже нарисован вместе с плоскостью.
Проекция сжимает весь такой кадр поY, включая нарисованную высоту языков/шипов.
Это не изменение исходника или новая анимация. Переключение4:3 возвращает
прежние пропорции; отдельные фигуры/колонны и стеновые шипы сохраняют размеры.
Визуальную приемлемость этого эффекта и перекрытий оценивает пользователь.
