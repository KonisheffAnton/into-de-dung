# Idle: солдат стоит и только дышит

2026-10-10, base `5a28b699268bd7d561e85f89e0914bdf7c5411d8`, main, без push.
U выбрал PixelLab для дальнейших анимаций и уточнил idle: солдат никуда
не поворачивается, только дышит. Выбор провайдера — [GRAPHICS_WORKFLOW](../../GRAPHICS_WORKFLOW.md),
образ/приёмка — [ART_DIRECTION](../../ART_DIRECTION.md).
Пробы отдельные; текущий игровой PNG/масштаб80%/гаммаА/посадка не меняются.

## Текстовый запрос — отклонённая попытка

`pixellab/` содержит один вызов `/v2/animate-with-text-v3`:4 запрошенных,
5 полученных кадров96×96, usage1generation. Первый/последний reference — тот же
экспорт игрового PNG, что в [предыдущем сравнении](../defender-idle-20261010/README.md).
Оригиналы сохранены без изменений, запрос/usage/хеши — в JSON рядом.

Независимое ревью REQUEST_CHANGES: меняются направление лица/шлема, щит и корпус.
В прямой петле есть скачок возврата. `preview.gif` показывает02→03→04→05→04→03,
по400ms,2.4s; обратный проход сглаживает стык, но повторяет нежелательный поворот.
Это **не выполнение запроса только на дыхание**; сохранённый неудачный эксперимент.
Кадры не дорисованы и не выровнены индивидуально. [Четыре позы](filmstrip.png).

## Уточнение через фиксированные суставы

`pixellab-rig/`: исходный96×96 PNG дополнен16px прозрачного поля до128×128
без масштабирования для `/v2/estimate-skeleton` (usage0.1generation).
Полученные18 суставов переданы в `/v2/animate-with-skeleton-v3`: восемь поз,
во всех закреплены X и порядок глубины; меняется только Y двух плеч максимум
на1px. Голова/лицо/шея/руки/таз/ноги неподвижны во входном задании.
Направление `south-east`, вид `high top-down`, seed20261012, прозрачный фон.

[Проверка входных поз](pixellab-rig/pose-validation.json) не доказывает соблюдение
ограничений сгенерированными картинками. `drift_threshold` текстового API управляет
цветовым мерцанием, а не запретом поворота; схема сверена по
[официальному OpenAPI](https://api.pixellab.ai/v2/openapi.json).

Результат — восемь128×128 PNG, usage3generations. Независимое ревью
REQUEST_CHANGES: направление стабильно, но альфа-маски всех кадров одинаковы;
изменяются лишь15–40 RGB-пикселей относительно первого кадра, в основном вне
груди. Получилось слабое цветовое мерцание, не читаемое дыхание. Палитра
сокращена провайдером с1500 до35 цветов исходника. [Петля](rig-preview.gif)
и [кадры](rig-filmstrip.png) сохраняют этот отклонённый результат.

## Уточнение амплитуды

`pixellab-breath/`: тот же128×128 вход и seed20261012. Верхние12 суставов
перемещаются вместе по Y на0/−1/−2/−3/−2/−1/0/0px; все X, глубина и
относительные расстояния головы/рук/плеч сохранены. Таз, колени и ступни
зафиксированы. Это отдельный уточнённый запрос, прежние исходники не изменены.

Получены8 кадров128×128, usage3generations. В [новой петле](breath-preview.gif)
виден подъём и опускание верхней части тела с сохранением направления;
[восемь исходных поз](breath-filmstrip.png), [PNG и переходы](pixellab-breath/frames-validation.json).
Стык08→01:37 изменённых RGB-пикселей, без изменения альфа-маски; внутренние
переходы вдоха/выдоха меняют135–147 пикселей альфа-маски. Числа не заменяют
просмотр анимации. Независимое ревью третьей пробы APPROVE: видимых поворотов
нет, альфа-маски обеих стоп постоянны. Это не художественная приёмка.
Провайдер сократил палитру примерно до40 цветов исходника; слабое мерцание
и изменение деталей остаются для оценки U.

## Просмотр и границы

`breath-idle-native.gif` —96×96, `breath-preview.gif` — сравнение с исходником,
8 кадров по300ms, петля2.4s. Последние две позы дают короткую паузу выдоха.
С исходных128×128 удалено только прозрачное поле16px со всех сторон;
кадры не дорисованы, не выровнены индивидуально и не интерполированы.
`prepare-preview.cjs --breath` воспроизводит монтаж; режим `--rig` — вторую
пробу, без флагов — первую. Нужен `SHARP_MODULE` с путём к модулю Sharp.

В предпросмотре общий масштаб80%; крупный показ дополнительно увеличен×4,
ниже приблизительные размеры камеры75/100/125%. Это не запись игрового боя.
Дальше — отзыв пользователя на амплитуду/ритм; runtime/playback/reset/restore,
F5/Editor/DPI/GPU и производительность проверять при отдельном подключении.
Удар/контакт/ход/урон/смерть и остальные бойцы в этом срезе не создавались.
Godot и игровые тесты не запускались: изменены только документы и арт-пробы.
Финальная художественная приёмка открыта. Отчёт:
`test_reports/defender-idle-breathing-20261010/`.
