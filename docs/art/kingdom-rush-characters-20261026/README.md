# Четыре героя в стилистике Kingdom Rush — 2026-10-26

U попросил найти 2D-референсы, сделать четырёх персонажей и передать то же
задание PixelLab. Затем приложил поле с воином, лучником, магом и разбойником.
Его изображение задаёт персонажей, экипировку, цвета, пропорции и ракурс;
официальные иллюстрации Kingdom Rush задают рисунок, контур и тени.

Это **статические концепты для сравнения**, `integration=false`.
Сцены, runtime-ассеты, анимации и выбранный warrior_format_v1 не менялись.
Готовы **4 ImageGen + 4 PixelLab**; все запросы PixelLab завершены (`completed`).

## Одинаковое задание

[Общий бриф](brief.json) содержит ограничения и четыре описания.
Точные тексты для обоих провайдеров: [воин](prompts/warrior.txt),
[лучник](prompts/archer.txt), [маг](prompts/mage.txt), [разбойник](prompts/rogue.txt).
Оба получают исходный отряд и одни и те же референсы Геральда/Аллерии.
ImageGen вызван встроенным инструментом с прозрачностью; PixelLab — официальным
API `/v2/generate-image-v2`, 512×512, `no_background=true`.
PixelLab предназначен для pixel art, но текст задания не заменялся пиксельным:
результат оценивается как ответ другого генератора на тот же 2D-бриф.

В ImageGen все три файла переданы как reference inputs. В PixelLab Геральд —
`style_image`, исходный отряд и Аллерия — `reference_images` с описанием роли.
Это одинаковые тексты и исходники при разных интерфейсах моделей, не идентичный API.

## Происхождение и сохранность

[Изображение пользователя](references/user-party.png) сохранено без изменений.
2D-референсы найдены на [официальном сайте Kingdom Rush](https://www.kingdomrush.com/kingdom-rush):
[Sir Gerald Lightseeker](https://www.kingdomrush.com/images/kingdom-rush/heroes/kr-hero_1_v3.png)
и [Alleria Swiftwind](https://www.kingdomrush.com/images/kingdom-rush/heroes/kr-hero_2.png),
Ironhide Game Studio. Иллюстрация Malik сохранена как просмотренный результат поиска,
но в запросах не использовалась. URLs и роли — [sources.json](references/sources.json).

Оригинальные PNG провайдеров сохранены без перекраски, кадрирования, изменения
alpha или масштабирования. У ImageGen есть почти невидимые краевые пиксели
alpha=1/255; они сохранены. Проверка отсечения видимого силуэта использует alpha>8
и отдельно записывает полный bbox и максимальную alpha на границе.
Это не очищенные и не интегрированные игровые спрайты.

[ImageGen provenance](imagegen/provenance.json) хранит исходные пути и SHA256.
[PixelLab provenance](pixellab/provenance.json) хранит IDs, SHA, параметры и usage:
по 25 генераций подписки за персонажа, суммарно 100; USD-списание в ответах 0.
Полные запросы/ответы PixelLab находятся вне Git в
`test_reports/kingdom-rush-characters-20261026/pixellab/`; ключи/headers не сохраняются.
Промпты и ссылки на входные файлы позволяют восстановить запрос без секрета.

## Проверки

Файловая проверка: [validation.json](validation.json) — 8 PNG/4 референса PASS.
Браузер загрузил 8/8 результатов без JS-ошибок; размеры 128/256, кнопки масштаба,
фона и сглаживания проверены. Исходные PNG ImageGen побайтно совпадают с файлами
из каталога генератора. Дробная alpha не исправлялась вручную.

`validate.py` читает PNG и проверяет количество, декодирование, alpha, поля вокруг
видимого силуэта, идентичность общих промптов и локальные ссылки галереи.
Снимки галереи получают браузерным рендером, исходные изображения не редактируются.
Godot/full/core/F5/editor/DPI/GPU не запускались; анимация, финальная художественная
приёмка и внедрение требуют отдельного выбора пользователя.

## Визуальное наблюдение ведущего

ImageGen дал более согласованный набор гладких 2D-фигур: одинаковые крупные
контуры, формы и тени. PixelLab сохранил четыре класса, но плотность пиксельных
деталей и лица различаются сильнее; у лучника особенно заметна грубая пиксельная
структура. Для выбранного пользователем 2D-направления предпочтителен ImageGen.
Это рекомендация для выбора, не утверждение финального арта или игровых размеров.
