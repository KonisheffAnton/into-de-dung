# Широкая диорама острова — 2026-10-18

Текущая проба **V4**: [яркая](diorama-bright-v4.png) / [приглушённая](diorama-muted-v4.png).
Обе 1672×941, соотношение близко к16:9. Это концепт для просмотра, в игру не внедрён.

U передал [яркий](source-bright.png) и [приглушённый](source-muted.png) оригиналы
1024×1536: продолжать с обеими версиями, сделать широкую диораму на весь экран,
дома заброшенными, в верхней скале высечь башню. Затем U уточнил: без лестниц
снаружи горы, башню немного монументальнее; последняя правка — убрать вход
в башню и сделать её полуразрушенной. Нижний отдельный вход в пещеру сохранён.

## Происхождение и границы

Встроенный **image_gen**, восемь вызовов: по две палитры на V1–V4. CLI/API и
PixelLab не использовались. Яркая V1 строилась по первому вложению; каждая
следующая яркая версия — по предыдущей. Приглушённая версия каждого шага
использует соответствующий яркий PNG для композиции и второй оригинал U для
палитры. Исходники, все полученные PNG и точные [промпты/цепочки](provenance.json)
сохранены; исходные файлы провайдера тоже оставлены. Usage/cost tool не вернул.

Остров расширен по горизонтали; водопад, ручей/мост, маленький лагерь, кузница,
лавка и маг у пещеры сохранены как ориентиры. Кузница/лагерь остаются активными,
заброшенность относится к жилым домам. Новые развалины по краям и обломки лодки
добавлены генератором; это детали пробы, не утверждённый сюжет.

V4 просмотрены ведущим и [независимым reviewer](review.md): пригодны для preview.
Главные наружные лестницы по склонам отсутствуют;
у нижней пещеры осталась короткая каменная тропа. Башня заметно разрушена,
большого дверного проёма в ней нет. Скальные швы местами напоминают кладку.
Варианты композиционно близки, но ImageGen перерисовывает мелкие детали:
точное совпадение пикселей/контуров/цветов и готовность к слоям/анимации не заявляются.
Запрошенный в первых промптах размер2560×1440 фактически не получен: файл1672×941,
без последующего растягивания/апскейла. Проверка формата/CRC/хешей — [validation](validation.json).
Финальная художественная приёмка и внедрение остаются за U; новых генераций
или следующего этапа без выбора U не начинать. HUD/runtime/core/сохранения не менялись.
