## Создание и просмотр

Imagegen: десять отдельных вызовов встроенного инструмента, разные задания
на композицию, без входных картинок. Один дополнительный edit убирает ореол
у G38; исходник и исправление сохранены отдельно. [Полные промпты](imagegen-prompts.json),
[коррекция G38](imagegen-g38-cleanup.json), [происхождение PNG](imagegen-sources.json).
Всего 11 вызовов, usage встроенный инструмент не сообщает. CLI не применялся.

PixelLab: первая партия с PL29 как style reference повторила почти одинаковую
кучку. Она сохранена в `pixellab/mixed-small/` как отклонённая для этого показа.
Вторая попытка — десять отдельных заданий `create-image-pixen` — дала
крупные целые кости, череп и подложки; тоже отклонена. Она сохранена в
`pixellab/individual/`, исторический mapping — `pixellab-selection-individual-rejected.json`.
Итоговые PL39–PL48 взяты из третьей партии `generate-image-v2` без style reference
и без G-входов. Requests, receipts, status и исходные PNG — `pixellab/fragment-redesign/`.
Выбраны десять различных композиций из 16 результатов. Всего PixelLab: 12 POST,
30 generations; все задания завершены, повторов одного POST не было.
Точная привязка номеров и фактический расход: [selection](pixellab-selection.json),
[provenance](pixellab-provenance.json).

Листы — только оформление сравнения. У PixelLab исходные 64×64 увеличены
ровно ×4 NEAREST. У Imagegen большие растровые исходники: для листа берётся
bbox alpha≥128, уменьшается NEAREST до 48×30 и затем показывается ×4.
Исходные RGB/alpha не меняются локально. Это **не утверждённые игровые спрайты**:
крупные G могут содержать мягкие края, отдельные кости у обоих провайдеров
бывают длиннее задания. У PL реальное пятно около 53–56×33–37 вместо запрошенных
36×18; число деталей и footprint в промптах не являются гарантией результата.

Повторная сборка листов и проверка из корня проекта:

```powershell
python docs/art/bones-twenty-next-20261123/build_preview.py
python docs/art/bones-twenty-next-20261123/verify.py
```

Проверка считает RGBA/alpha, размеры, уникальные файлы, точность копий G и
сохранность защищённых файлов; результат — [verification.json](verification.json).
Независимый [визуальный review](art-review.md): APPROVE для поискового показа.
Художественная приёмка остаётся за пользователем. Runtime и игровые ресурсы
не менялись; Godot/import/full/core/F5/DPI/performance и примерка на поле не проводились.

Свежие трупы по прежнему решению пользователя — последний кадр смерти;
новых свежих кучек здесь нет. Правило и остаток внедрения принадлежат
[ENVIRONMENT_D5](../../ENVIRONMENT_D5.md#свежие-трупы-и-кости--2026-11-22).
Сроки свежести, каннибализм и выбранная смерть С2 этим показом не меняются.
