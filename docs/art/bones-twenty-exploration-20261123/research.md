# Готовые решения: проверка 2026-11-23

По просьбе U искали готовые пиксельные кучи костей. Поиск не подтверждает
готовый ассет, полностью соответствующий нашему brief: мелкие разные кости
внутри одной низкой кучки, без узнаваемого черепа/анатомии, в стиле игры.
Превью помогают сравнить степень упрощения; никаких покупок/внедрения не было.

Дополнительно найден [0x72 DungeonTilesetII](https://0x72.itch.io/dungeontileset-ii),
CC0, но отдельная подходящая кучка в этом наборе не подтверждена. Не выдаём
общий dungeon tileset за найденный готовый спрайт костей.

Исходные страницы/лицензионные формулировки проверялись через web, адресный поиск
помощником и ведущим. Публичные preview PNG для визуальной проверки временно
кэшированы в игнорируемом `test_reports/bones-research-20261123/`; не копируются
в игровые ресурсы и не передаются генераторам. Платные файлы не скачивались.
Отдельно в `third-party/` сохранён бесплатный CC-BY4.0 спрайт-лист BoundWorlds
и кадр без головы, с [атрибуцией и описанием изменений](third-party/ATTRIBUTION.md).
[Превью готового кадра](ready-bones-preview.png) — только исследование/сравнение.

Новые20 вариантов создаются независимо от сторонних рисунков. Из исследования
взяты общие принципы: низкое пятно, небольшая палитра, простые костяные обломки,
читаемость на маленьком масштабе. Ни чужие пиксели, ни композиция не копируются.
Условия коммерческого включения конкретного выбранного набора нужно сверить
с его фактическим LICENSE при получении ассета; это обзор, не юридическое заключение.
