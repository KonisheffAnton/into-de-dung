# Сборный герой: экипировка и движение — визуальная проба

U2026-11-18: показать дыхание и удар в двух комплектах, с несколькими
наборами оружия, через PixelLab и без внедрения. База `main`,
`fcfe0c3ddf70690b82bd7bb424c0ddf107417cbd`.

## Что сравниваем

Шесть вариантов: лёгкая/тяжёлая броня × меч и щит / топор и щит /
двуручное копьё. У каждого отдельные покой и атака. Выбор трёх наборов
и характер движений — предложение ведущего, не изменение игровых предметов.

`reference-concept.png` — побайтная копия предыдущего сравнительного листа
ImageGen; `reference-warrior.png` — нативный `red_bastion/still.png` из игры,
который был основой этого концепта. PixelLab редактирует нативный256² источник:
увеличенный рисунок концепта не уменьшается и не выдаётся за игровой спрайт.
Все шесть исходных комплектов созданы `edit-image-pixen`. Новые позы создаёт
только `animate-pixminimax`; никакой локальной дорисовки движения нет.

Это **готовые растровые кадры, а не работающий сборный каркас**. Предметы
не отделены от тела в анимации; единые суставы/перекрытия/взаимозаменяемость
слоёв не проверены. Генерации могут менять детали брони, лицо или форму оружия.
Приёмка пользователем и разрешение реализации отсутствуют.

## Воспроизведение экспорта

После сохранения завершённых ответов API:

```powershell
python docs/art/modular-equipment-animation-20261118/export_preview.py
python docs/art/modular-equipment-animation-20261118/build_gallery.py
```

`prepare_requests.py` лишь готовит ограниченную серию запросов и отказывает
при повторной подготовке тех же ID. Сам HTTP не выполняет. Фоновые задания
возобновляются по сохранённому ID; неясный результат POST не повторяется.

Игровые сцены, assets, core/preview/queue/RNG/save и каталоги не меняются.
Godot/F5/Editor/DPI/full/core/performance для этой художественной пробы
не запускались. Техническая проверка пакета не является приёмкой анимации.

Проверки экспортёра сверяют сохранённый запрос, входной PNG и все хеши кадров
с результатом провайдера; неверная подстановка другого задания не проходит.
Неполный повторный экспорт убирает только старые обзорные GIF/PNG и галерею,
сохраняя исходные кадры. [Независимое ревью](review.json) относится к коду
экспорта; [проверка браузера](browser-validation.json) — к работе просмотра.

## Результат и ограничения

Готовы6 исходников и12 выбранных клипов:252 PNG256². В выбранных кадрах
нет касания края холста; все первые кадры RGBA-равны своим исходникам,
но последние не равны им точно. Швы, деформация лица/кистей, соответствие
экипировки между независимыми генерациями и ощущение веса требуют отзыва U.
Просмотр ключевых поз и полный лист копейщика выполнены ведущим; это не F5.

Первоначальный лёгкий укол107 касался правого края в кадрах8/9. Отдельная
генерация207 с меньшим вылетом выбрана для показа; все25 кадров без касания
края, максимальная правая граница alpha235 при холсте256. Исходная проба и
её запрос сохранены в `rejected/`; [выбор](correction.json) явно отделён от raw.
`selected_job_id` в публичном запросе привязывает замену к её исходному заданию.

Фактический расход —39 генераций подписки:6 правок исходника,12 выбранных
клипов и1 отклонённый укол. Выбранный набор сам по себе —36 генераций;
разница3 сохранена в отчёте, а не скрыта. Новых списаний за локальный экспорт нет.

Экспорт18/18, хеши/происхождение/размеры PASS;9 проверок браузера PASS
(12 плееров, видимость, движение, пауза, кадр, фильтр, скорость, масштаб, сброс).
Независимое ревью кода —APPROVE. [Итоговая проверка](verification.json)
также фиксирует точный архив HANDOFF и сохранность33 чужих файлов.
