# Мельче сами кости — 2026-11-23

U: «Помельче кости». Интерпретация, озвученная перед работой: уменьшить
отдельные кости/обломки внутри каждой кучки, сохранив общий размер пятна.
Продолжается поиск пяти собственных и пяти PixelLab вариантов; внедрение
по-прежнему ждёт выбора. Голые универсальные кости, разные формы в одной
низкой кучке, простые пиксели, без черепа/лица/узнаваемого скелета.

- [G6–G10](imagegen-five.png): встроенный imagegen редактирует прежние G1–G5,
  заменяя крупные доминирующие кости короткими обломками. [Точные промпты](imagegen-prompts.json),
  [происхождение](imagegen-sources.json); исходные RGBA сохранены в `imagegen/`.
- [PL14–PL18](pixellab-five.png): PixelLab адаптирует новые G6–G10, выход64×64;
  финальные PNG — `pixellab/PL14-adapt/image.png`…`PL18-adapt/image.png`.
  Это та же более мелкая раскладка, а не независимые композиции.
- `provider-inputs/G6.png`…`G10.png` — технические входы64² для PixelLab:
  обрезка для рамки по alpha≥128, nearest thumbnail54×39 в64². Исходная alpha
  не очищалась локально; мелкие кости нарисованы imagegen, pixel cleanup — PixelLab.
- Первые `PL14`…`PL18` (правка старых PL) не выбраны: большие кости сохранились.
  Следующие `*-small` (создание с нуля) тоже не выбраны: крупные кости,
  повторные формы и лишние подставки/фон. После двух проб пересмотрен способ
  передачи задания: провайдер получил готовые мелкие обломки как изображение.
