# Пятый референс — минигерои и монстры разного размера

U, 2026-10-17: десять изображений в стиле нового листа минигероев; добавить
монстров из ранее присланного листа, причём одних больших, других маленьких.
Понравившаяся палитра сохранена отдельным ориентиром. Это поиск, не замена
действующего игрового эталона и не назначение занимаемых монстрами клеток.

[Галерея](gallery.html) содержит десять финальных G01–G10. В каждом — четыре
героя и два монстра разных размеров. По предыдущему уточнению U для G01–G08
задан передний изометрический ракурс, для G09–G10 — фронтальные фигуры;
пол остаётся изометрическим. Ноги/опоры прямо на клетках, без отдельных подставок.
Метки описывают задание генератору; точные углы и игровые anchors не измерялись.

## Оценки анимации

В галерее под каждой картинкой отдельно указаны герои и оба монстра.
[ratings.json](ratings.json) — владелец оценок и причин. Шкала 1–10:
1 проще, 10 сложнее. Число изображения — максимум сложности его фигур,
а не оценка генерации анимации всей сцены. Эталон Defender: 4/10.
Герои: 3; слизь: 2; панцирники: 4; щупальцевые/глаз: 4–5;
длинный скелетный страж: 6. Размер сам по себе не определяет сложность.
Это предположение о сохранении формы при idle/ходьбе/атаке с одной камерой;
реальная генерация анимаций не выполнялась.

## Происхождение

reference.png — последний лист минигероев; palette-reference.png — понравившаяся
U палитра: оливковый, пыльный синий, песочный, земляной, молочный и тёмно-сливовый
с небольшими коралловыми акцентами. monster-reference.png — лист видов монстров;
projection-reference.png — ориентир пола 4:3; defender-benchmark.png — эталон.
Все исходные PNG сохранены без правок. Точные запросы и native-пути результатов
в [manifest.json](manifest.json); первые запросы с монстрами — requests-with-monsters.json,
четыре последующих исправления — review-correction-requests.json.

18 вызовов встроенного ImageGen: четыре ранние сцены до уточнения о монстрах,
десять сцен с монстрами и четыре исправления после ревью.
Прежние PNG и фактические запросы — iterations/. input_snapshots в финальном
manifest связывает заменённые G03/G05/G07/G09 с точными входами исправлений.
requests.json содержит первоначальный план десяти сцен, из которого выполнены
только G01–G04; это не журнал десяти дополнительных вызовов.
PixelLab не использовался. Расход ImageGen инструмент не сообщает.
Финальные PNG совпадают с байтами провайдера; RGB, alpha, размеры и позы вручную
не менялись. Для просмотра галереи достаточно содержимого этой папки.

## Проверка и границы

`python build_gallery.py`, затем `python validate.py`: [validation.json](validation.json).
Проверяются десять PNG, CRC/размеры/SHA, байты native-результатов, пять референсов,
оценки каждой фигуры, максимум оценки сцены, входы исправлений, ссылки и сохранность main_menu.
Повторная проверка байтов провайдера требует native-файлов по путям manifest;
временные вложения для проверки референсов не нужны.
Визуальные замечания и границы — [review.md](review.md).
Игрового внедрения и Godot/full/core/F5 нет. Приёмка стиля остаётся за U.
Далее — отзыв по G01–G10 либо новый референс по прямому поручению;
новые генерации, анимации и интеграцию автоматически не начинать.
