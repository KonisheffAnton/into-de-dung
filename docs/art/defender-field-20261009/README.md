# Новая земля и сравнение Защитников — 2026-10-09

Первый набор травы ниже пользователь отклонил как неестественный. В той же сцене
теперь [четыре варианта по новым референсам](../grass-reference-20261010/README.md).
Бойцы и правила запуска сохранены; PNG первой пробы оставлены для сравнения.

U: игровая сцена с землёй со второго вложения, новым Защитником из первого
и прежним, зеркально развёрнутым, у противника. Затем поручены вариации тайлов.
Пропорции остаются предметом ручного отзыва.

## Запуск

Открыть [art_trial_battle.tscn](../../../scenes/demo/art_trial_battle.tscn) в Godot
и нажать **F6**. Это штатный бой «Реакции и скрытая атака», поле8×8, шесть бойцов:
новый рисунок у союзного воина, прежний №4 у вражеских воинов с отражением.
Другие классы сохраняют свои изображения и способности. Enter — начать бой;
колесо/кнопки — масштаб, ПКМ — сдвиг, R — сброс. Для обзора отдалить до75%.
F5 остаётся прежним входом. Проба не пишет профиль.

Исходные BattleDemo/BattleCoreReactionsSession сохраняют расстановку,
покомандный ход, worker, команды, прогноз и показ. Основной набор M3/№4 не заменён.
