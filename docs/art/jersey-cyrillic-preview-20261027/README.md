## Метод сравнения

[Исходный кадр](source-battle.png) 1280×850 побайтно скопирован из
[предыдущего сравнения пар](../combat-font-pairs-preview-20261027/README.md).
В листе — crop x=400, y=0, w=880, h=700 при 50%; отдельные PNG — полный кадр 100%.
Верхняя фигура частично обрезана исходной камерой. Фон не ретушировался.
Подписи рисуются настоящими TTF через HTML/CSS, без генерации изображения.

Одинаковые значения -12.5, -28.0, +8.0, -6.0 и КРИТ/ЩИТ/БЛОК/ПРОМАХ/
КРОВОТЕЧЕНИЕ — примеры оформления, не реальные события записанного боя.
Цвета, позиции, наружный контур 4px и тень 3px native одинаковы.
Видимая высота цифр 40px, крита 50px; слов 32px, тегов 24px native.
Em-размер нормализован по видимым границам; дробные масштабы допустимы для
оптического сравнения. Это не проверка пиксельной сетки, размера или рендера Godot.
В строках под кадрами показаны знаки без контура, включая «Щит броня HP».
Верхняя полоса — настоящая латиница оригинального Jersey для сравнения рисунка.

Jersey, Island, Chetyre используют Regular; жирность Pixeloid записана в TTF,
синтетическое утолщение отключено. Handjet: wght=900, ELGR=1, ELSH=2 (Square).
Цифры во всех вариантах имеют один файл, вес, размер и рисунок.

## Источники

- [Font Island C Improved](https://www.fontstruct.com/fontstructions/show/2692709/font-island-1-1)
  автора Logan2020 — неофициальная FontStruct-переработка, близкая к Jersey 10,
  с кириллицей. Это отдельный шрифт, не официальный Jersey с добавленной кириллицей.
  Сохранены TTF, авторская OFL и README с цепочкой исходных FontStructions.
- [Chetyre](https://hanshuyuri.itch.io/chetyre) и
  [Pixeloid](https://ggbot.itch.io/pixeloid-font) — побайтные копии из
  [прежнего пакета](../combat-font-options-preview-20261027/README.md).
- [Handjet](https://github.com/rosettatype/Handjet) — исходный variable TTF,
  OFL и metadata из Google Fonts, commit e7db6ca603fd4862010383ff17ffd6cc4ffac1c0.
- Jersey — побайтная копия исходного полного TTF/лицензии/metadata из сравнения пар.
  В этом превью он используется только для цифр и латинского образца.

Все файлы и SHA256 — [provenance.json](provenance.json), лицензии — fonts/.
Архив FontStruct и отчёты: test_reports/jersey-cyrillic-preview-20261027/.
Тексты лицензий и README автора сохраняются побайтно через .gitattributes.

## Проверки и границы

[Рендер](render-preview.cjs): `node render-preview.cjs <node_modules с playwright>`;
установленный Edge, headless, DPR1. [Проверка](validation.json): 5 шрифтов загружены,
полная русская азбука А–я/Ёё и HP есть в cmap четырёх вариантов; 28 подписей
внутри кадра, без взаимных пересечений, 16 строк образцов без переполнения.
CDP подтвердил локальные шрифты на 53 текстовых узлах без системного fallback;
ошибок браузера нет. Четыре полных PNG побиксельно сохраняют фон вне надписей
с запасом 12px на контур/тень. Лист и полные PNG просмотрены.
Независимое ревью и контроль SHA — в отчёте этапа.

.gdignore исключает пакет из импорта Godot. Игра/assets/сцены не менялись;
прежние превью и защищённые пользовательские файлы сохранены побайтно.
Godot/full/core/F5 не запускались. Движение/DPI, выбор и внедрение открыты.
Core/preview/queue/RNG/save/frozen прежние. Новый этап автоматически не начинать.
