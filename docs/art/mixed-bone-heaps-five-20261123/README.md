# Разные кости внутри одной кучки — 2026-11-23

U исправил трактовку: разные должны быть **сами кости внутри каждой кучки**.
Нужны пять новых вариантов PixelLab и, по «Ты тоже попробуй», пять собственных.
Прежняя серия PL4–PL8 меняла прежде всего раскладку и не закрыла это требование.
Новая серия — предложения для выбора; в игру не внедрена.

Каждая кучка смешивает длинные/короткие, толстые/тонкие, прямые/дугообразные,
плоские и суставные обломки. Голые универсальные останки, без черепа/лица,
узнаваемого скелета, мяса и высокой костяной пластины. Один низкий компактный
объём, прежняя приглушённая костяная палитра и крупные пиксели.

- [Мои G1–G5](imagegen-five.png): встроенный imagegen, пять отдельных генераций;
  [точные промпты](imagegen-prompts.json), [происхождение](imagegen-sources.json).
- [PixelLab PL9–PL13](pixellab-five.png): native RGBA64×64, показ ×4 nearest.
  Каждый запрос/ответ/PNG сохранён в `pixellab/<id>/` без секрета.
- В показе PL11 используется `pixellab/PL11-clean/image.png`: короткие разноформенные
  обломки, более низкая камера. Первая PL11 отклонена из-за дуг-рёбер;
  v2 слишком вытянута/высока; v3 сохранила практически ту же композицию PL10.
  Для v4 задание упрощено, задан более низкий ракурс и всего шесть разных кусков.
  Случайные камни по краям v4 удалены через PixelLab inpaint-image-pro-flash;
  все пиксели внутри чёрной области маски сохранены провайдером побайтно.
- Остальные PL соответствуют одноимённым папкам; G — `imagegen/G1.png`…`G5.png`.

Imagegen использовал прежний `bones-five-20261123/B5-v2/image.png` только как
ориентир стиля. Это крупные растровые концепты, **не готовые native64 спрайты**.
У G1/G2/G5 есть слабая фиолетовая полупрозрачная кромка; при выборе нужна
адаптация/очистка через провайдера. G3/G4 визуально чище. Исходные RGBA
сохранены без исправления; Python только составляет листы сравнения, кадрирует
по bbox alpha≥128 и уменьшает/увеличивает nearest. Он не дорисовывает кости и
не вычищает alpha. Целевые 8–10 цветов — текст задания, не измеренное свойство
всех полученных исходников. Размеры/alpha/хэши — в [verification.json](verification.json).

PixelLab: официальные `/v2/create-image-pixen`, `/v2/edit-image-pixen` и
`/v2/inpaint-image-pro-flash`: 9 POST = 13 generations, включая три пробы
замены PL11 и очистку её фона (5 generations).
У imagegen было 5 вызовов, расход не предоставлен tool.
Автоматических повторов POST нет. Повтор запуска разрешён только после
проверки существующего receipt; клиент защищает успешные запросы от дублей.

Проверено: 10 финальных PNG читаются, RGBA/alpha; пять PL имеют64²;
35 PNG прежних пакетов сохранены побайтно. Независимое art review одобрило
показ, отдельно проверена замена PL11. Приёмка пользователя остаётся открытой.
Лучше для отбора G4 и PL13; PL10 также читаемый. У PL12 широкий низкий осколок
может напомнить пластину, но не стоит вертикально и не содержит лица.
Godot/тесты механик не запускались: runtime и ресурсы игры не менялись.

Дальше: получить выбор костей, затем закончить прежнее поручение внедрения
выбранной пары и показать на настоящем поле. Свежий — ранее выбранный нижний

каннибализм и С2 не меняются.
