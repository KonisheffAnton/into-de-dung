## Согласованное и открытое

Q1–Q5 повторно не спрашивать. p=clamp(1-2*Acurr/Amax,0,1) при Amax>0 до всего попадания.
Объединение типа/политики → один floor входа после модификаторов; H0=floor(D*p), B0=D-H0.
R_B=min(rA+rH,L_B), R_H=min(rH,L_H); floor по ветвям, естественная защита один раз,
overflow без повторной. Базовые пределы 75%, повышение только перками; абсолютного потолка
и нижней границы сопротивлений нет. R>100% лечит HP обеими ветвями: floor положительного лечения.
Один итог HP=clamp(HP_before-T_damage+T_heal,0,HPmax), смерть по итогу; состояния допускает
нужная положительная HP-часть до лечения, с учётом иммунитетов/источника. Лечение не ремонтирует броню.
Между типами расход пропорциональный; floor/крупнейшие остатки/стабильный порядок типов.
Стойка ×0.7 до разделения; impact без HP-урона; collision/fall отдельные попадания, пропасть — смерть.
Отдельной прочности нет. Обычный запас — остатки a_i предметов; Amax=sum(A_i) надетого комплекта.
Расход не уменьшает Amax; остатки сохраняются по экземплярам при снятии/возврате только вне боя.
Избыток расходуется первым; остаток расхода — случайно по предметам: один, при нехватке следующий;
кандидаты a_i>0, веса A_i. Сопротивления надетых вещей складываются по типу в rA и действуют при a_i=0.
После боя обычная броня сама не растёт. Заклинание восстанавливает её пропорционально недостаче:
floor/крупнейшие остатки/стабильный порядок вещей. Излишек — временная броня сверх Amax;
расходуется первой, исчезает после боя, если перк не задаёт другое. В бою каст при полном запасе разрешён:
M=0 → обычные доли не вычислять, весь объём временный. Между уровнями — ресурсный ремонт на экране персонажей.
