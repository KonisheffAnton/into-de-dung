## Согласованное и открытое

Полные ответы и текущая карта HP/смерти/API — D0. Q1–Q5 повторно не спрашивать.
p=clamp(1-2*Acurr/Amax,0,1) при Amax>0, до всего попадания; H0=floor(D*p), B0=D-H0.
Тип/политика объединяется, один floor входа после модификаторов, затем floor каждой ветви.
R_B=min(rA+rH,L_B), R_H=min(rH,L_H); естественная защита один раз, overflow без повторной.
Лимиты по умолчанию 75%, повышенный максимум только от перков, абсолютного потолка нет.
Отрицательные сопротивления допустимы без нижнего предела. R>100% лечит HP обеими ветвями;
положительное лечение каждой ветви floor без минимума 1. Броню оно не ремонтирует.
Один итог HP=clamp(HP_before-T_damage+T_heal,0,HPmax), смерть только по итогу.
Нужная положительная HP-часть до лечения допускает состояние: 10 физического +10 лечения
огнём оставляют HP прежним, но допускают кровотечение. Иммунитеты сохраняются.
Распределение брони между повреждающими типами пропорциональное; floor, остатки по дробям,
равенство — постоянный порядок типов. Расход по предметам этим не определён.
Стойка ×0.7 до разделения; impact без HP-урона; collision/fall отдельные попадания;
пропасть — прямая смерть. Снятие/замена брони только вне боя; после боя броня сама не растёт.
Броню восстанавливают заклинания (включая бой), между уровнями — ресурсный ремонт
на экране персонажей. Это дизайн, не реализованные механики.
