## Согласованное и открытое

Q1–Q5 повторно не спрашивать. До всего попадания p=clamp(1-2*Acurr/Amax,0,1) при Amax>0;
при Amax=0 p=0 с временным запасом, иначе p=1. Объединение типа/политики → один floor входа
после модификаторов; H0=floor(D*p), B0=D-H0. R_B=min(rA+rH,L_B), R_H=min(rH,L_H);
floor по ветвям, естественная защита один раз, overflow без повторной. Лимиты 75%, повышение
только перками; абсолютного потолка и нижней границы сопротивлений нет. R>100% лечит HP
обеими ветвями: floor положительного лечения. Один итог HP=clamp(HP_before-T_damage+T_heal,0,HPmax),
смерть по итогу; состояния допускает нужная положительная HP-часть до лечения с учётом иммунитетов/источника.
Между типами расход пропорциональный: floor/крупнейшие остатки/стабильный порядок типов.
Стойка ×0.7 до разделения; impact без HP-урона; collision/fall отдельные попадания, пропасть — смерть.
Отдельной прочности нет. Amax=sum(A_i) надетого комплекта, расход не уменьшает максимум;
a_i принадлежат экземплярам и сохраняются при снятии/возврате только вне боя. Сопротивления вещей
складываются по типу в rA и действуют при a_i=0; прямую HP-ветвь защищает только rH.
Временный запас E принадлежит персонажу; Acurr=sum(a_i)+E. Он расходуется первым;
остаток расхода — случайно по предметам: один, при нехватке следующий; кандидаты a_i>0, веса A_i.
Обычная броня после боя сама не растёт. Заклинание восстанавливает её пропорционально недостаче:
floor/крупнейшие остатки/стабильный порядок вещей. Излишек — временная броня сверх Amax без изменения max;
в бою допустим каст при полном запасе и Amax=0, избыток складывается с оставшимся без предела.
Он исчезает после боя, если перк не задаёт другое. Вне боя создание избытка пока отложено.
Между уровнями — ресурсный ремонт на экране персонажей. Лечение от сопротивлений броню не ремонтирует.
Открыты: ресурс/цена/распределение ремонта, подготовка объёма/стоимость/параметры заклинаний,
обработка превышения недостачи вне боя, технический учёт E/исключения перков; другие источники max,
a_i/идентичность/RNG/стабильные ключи, конкретные перки/сложение лимитов, реестр типов,
события/реакции и состояния/последствия. Остальные P не приняты. Следом обсудить принцип расхода ресурса ремонта.
