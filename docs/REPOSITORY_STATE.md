# Запуск и воспроизводимость

## Обычный запуск

Локальный checkout с 2026-10-08: `D:\Games\into-de-dung`.
Открывайте `project.godot` из этого каталога. Проект использует относительные
`res://`-пути; старый каталог в Documents для запуска не требуется.

Проба новой земли и двух Защитников: F6 на `scenes/demo/art_trial_battle.tscn`.
Три варианта тайла, новый союзный воин и прежний зеркальный вражеский в штатном
бою8×8. Enter — начать, R — сброс; колесо/кнопки — масштаб, ПКМ — сдвиг.
Материалы и границы — [арт-проба](art/defender-field-20261009/README.md).

Сравнение темпа: F6 на
`scenes/demo/initiative_battle.tscn`. «Командой» / «По инициативе» перезапускают
одинаковый бой; [правила эксперимента](INITIATIVE_COMPARISON.md).

Откройте `project.godot` в Godot 4.7 и нажмите F5. Проверенная в проекте версия —
4.7.2; главная сцена `scenes/demo/main_menu.tscn`. Нажмите «Начать тест», затем в
[хабе H1](HERO_HUB_H1.md) выберите до трёх героев и «Начать поход · 7 комнат».
Новый поход сразу открывает расстановку в стартовой комнате со всеми текущими
опасностями и тремя типами врагов. После победы карта [U14](EXPEDITION_U14.md)
показывает следующие пути; условия дальних комнат скрыты. Действует
[колода мага](MAGE_DECK_V1.md): базу можно
пересобрать в хабе, после расстановки подтвердить/пропустить замену до двух карт.
После победы выберите карту или откажитесь, затем продолжите; у безопасной точки
после услуги доступны состав колоды и выход. Финал требует решения награды перед
возвратом. Загруженный legacy H1 бой/старый U14 поход сохраняет прежние правила.
На время плейтестов меню по умолчанию использует `temporary_profile = true`:
каждый F5 создаёт новый отдельный профиль `user://hero-hub-playtest-*.save`.
При обычном выходе удаляются только его файл, `.bak` и `.tmp`; прежний
`user://hero-hub-v1.save` не затрагивается. Принудительная остановка может
оставить временный файл, но следующий запуск его не загрузит.
Для продолжения между запусками отключите **Temporary Profile** у корня
`main_menu.tscn` в Inspector: кнопка станет «Продолжить», будет использован
**Save Path** (по умолчанию `user://hero-hub-v1.save`). Загрузка посреди боя
повторяет его с начала. Python launcher использует отдельный каталог профиля;
временный режим меню действует и в нём.
Действия показываются последовательно на временных фигурах ([V1](BATTLE_PRESENTATION_V1.md));
Пропустить / Пробел завершает показ текущего действия, кнопка скорости даёт ×1/×3.
При ошибке записи экран предлагает повтор и не публикует несохранённые изменения.

Самостоятельный принятый бой ядра остался в `scenes/demo/core_reactions_battle.tscn`
(F6); из него доступны прежние демонстрационные режимы. Управление —
[TACTICAL_BATTLE](TACTICAL_BATTLE.md) и [DEMO_SANDBOX](DEMO_SANDBOX.md).
Кнопка «Забег» открывает [D4](EXPEDITION_D4.md): подготовку, два боя, отправку
и возврат. Прямой вход — `scenes/demo/expedition_d4.tscn`; профиль `user://d4-run.save`.
Из подготовки в бой с надетыми вещами ведёт «Отправиться · бой 1 из 2».
«К отдельным боям» выходит из забега в самостоятельный сценарий с его экипировкой.
Загрузка посреди боя начинает его заново с сохранённой контрольной точки.

Самостоятельная сцена ядра открывает расстановку: свободно переставьте отряд в зоне
или нажмите «Начать бой» / Enter с готовой позицией ([K9](CORE_BATTLE_BATCH_K9.md)).
После старта первым ходит противник, затем игрок и окружение. В ход игрока
панель использует четыре слота: атака, защита и два назначения —
[раскладка main/H1](BATTLE_PRESENTATION_REWORK.md#панели-способностей-и-области-действия--образец-2026-10-01).
R возвращает расстановку. Восьмислотовая панель сохранена в legacy-сценах.

Самостоятельный сценарий — «Сочетания ядра» — [K10](CORE_REACTIONS_K10.md),
наследник K9/K2. Бор на E4 может ударить Щита D4 и сдвинуть на шипы C4;
для скрытой атаки нужна вторая ближняя угроза, например Астра на D3.
После обеих команд [окружение K15](ENVIRONMENT_COLLAPSE_K15.md) случайно отмечает
клетку; в следующую свою фазу обрушает её. Пульсирующие трещины обозначают
предупреждение, hover объясняет срок; «Окружение · прогноз фазы» показывает
условный результат при текущем мире.
Астра/Страж получают режимы танка, Бор/Дозорный — пассивку.
Щит имеет иммунитет к кровотечению. Старый вход `core_combination_battle.tscn`
сохраняет прежнюю спину как сценарий регрессии C1/K9.
Астра рядом с телом A4, Рей оглушён до конца вашего хода. Кровавая руна — слот 5,
поднятие — слот 6. Контроль, кровотечение и пополнение действий проходят общую
границу хода. K7 даёт Бору пробивающий клинок M4: 50% физической базы обходят
броню. Для обычного наложения кровотечения переместите Бора на E5 и атакуйте
Дозорного F5. [Правила и сценарии K7](ARMOR_PIERCING_M4.md#k7--клинок-в-общем-бою-ядра).
Это отдельный бой с собственной экипировкой, без загрузки профиля D4.
K8: слот 7 — [Опутывающий удар](ENTANGLE_ATTACK_K8.md). Бор E5 → Дозорный F5:
физический HP-урон от пробивания накладывает путы после последствий удара.

Кнопка «Сочетания ядра» возвращает к K2 из других боевых режимов. «Полигон»
и затем «Бой против ИИ» открывают прежнюю карту с высотами, стеной, пропастью
и призывом печатью; прямые сцены `battle_demo.tscn` и `tactical_battle.tscn`
сохранены в `scenes/demo/`. Забег и сравнение ходов сохраняют отдельные входы.
Четыре раздельные демонстрации D2/D3/D5/C1 убраны из меню и перенесены в
`tests/fixtures/demo/` для регрессии. Старой `scenes/test/test_grid_scene.tscn`
и её отладочных панелей больше нет; механические тесты сохранены.

Альтернативный изолированный запуск при установленном Python 3:

```powershell
python tools/demo/isolate.py --godot "C:\Tools\Godot\Godot.exe"
```

Замените путь на свой или задайте GODOT_BIN. Launcher создаёт отдельную копию
исходников/профиль в test_reports и открывает игру. Команды автоматических
проверок и объяснение результата находятся только в [TESTING](TESTING.md).

## Git и локальные артефакты

Git самодостаточен с фиксации зависимостей `c8dfb0b95e851263151e5f0ce39a9a636434637a`.
Старый dirty overlay восстанавливать не нужно. `test_reports/` ignored,
кроме `.gdignore`; отчёты не нужны для запуска чистого клона. Новый прогон
создаёт собственные логи. Сохранённые инструкции и контракты должны быть в Git,
а не только в локальном отчёте. `.godot/` — генерируемый кэш, не исходники.

Рабочие инструкции — [AGENTS](../AGENTS.md), передача — [CODEX_HANDOFF](CODEX_HANDOFF.md),
индекс — [PROJECT_CONTEXT](PROJECT_CONTEXT.md). Правила коммитов/публикации не
дублируются здесь. Подтверждения прежних clean-clone запусков сохранены в
[архиве воспроизводимости](REPOSITORY_STATE.history-20260920.md).
