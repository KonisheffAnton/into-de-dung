Поручение продолжить ядро — 2026-09-25, исходный HEAD
`3a99cc4698088c49ea117260e390b918c95f7b12`. Выбран один новый путь наложения
существующего состояния [C1](CRITICAL_BACKSTAB_C1.md), без общего движка статусов.
Пользовательская приёмка K8 открыта, теперь в общем плейтесте [K9](CORE_BATTLE_BATCH_K9.md); технические свидетельства — [HISTORY](HISTORY.md).

## Исполняемые правила первого среза

Технический сценарий ведущего: отдельный «Опутывающий удар» в общем бою K2,
слот 7, цена 1 main. Дальность, допустимость цели, прямой урон, крит/спина,
пробивание и толчок используют нынешний расчёт атаки. Новых множителей нет.
Атака не накладывает кровотечение; обычный удар и Кровавая руна не меняются.
Это проверочная способность участников K2, не распределение будущих классов.

- Путы допускаются при положительной сумме физического `hp_damage` прямого hit
  после защиты и округления, до взаимозачёта с лечением. Пробивание M4 учитывается.
  Урон только броне, урон шипов/столкновения и чистый огонь не открывают этот gate.
- Сначала исполняются прямой hit и всё его обязательное пространственное поддерево:
  равновесие, толчок, столкновения, смерти, шипы, снятие прежних пут. Затем идут
  кровотечение (если отдельно включено определением) и новые путы. Предметные
  реакции отложены до окончания этих обязательных последствий.
- Погибшая цель пропускает наложение. Новые путы не дают крит этому же удару
  задним числом. Прежние путы участвуют в его расчёте по C1.
- Живой цели ставится `entangled_turns=1`; оглушение сохраняется. Повторное
  наложение оставляет 1, без накопления срока. Истечение — в конце ближайшего
  хода команды цели; конец хода другой команды состояние не снимает.
- Добровольное движение запрещено, другие действия доступны при отсутствии
  оглушения. Порог равновесия удвоен. Следующий фактический принудительный сдвиг
  снимает путы; упор без перемещения не снимает. Если сам опутывающий удар снял
  прежние путы толчком, он может наложить новые после своих последствий.
- Требуется существующая валидная `ControlState` цели. При её отсутствии — отказ
  `control/capability_required` до оплаты. Новые иммунитеты контроля и создание
  capability у nullable-помощников в этот срез не входят. Иммунитет D3 относится
  только к кровотечению и сам по себе не запрещает путы.

## Границы реализации

`AttackDefinition.entangle_on_physical_hp` по умолчанию выключен и разрешён
только для `ARMOR_PROFILE`; `AttackRules` проверяет и копирует его вместе с
определением. `AttackCommand` проверяет capability до оплаты, затем передаёт
sealed признак `AttackHitCommand`. Внутренний `EntangleApplyCommand` хранит
связь с actor/target/source/hit/definition и ссылку на ControlState, допускает
известные изменения её значений предшествующим push, но не подмену объекта.
Прямой submit команды наложения запрещён. Мутация проходит `control_phase`
существующего spatial guard; fault сохраняет реально исполненный prefix.

Событие `control_changed` сохраняет прежнюю форму; новые причины `entangled`
и `refreshed` проходят строгую проверку before/after. Накопление сроков >1,
новые поля ControlState, версии Unit/Item и новые сериализуемые enum не нужны.
Состояние сохраняется прежними snapshot codecs, определение копируется штатным
`ActionContext.copy_for_simulation`. Старые выключенные определения сохраняют
прежнее исполнение и события.

Preview исполняет ту же команду на изолированной копии. UI показывает успешные
путы, пропуск из-за отсутствия физического HP-урона/гибели, срок и расход main.
Выбор режима сбрасывает прежний прогноз; клик строит новую команду по live.
Смена персонажа, отмена, другое действие, reset и смена сценария очищают режим.

## Проверка и ручной сценарий

F5 → «Начать бой» (K9) → Бор E4 → перейти на E5 → 7 → навести на Дозорного F5 → ударить.
Пробивающий клинок даёт физический HP-урон сквозь броню: прогноз и исполнение
должны показать путы без кровотечения. Клик по врагу в режиме движения показывает
его состояние. Конец хода врага снимает путы; раньше их снимает фактический толчок.

Адресные runner: `test_entangle_attack.gd` и `test_entangle_ui.gd`, включены
в full/render. Область: gate/повтор/смерть, отказ без оплаты, порядок последствий,
preview/live snapshots/events/steps/RNG/counters, restore, истечение,
FAULTED prefix/лимиты, настоящий ввод/свежий клик/reset и PNG.
Полная приёмка ядра, наложение оглушения, общий runtime статусов, новая скрытая
атака, реакции танка, карта забега, баланс, инициатива и новое падение — вне K8.
