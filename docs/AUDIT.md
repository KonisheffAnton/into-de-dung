# Исторический аудит и работа с дефектами

Аудит от 2026-09-11 сохранён полностью: [AUDIT history](AUDIT.history-20260920.md).
Там находятся исходные C-*, S-*, M-*, D-*, G-* и P-* с причинами и примерами.
Незаполненный checkbox отражает состояние той записи, а не доказательство
существующего дефекта на текущем HEAD. Для конкретного ID сверять код,
позднейший контракт и результаты исправления из [HISTORY](HISTORY.md).

Современная карта реализации и известных ограничений — [ARCHITECTURE](ARCHITECTURE.md).
Предлагаемые работы — [DESIGN_DIRECTION](DESIGN_DIRECTION.md). Новый найденный
дефект записывать в контракт/пакет текущей задачи со сценарием воспроизведения,
HEAD, статусом и проверкой; не обновлять историческую оценку задним числом.
Этот рефакторинг документации не проводит повторную приёмку всех старых дефектов.
