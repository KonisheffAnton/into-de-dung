# Прогнозы магии/карт и интерактивный бой32 — 2026-11-01

База: main `3e959837189e15157a7b379fcae9ad371edb4159`.
Цель — устранить фризы при наведении и проверить длительный бой с мышью.
Стабильные60 FPS пока НЕ подтверждены. Все времена ниже локальны для этой машины.

## Причина и изменение

`_mage_card_cache`/`_elemental_cast_cache` повторно создавали полный проверенный
снимок мира на наведении и при покадровой проверке уже готового прогноза.
Для32 бойцов один снимок занимал41–44мс, вход hover — около87мс,
проверка неподвижного готового прогноза —44–48мс.

`BattleForecastFreshness` строится после полного prepare в существующем worker
под исключительным владением session. После join UI сравнивает сырой граф:
значения/типы/identity, metadata, RNG, поля объектов и соединения сигналов;
реестр callback смерти проверяется отдельно. Это не admission и не hash/revision
cache. Неизвестный граф, RID, callbacks, циклы/лимиты и ошибка сериализации
включают прежний полный путь. Свежий click по-прежнему исполняет команду заново.
Между запросом и prepare отдельно проверяются тип карты и текущий occupant цели.
Контракт — [ATTACK_FORECAST](../ATTACK_FORECAST.md).

Готовый прогноз и уже обновлённая панель мага используют одну exact raw-проверку
в `_process`: повторный admission всей руки пропускается только при точном
совпадении с их общим свидетелем. Явный refresh панели сбрасывает связь; raw
мутация и возврат к старым значениям не оставляют промежуточную панель на экране.

Выбор магического режима дополнительно вызывал полный синхронный refresh:
23мс для магии,26мс для карты. Теперь штатный работающий UI выполняет его
по стадиям: уступает кадр выбора, отдельно обновляет панель мага, затем выполняет
четыре части refresh без повторного обновления мага. Быстрый следующий клик/смена режима сохраняются
как смысловые действия; камера не меняет записанную клетку. Pause/process_mode
и выключенный process сохраняют синхронный путь. Правила владения, отмены и
очереди — [BATTLE_EXECUTION_UI](../BATTLE_EXECUTION_UI.md).

Core, preview, queue, RNG, save и frozen не менялись. Нового арта/генерации нет.

следующему измеренному process interval. Pre/post-draw делят интервал только
при согласованных границах; это не физический scanout. Запись JSON — после боя.
