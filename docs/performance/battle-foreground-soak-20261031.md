## Готовность кадра и оставшийся вопрос

Для каждого из 40 display-выбросов посчитано:
`msUntilDisplayed - msUntilRenderComplete - msBetweenDisplayChange`.
У 36 кадров GPU завершил работу за **12,2528–13,6608 мс до предыдущего display
timestamp**; наибольший такой display-интервал — 25,2616 мс. Поздняя готовность
именно этих кадров не объясняет их задержку целиком. Конкретный виновный
драйвер, процесс или механизм ОС по этим данным не установлен.

Четыре оставшихся интервала — 50,0613 / 33,3891 / 33,2788 / 33,5127 мс;
кадр для них готов позже предыдущего display timestamp. Их CSV номера
372/5267/7639/12710 находятся рядом с Godot test-planning кадрами
373/5268/7640/12711. Это основание для отдельного измерения стоимости
подготовки действия, **не доказанное покадровое соответствие**.

PresentMon timestamps получены из ETW, а не независимого физического датчика
scanout. Новая запись воспроизводит задержки с фокусом и стабильным present mode,
но не даёт основания объявить все причины внешними по отношению к приложению.
Общий механизм выбора independent/composed описан в
[документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/for-best-performance--use-dxgi-flip-model);
она не доказывает причину наблюдаемых здесь выбросов.

## Исправление автотеста

`tests/test_battle_soak_performance.gd` теперь выбирает кандидата по пространственным
условиям и пути, затем передаёт его обычному live-worker со строгой валидацией.
Повтор разрешён только после нового завершённого REJECTED при возвращённом
владении сессией и доступном ходе игрока. Fault, interruption, pending, потеря
владельца и отсутствие нового receipt останавливают сценарий. Перед итоговым
чтением runtime выполняется join любой оставшейся работы и повторная привязка
владельца. Старый APPLIED/REJECTED не засчитывается новой команде.

`tests/test_battle_soak_planner.gd`: 61 PASS / 0 FAIL на управляющем цикле теста,
включая retry, abort, stale receipt и возврат владельца. Исходы подставные;
это не проверка реального отвергнутого worker transaction. Разбор Godot в
изолированной копии прошёл. Штатный launcher `--check --only battle_soak_planner`:
import/startup/planner — 3 PASS, без пропусков/таймаутов; отчёт
`test_reports/demo-6533e9039d1a4ed98d46e1aa60725c67/`.
Launcher unit tests: 30/30 PASS.
Независимое ревью конечных test-файлов — APPROVE; production/core/preview/RNG

Пользователь разрешил продолжать в его отсутствие. Последующие прогоны не
