# Бюджет кадра при действиях — 2026-10-31

Main, база `e413a9e49e9fd4a5d60e674526645c579bb049d3`.
Продолжение [первого этапа](action-smoothness-20261031.md): убрать оставшиеся
регулярные задержки около40 мс при действиях24 персонажей.

## Реализовано

- Полный аудит владения выполняется на main порциями с мягким бюджетом2 мс.
  Job уже владеет session; UI читает только проекцию. Поток запускается после
  всех прежних проверок. Неизвестные callbacks остаются синхронным fallback.
- Завершение показа распределяет настройки HUD, свежий capture/доступность,
  публикацию поля и финальный HUD по соседним кадрам. Reset отменяет UI-хвост,
  skip возвращает готовое управление сразу. H1 не раскрывает исход до конца.
- Начальная публикация отделена от первого клипа; технический after после
  анимированного after не публикуется в том же проходе. Фазы контакта непрерывны.
- Земля переиспользуется и при обычном refresh; подсветка обновляется отдельно.
  Авторский opt-in разрешает redraw только ground overlay; custom fallback прежний.
- Метки областей собираются по клеткам один раз, redraw касается изменившихся
  значений. Hover/acting также проверяют фактические флаги. Native-сортировка
  сохраняет порядок по экранному Y и индексу дочернего узла.
- Кандидаты action areas ограничены допустимой дальностью; оставшиеся клетки
  проверяет прежний AttackReachCheck. Порядок, пустые области и ошибки сохранены.
