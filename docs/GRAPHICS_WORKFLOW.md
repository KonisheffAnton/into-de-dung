# Графика: PixelLab

Поручение пользователя 2026-10-05: использовать предоставленный ключ PixelLab
для генерации графики intoDeDung. Провайдер — PixelLab.ai, API v2; это рабочий
инструмент графики, не утверждение финального стиля или разрешение заменить все ассеты.

Ключ хранится вне репозитория: `C:\Users\Aston\.codex\secrets\pixellab.dpapi`.
Это Windows DPAPI для текущего пользователя. Прочитать файл, убрать завершающий
перевод строки (`Trim()`), расшифровать через `ConvertTo-SecureString` и передавать
только в Authorization Bearer официальному `https://api.pixellab.ai`.
Значение ключа не писать в код, Git, журналы, отчёты или промпты передачи.
На другом компьютере потребуется локально настроить доступ к тому же аккаунту.

API: [документация](https://api.pixellab.ai/v2/llms.txt),
[OpenAPI](https://api.pixellab.ai/v2/openapi.json). Перед новой интеграцией сверять
поля API. Для пробы достаточно одной генерации, без автоматических серий повторов.
Сохранять запрос без секрета, исходный PNG и фактический usage; проверять размер,
прозрачность и читаемость. Подключать выбранный ассет к сцене по поручению.

Первая успешная проба — маг 64×64, прозрачный фон, `create-image-pixflux`,
usage 1 generation из подписки. Исходник/запрос/ответ без ключа:
`C:\Users\Aston\.codex\generated_images\pixellab-20261004\mage-trial-01.*`.
Ассет остаётся пробным и не подключён к игре. Текущий баланс читать через
`GET /v2/balance`, не считать зафиксированный ранее остаток актуальным.
