# Первый хаб героев — H1

2026-09-28. Поручение и ответы приняты в DESIGN_DIRECTION §3/3.1/6.1.
Этот контракт владеет поведением H1, CORE_READINESS — областью проверки,
TESTING — командами. Пользователь поручил ведущему временные числа/каталог.

Целевой набор героя уточнён 2026-10-07 в [DESIGN_DIRECTION §3.1](DESIGN_DIRECTION.md#31-классы-и-индивидуальность--выбор-2026-09-27).
Ниже остаётся legacy H1. Новый профиль основного F5 использует каталог v2 с
[Щитоносцем](SHIELDBEARER_V1.md); общий случайный набор активок/пассивок
и распределение безопасного отхода ещё не реализованы.

## Цикл и принятые правила

Legacy H1 (`hero_hub.tscn`): хаб → карточки/найм/отряд/развитие/экипировка → расстановка → настоящий
командный бой → опыт/потери → хаб. Один выход H1 содержит один бой.
Основной F5 начинает [U14](EXPEDITION_U14.md) с [колодой мага](MAGE_DECK_V1.md) через главное меню;
правила одиночного боя ниже сохраняются для старой контрольной точки/fixture.
Результат, восстановление после победы, платный ремонт и достижения H1
дополнены [POST_BATTLE_V1](POST_BATTLE_V1.md) 2026-10-01.
Классы: воин, стрелок, разбойник, маг-наёмник; внешний маг K18 отдельный.

- За победу каждый выживший участник получает одинаковую награду встречи;
  каждый резервист — 10% награды одного бойца. За поражение опыта нет.
  XP и уровень начисляются после боя; дробь хранится целыми десятыми.
- Уровни конечны, каждое повышение даёт одно очко. Стартовые очки распределены,
  перк врождённый. До «Применить» распределение изменяемо; видны производные
  значения и нулевые прибавки из-за порога/округления. Единого рейтинга силы нет.
  Точный урон по цели по-прежнему рассчитывает боевой прогноз.
- Рост максимума HP добавляет ту же дельту текущим HP. Уровень без вложения
  очка не меняет HP. Платный сброс возвращает только подтверждённые очки,
  оставляет базу/перк, ограничивает HP новым максимумом. В хабе нет запаса
  боевого равновесия: каждый бой начинает его заново.
- Живые выбранные герои бесплатно полностью лечатся перед выходом;
  это не ремонт брони. Погибшие не возвращаются.
- При победе вещи погибших попадают на склад, выжившие сохраняют вещи и остаток
  брони. При полном поражении взятая экипировка теряется, склад/резерв остаются.
  Временный помощник не заменяет погибший постоянный отряд.
- В найме всегда бесплатные новички уровня 1 с минимальным комплектом.
  Найм переносит показанного кандидата без переброса; замена получает новый ID
  и те же свойства до следующего исхода боя. После исхода обновляются четыре
  предложения. Ручного бесплатного переброса нет.

## Временные данные ведущего

12 героев всего, до 3 в отряде, 4 предложения. Старт: по одному герою каждого
класса, первые три в отряде, 100 золота. Победа: 100 XP участнику, 10 резервисту,
40 золота. Сброс: 50 золота. Предел уровня 10; переход L→L+1 стоит 100×L опыта.
На пределе уровни/очки не добавляются; технический предел XP — 10⁹ десятых.

| Класс | База Мощь/Ловкость/Выносливость/Интеллект | Дальность | Оружие | Броня |
|---|---|---:|---:|---:|
| Воин | 3/2/3/1 | 1 | 4 | 40 |
| Стрелок | 3/3/2/1 | 4 | 4 | 20 |
| Разбойник | 3/3/2/1 | 1 | 3 | 25 |
| Маг | 3/2/2/2 | 3 | 4 | 15 |

Генерация добавляет 0–2 случайно распределённых очка и один перк: +4 HP,
+2 равновесия, +1 перемещения либо +1 Мощи. Внедрённый RNG сохраняется;
файловый адаптер даёт новому прохождению случайный seed, тесты — явный seed.
Определения — Resource, состояние — RefCounted; данные отделены от runtime.

- HP = 20 + 2×Выносливость (+ перк); равновесие = 10 + 2×Выносливость (+ перк).
- Перемещение = 3 + floor(Ловкость/3) (+ перк); прежние 1 main и 1 bonus.
- Естественное сопротивление огню = min(50, 3×Интеллект) процентов.
- Физическая база = Мощь + оружие. Обычная атака мага: только огненная база
  Мощь + посох, без повторного физического вклада Мощи.
- Всем один флакон на бой: 4 + Мощь HP, прежняя оплата. Общие стойка/отход.
- Воин: оглушающий удар, реакции танка/контратака; стрелок: дальний и опутывающий
  выстрел; разбойник: скрытая атака, кинжал с 35% физического пробивания;
  маг: огненная атака, три стихийных действия K17, восстановление брони +20.
  Цены/сроки/условия прежних команд сохранены. Кровавая руна H1 не выдана.

Оружие только своего класса, любой обычный доспех можно передать любому герою.
Снятое остаётся на складе; карточка учитывает надетые вещи. Противники первого
боя: три дозорных по 24 HP, физическая база 6 и огненная 2. Нет продажи,
увольнения, случайной добычи; технический предел предметов — 2048.
Ненадетый предмет можно явно выбросить без компенсации; это позволяет освободить
два места для бесплатного комплекта новичка даже при полном складе. При нехватке
мест интерфейс объясняет отказ найма. Автоматического уничтожения вещей нет.
Баланс, пригодность новичков и риск обязательной Мощи ещё не проверены игроком.

## Владение и исход

`HeroHubState` владеет героями/кандидатами/вещами/отрядом; `HeroProgression` —
ростом. `HeroCatalog`/`HeroGearCatalog` дают определения. `HeroHubBattleFactory`
создаёт свежую точную `BattleCoreReactionsSession`: board, units, definitions,
inventory/equipment, очередь, события и отдельный RNG. Bundle связывает
постоянные ID героев/вещей с runtime ID. Изменяемый граф профиля не разделяется.
Расстановка, enemy-first, окружение, K18, guards и FAULTED сохраняются.
`actor_loadouts` задаёт атаки/классовые допуски; пустая таблица сохраняет legacy.
`TurnForecast` переносит таблицу в изолированную симуляцию; прогнозы исполняют
те же команды с вещами/RNG/ресурсами. Нет revision-only кэша мира.
Live worker владеет сессией исключительно; хаб не читает runtime при pending.

Исход извлекается после очереди без FAULTED; проверяются serial/фаза, полный
набор HP исходных героев и их предметов, типы/пределы. На копии профиля
выдаются награды, учитываются смерти/вещи, меняется фаза. Повтор отвергается.
Гибель всех постоянных участников даёт поражение даже при живом помощнике.

## Сохранение и ошибки

`user://hero-hub-v1.save`: писатель schema3 / `hero-hub-v3`, SHA-256.
Колода добавляет profile4; новый каталог Щитоносца — profile5 / `hero-hub-v5`
по SHIELDBEARER_V1. Загрузка прежних профилей не меняет их каталог классов.
Совместимое чтение schema1/2 и порядок миграции — POST_BATTLE_V1 и U14 §5.
`HeroHubStore` — внешний файловый адаптер, core не зависит от автозагрузок.
Строгая загрузка проверяет поля/типы/ID/владельцев/лимиты/конечность HP.
Новый профиль сразу сохраняется; повреждённый автоматически не заменяется.
Мутация: копия → проверка → временный файл/flush → замена → публикация в UI.
При отказе записи блокируется дальнейшая работа, доступен повтор записи;
старый опубликованный профиль неизменен. Терминальный исход пишется автоматически.
`.bak` сохраняется до успешной замены. Перед выходом пишется начало боя;
загрузка повторяет бой с теми же героями/вещами/seed, середина хода не сохраняется.
R и переходы к демонстрационным режимам закрыты. D4-save/миграции не менялись.
При FAULTED награды не выдаются; отдельная кнопка по явному нажатию повторяет
сохранённое начало боя. Автоматического отката исполненного prefix нет.
