## Pixel Logic: что применять

Michael Azzi, *Pixel Logic — A Guide to Pixel Art*, версия 1.0, ©2019.
Пользователь предоставил PDF 2026-10-09: 242 страницы. Разобран текст всех
девяти глав; ключевые иллюстрации проверены визуально. Отдельные анимационные
приложения не предоставлены: просмотр движения этим не заменён.
Ниже собственный краткий пересказ. Номера — страницы PDF с обложкой;
на проверенных страницах совпадают с печатными.

| Принцип | Практический смысл | Страницы |
|---|---|---|
| Масштаб раньше деталей | Выбирать размер по узнаваемым признакам; проверять в размере показа. Целое увеличение сохраняет сетку, уменьшение требует проверки. | 19–21, 88–96, 112 |
| Формы раньше пикселей | Строить связные массы света/тени; точность отдельного кластера не спасает слабое целое. Детали должны описывать форму. | 170–173 |
| Силуэт и просветы | Выделить признаки класса/действия. Развести слившиеся оружие, руки и корпус; внутренний контраст помогает там, где силуэта мало. | 95, 103, 106–108 |
| Фигура важнее фона | Проверять бойца на настоящей земле; отделять светлотой, цветом или контуром, а не повышать контраст всего рисунка сразу. | 79, 104–110 |
| Палитра по задаче | Переиспользовать оттенки, проверять их рядом. Оттенок и насыщенность теней можно менять; универсального числа цветов нет. | 65–85 |
| Осмысленный край | У ступенек должен быть ритм. Banding — соседние полосы повторяют один контур и зрительно утолщают его; исправлять форму края. | 23–29, 55–58 |
| AA по необходимости | Ручные промежуточные пиксели могут улучшать кривую; избыток размывает малый спрайт. Это не bilinear-фильтр и не требование сгладить всё. | 39–46, 111 |
| Дизеринг не по умолчанию | Полезен для перехода/материала, но съедает место и даёт зерно. Случайная россыпь не заменяет фактуру. | 115–120, 124 |
| Общий ракурс | Строить окружение по направляющим, сравнивать предметы рядом. Проекция служит игровому чтению; примеры книги не задают размеры нашей сетки. | 135, 147–158, 160, 181 |
| После трансформации — правка | Resize/rotate/skew дают заготовку: восстановить важные признаки, края и просветы в конечном размере. | 150, 177–180 |
| Сначала движение целиком | Ключевые позы, подготовка, траектория и длительности важнее числа кадров. Основное действие строить раньше запаздывающих частей. Проверять воспроизведение. | 215–225, 232–234 |
| Subpixeling дозировать | Перераспределение цветов даёт впечатление движения меньше пикселя. Не двигать каждый пиксель и не подменять движение ползущей светотенью; беречь лицо/силуэт. | 188–203, 205, 210–211 |

## Рабочий порядок intoDeDung

Это применение ведущего к нашей игре, а не числовые нормы книги.

1. Начать с выбранного эталона и `preset.json`: ракурс4:3 и посадку не угадывать
   заново. Не переносить учебный шаблон2:1 в наш контракт.
2. Смотреть обычный игровой размер: боец, опора, границы клеток, ловушки и
   подсветки. Затем поле6×6: не складываются ли кант и одинаковые пучки в узор.
3. У земли — спокойный центр и редкие цельные пучки; у бойца — ясные крупные
   признаки. Убирать вторичные формы, а не просто укрупнять пиксели.
4. Увеличение использовать для правки, затем снова смотреть малый размер.
   Проверить светлый/тёмный фон; nearest сам по себе не гарантирует качество
   уменьшения. Сравнить варианты в одинаковом масштабе до принятия.
5. Для будущей анимации сначала проверить позы и темп в движении, затем
   промежуточные кадры и мелкие эффекты. Статичный PNG не подтверждает анимацию.
