# K9 — единый боевой пакет ядра

Поручение 2026-09-25: объединять близкие задачи, реализовывать связанную цепочку
и предлагать одну крупную ручную приёмку. Base main `1a127c5d5c3416289f6f8f9bdc87876a42af3f80`.
Пакет реализован; результаты прогонов и независимого ревью — [HISTORY](HISTORY.md).
Это не заявление о завершении всего будущего ядра.

## Состав и владение

Основной вход F5 / «Сочетания ядра» соединяет свободную расстановку, прежние
C1/D3/D5/M4/K8, лечение, печать и поднятие, все восемь слотов и их прогнозы.
`BattleCoreCombinationSession` владеет расстановкой и включением печати в K2;
`UseSummoningItemCommand` — её исполнением, `ForecastSimulation` — изоляцией.
Точные дополнения печати — [SUMMON_ITEM](SUMMON_ITEM.md#композиция-с-бронёй-и-средой-k9),
восстановления брони — [ATTACK_FORECAST](ATTACK_FORECAST.md#k9--прогноз-восстановления-брони).
Отдельный универсальный runtime статусов/эффектов для этого не нужен.

## Расстановка

Согласованная фаза из TACTICAL_DESIGN_NEXT §7 теперь включена в основной K2.
A: зона проверочного сценария — A3–F6, только проходимые клетки без пропасти и
шипов. Занятые клетки не принимают другого бойца; обмен делается через свободную
клетку. Стартовая расстановка прежняя и уже допустима; начать можно без перестановок.
Клик по своему живому выбирает его, клик по свободной клетке переставляет через
BattleBoard. Оглушение/путы не мешают подготовке; враги доступны для осмотра.
Путь не прокладывается: расстановка не является добровольным боевым движением.

До «Начать бой» / Enter атаки, предметы, стойка, восстановление брони, поднятие,
прогнозы боя, конец хода и ИИ заблокированы на session API. Перестановка не тратит
ресурсы, не запускает шипы, контроль/кровотечение, RNG, очередь и реакции.
Состояния/остатки сохраняются; меняются только позиция/occupancy/board version.
Старт проверяет зону, occupancy и снимок; сохраняет ресурсы и сроки, переводит в
первый ход ровно один раз: в K2 игрока, в основном K15 противника
([порядок](ENVIRONMENT_COLLAPSE_K15.md)). Повторный старт и перестановка после него запрещены.
R возвращает исходную расстановку и исходное состояние сценария, включая предметы.

DEPLOYMENT добавлен в конец enum Phase; значения прежних фаз сохранены.
Подготовка — состояние session, а не новая схема боевого snapshot или save D4.
Созданная отдельно K2 session по умолчанию начинает бой для механических fixtures;
игровой UI явно включает расстановку. Старые адресные UI fixtures отключают её,
полный вход и переход проверяет `test_core_batch_ui.gd`.

## Один ручной прогон

F5 → при желании переставить отряд → «Начать бой». Слоты: 1 атака, 2 стойка,
3 лечение, 4 восстановление брони, 5 Кровавая руна, 6 поднятие, 7 путы, 8 печать.
Для простой комбинации оставить Бора E4, перейти E5 и ударить Дозорного F5 слотом 7.
Астрой можно поднять тело A4 или вызвать помощника печатью рядом с собой;
одновременно оба у одного владельца недоступны. Наведение на слот 4 показывает
расход и восстановление/временную броню. После хода врагов помощник начинает действовать.
Далее продолжить бой до победы/поражения и сбросить R. Отзыв нужен по целому бою,
отдельные ручные приёмки K8 и новых кнопок не требуются. Технические PASS не
подменяют этот отзыв и не закрывают прежнюю частичную приёмку автоматически.

## Проверки и границы

Один пакет `test_core_batch.gd`, `test_core_batch_ui.gd`, `test_summon_composition.gd`:
отказы подготовки, два размещения и полные бои через BT/команды до исхода;
изолированные preview/live/restore, ресурсы/RNG/admission/ID, FAULTED prefix;
печать/поднятие, pending/оба хода, вражеский помощник; реальный ввод и четыре PNG.
Включён в общий full/render. Механические адресные fixtures остаются регрессией,
их не требуется предъявлять пользователю по одному.

Не добавлены оглушающий удар/иммунитеты контроля, цепочки будущих команд,
реакции танка/скрытая атака, фаза среды, новое падение/цепной толчок.
Помощник сохраняет nullable control M1/D5; K8 требует capability у цели.
Карта/хаб/метапрогрессия, баланс и анимации вне пакета. Основной режим командный;
формулы, Q1–Q6/frozen, 1 main, действующие сроки, профиль D4 сохранены.
