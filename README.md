# intoDeDung

Тактическая игра для десктопа на Godot 4.7. Команды ходят поочерёдно;
игрок выбирает порядок своих бойцов. Текущий игровой цикл: меню → хаб →
поход из семи комнат → хаб с результатом. Бойцы, предметы, среда и колода
мага используют общий бой и изолированный прогноз.

Откройте `project.godot`, нажмите **F5 → Начать тест → Начать поход**.
Enter подтверждает расстановку; колесо меняет масштаб, ПКМ сдвигает поле.
Сцены F6 — отдельные проверки, основной поход начинается из хаба.
Графика и анимации пока пробные; техническая проверка не заменяет их приёмку.
